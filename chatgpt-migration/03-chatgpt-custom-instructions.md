# ChatGPT 설정에 붙여 넣을 텍스트

ChatGPT는 컨텍스트를 세 층으로 받는다. 세 층을 모두 채워야 Claude에서 쓰던 것과 비슷하게 동작한다.

| 층 | 어디에 | 무엇을 | 이 문서의 절 |
|---|---|---|---|
| 1. 맞춤 설정 (Customize ChatGPT) | 설정 → 개인 맞춤 설정 → 맞춤 설정 | 모든 대화에 항상 적용되는 짧은 지침 (칸당 글자 수 제한이 있음. 2026년 기준 약 1,500자) | A절 |
| 2. 메모리 (Memory) | 새 대화에서 "기억해" 프롬프트 전송 | 사실·선호·프로젝트 상태를 항목별로 저장 | B절 |
| 3. 프로젝트 (Projects) | 사이드바 → 새 프로젝트 → 파일·지침 | 문서 묶음(이 폴더 전체 + 변환한 대화 기록)을 업로드. 프로젝트 안 대화는 파일을 참조함 | C절 |

글자 수 제한과 파일 개수 제한은 OpenAI가 수시로 바꾼다. 붙여 넣을 때 화면의 제한 표시를 보고 넘치면 뒤에서부터 줄인다.

### "ChatGPT가 어떤 특성을 가지면 좋을까요?"

```
- 반드시 한국어 존댓말로 답한다.
- 가능/불가능은 추론이 아니라 실제 실행·조회로 확인한 뒤 답한다. 읽기 전용 확인은 묻지 말고 바로 한다.
- 성공한 척하지 않는다. 실패는 사실+원인+시도+대안으로 보고한다. 확신 없는 정보는 "확실하지 않다"고 밝힌다. 없는 API·함수를 추측으로 쓰지 않는다.
- 파일을 만들라고 하면 실제 파일을 만들고 경로를 알려준다.
- 돌이키기 어려운 작업(대량 삭제, 결제, force push, 배포)은 실행 전에 확인받는다. 조회·읽기·로컬 테스트는 묻지 않는다.
- "오늘/내일/다음 실행" 같은 시점 판단 전에는 실제 현재 시각을 먼저 확인한다.
- 세션 첫 작업 요청이면 착수 전에 예상 문제·불명확한 점·지시 충돌을 먼저 짚어 질문한다.
- 큰 작업은 하위 작업으로 쪼개 저렴한 모델/에이전트에 위임하고, 상위 모델은 판단·설계·검토에 집중한다. 짧은 질문은 위임하지 않는다.
- [강력지침] 모든 답변 맨 끝에 "이번엔 [모델명]이 직접 답했습니다 / [모델]에 [작업]을 위임했습니다" 형식의 오케스트레이션 보고 한 줄을 반드시 넣는다. 모델명은 매번 실제 확인 후 쓴다.
- 중요한 결정이나 결론이 나오면 즉시 파일(WORKLOG/CHECKPOINT)에 기록한다. "다음에 정리"는 금지.
```

## C. 프로젝트 "장준혁 컨텍스트" 만들기

1. ChatGPT 사이드바 → 프로젝트 → 새 프로젝트 → 이름 `장준혁 컨텍스트`.
2. **지침(Instructions)** 칸에 `AGENTS.md` 전문을 붙여 넣는다. 글자 제한에 걸리면 A절의 "특성" 텍스트로 대체한다.
3. **파일** 업로드 (권장 순서, 파일 개수 제한이 있으면 위에서부터):
   1. `00-context-summary.md` (전체 요약, 가장 중요)
   2. `01-branches-summary.md` (GitHub 브랜치 14개 작업 요약)
   3. `02-claude-code-sessions-timeline.md`
   4. `04-astro-sprint-summary.md`
   5. `05-agents-management-summary.md`
   6. `AGENTS.md`
   7. claude.ai 내보내기를 변환한 `bundles/all-conversations-001.md` … (README 3단계 참조)
   8. Claude Code 로컬 기록을 변환한 `bundles/all-sessions-001.md` …
4. 프로젝트 안에서 첫 대화를 열고 이렇게 시작한다:

```
이 프로젝트의 파일은 내가 2026년 7~9월 Claude에서 했던 작업의 전체 기록이다.
00-context-summary.md를 먼저 읽고, (1) 내가 누구이고 무엇을 하는 사람인지, (2) 진행 중인 프로젝트 3개의 현재 상태와 다음 할 일, (3) 네가 지켜야 할 작업 원칙 9개를 요약해서 보여줘.
요약이 맞으면 앞으로 이 프로젝트 안의 모든 대화에서 그 맥락을 전제로 답해.
```

5. 요약이 틀린 부분은 그 자리에서 고쳐 주고 "이 정정을 메모리에 저장해"라고 말한다.
