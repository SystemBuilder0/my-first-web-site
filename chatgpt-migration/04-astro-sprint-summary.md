## 4. 기술 스택과 구조

- **언어/런타임**: Python 3.14.5 (venv), numpy 2.5.1
- **웹 프레임워크**: Flask 3.1.3, Jinja2 3.1.6, Werkzeug 3.1.8 (단일 서버, 포트 **5001** — 5000은 좀비 소켓 문제로 이전)
- **점성술 계산 엔진**: Skyfield(MIT) + JPL **DE421** ephemeris (`product/de421.bsp`, 16.8MB). Swiss Ephemeris(AGPL)는 폐기.
  - 하우스 시스템: **Whole Sign** (직접 구현)
  - ASC/MC: GAST + 진황도경사 기반 직접 구현(atan2 표준식), astro.com과 각분 단위로 일치 검증됨

- **LLM**: **Gemini `gemini-3.6-flash`** (유료 티어 활성, `GEMINI_MODEL` 환경변수로 오버라이드 가능). SDK: `google-genai` 2.18.1. 이미지 생성은 실패했던 `gemini-2.5-flash` 대신 채택.

## 5. 열린 문제·리스크

- 🔴 **[최우선] 3분 동기 요청이 Cloudflare 터널·모바일 네트워크에서 끊긴다** — 비동기 전환 전까지 사실상 실배포 불가
- **임시 터널 URL이 재기동마다 바뀐다** — 배포하려면 정식 도메인이 사실상 필수
- 일부 컷(`explain-l6`, `serious-r7`)의 사각형 안쪽 톤이 페이지 배경보다 어둡다 — CSS로 한계, 에셋 재출력 필요
- `-l`/`-r` 파일명이 실제 인물 위치와 반대인 경우가 있다(반전 로직 버그) — 이름 대신 실측(픽셀 분포)으로 배정해야 함
- **iOS Safari 전부 미확인**: `mask-composite`, `background-attachment: fixed`, `100dvh`, `navigator.share()`
- `/admin/*`에 인증이 없다 — 공개 URL로 누구나 접근 가능. 실런칭 전 필수 보완 항목
- 데이터 보관기간·파기 정책 없이 저장 기능이 먼저 나갔다(법무 검토 보류의 결과)
- 광고: 조사 시점 기준 유료 채널 신규 계정 개설 가능한 곳 0개(`docs/27`). Pinterest가 다음 최우선 후보
- 치비 캐릭터 미제작 / 씬 이미지 6종이 옛 화풍(밤하늘 톤과 불일치) / `inputs/` 4개 폴더 여전히 빈 상태(리서치 시 "다른 정보 식단" 원칙이 실질적으로 작동하지 않음)
- 나머지 9개 챕터(11챕터 중 ch5만 시각 완성)가 아직 시각적으로 미착수
- `inputs/customer/`에 원문 커뮤니티 자료가 없어 Reddit 등 1차 자료 조사가 계속 막혀 있음(사이트 자체 차단)
- Swiss Ephemeris/AGPL 관련 리스크는 Skyfield 채택으로 해소됐으나, JPL 에페메리스 데이터 자체의 "퍼블릭 도메인" 지위를 명시한 1차 문서는 못 찾음(최종 법적 판단은 인간 몫으로 남겨둠)
