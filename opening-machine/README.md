# 오프닝 머신 (벤치마크 데이터 공정)

직감이 아니라 수치로 벤치마크 채널과 아웃라이어 영상을 고르고, 그 원문으로 AI 오프닝 생성기를 만드는 공정입니다.
채널마다 `config/<프로젝트>.json` 하나만 새로 만들면 신규 채널에서도 같은 공정을 그대로 반복합니다.

## 전체 공정

| 단계 | 이름 | 실행 | 산출물 |
|---|---|---|---|
| 0 | 설정 | `config/<프로젝트>.json` 작성 (검색어, 주제 사전, 기준값) | 설정 파일 |
| 1 | 채널 발굴 | `python machine.py discover <프로젝트>` | `candidates.json` |
| 2 | 수치 수집 | `python machine.py collect <프로젝트>` | `channels.json`, `videos.json` |
| 3 | 통계 선정 | `python machine.py score <프로젝트>` | `channels_ranked.csv`, `videos_A_outliers.csv`, `videos_C_contrast.csv` |
| 4 | 원문 확보 | `python transcripts.py <프로젝트>` (대표님 PC) | `openings.jsonl`, `transcripts/` |
| 5 | 오프닝 뱅크 | AI가 오프닝을 유형·약속·문장 구조로 태깅 | `opening_bank.jsonl` |
| 6 | 생성기 | A급 다량 예시 + C급 대조 → 후보 30~50개 → 금지 표현 필터 → AI 비교 심사 → 상위 3개 | 오프닝 후보 |
| 7 | 피드백 | 대표님 선택·수정 기록, 업로드 후 30초 유지율 → 뱅크와 규칙 갱신 | `edits_log.jsonl` |
| 8 | 확장 | 같은 공정을 주제·제목·썸네일 문구·썸네일 이미지·본문·클로징·설명란·고정댓글, 쇼츠·릴스·스레드에 적용 | |

1~3단계는 한 번에 `python machine.py all <프로젝트>`로 실행합니다.

## 판정 기준 (전부 수치)

**채널 통과 조건** (`channel_filter`)
- 구독자 1만~200만
- 롱폼(4분 이상) 20편 이상, 마지막 업로드 180일 이내
- 제목의 한글 비율 0.6 이상
- 주제 적합도(제목에 주제 사전 단어가 들어간 비율) 0.35 이상
- 게시 30일 이상 지난 롱폼 10편 이상

**채널 점수** (높은 순으로 상위 30개)
- 35% 평소 체급: log10(중앙 조회수)
- 30% 터뜨리는 빈도: 채널 중앙값의 3배 이상 나온 영상 비율 (20%면 만점)
- 15% 구독자 대비 도달: 중앙 조회수 ÷ 구독자 (0.3이면 만점)
- 20% 주제 적합도 (0.8이면 만점)

**영상 라벨**
- 아웃라이어 배수 = 영상 조회수 ÷ 그 채널 최근 롱폼(게시 30일 이상) 조회수 중앙값
- A급: 배수 3 이상, 조회수 3만 이상, 제목이 주제에 맞을 것, 채널당 최대 10편
- C급(대조): 배수 0.5 이하, 채널당 3편

기준값은 모두 config에서 바꿀 수 있습니다. 근거: 업계 표준인 "채널 중앙값 대비 배수"(1of10, vidIQ, Paddy Galloway의 3~4배 기준), 중앙값 사용(평균은 대박 한 편에 왜곡됨), 게시 30일 경과(조회수 안정화).

## 한계 (정직하게)
- 남의 채널 30초 유지율은 공개되지 않습니다. 조회수 배수는 오프닝뿐 아니라 주제·제목·썸네일 효과가 섞인 신호입니다. 그래서 7단계에서 내 채널 30초 유지율로 보정합니다.
- 자막은 공식 API로 남의 영상을 받을 수 없어 4단계는 비공식 라이브러리를 대표님 PC에서 소량 실행합니다. 원문은 내부 분석·예시용으로만 쓰고 재배포하지 않습니다.
- YouTube Data API 기본 한도는 하루 10,000 유닛입니다. 검색 1회가 100 유닛이라, 검색어 30개 × 길이 2종 × 1페이지 = 약 6,000 유닛이라 하루 안에 1~3단계가 끝납니다. `pages_per_query`를 2로 올리면 하루를 넘기므로 이틀에 나눠 돌립니다.

## 준비물
- YouTube Data API v3 키 (Google Cloud 콘솔 → API 및 서비스 → YouTube Data API v3 사용 설정 → 사용자 인증 정보 → API 키)
- PC 실행 시: 환경변수 `YT_API_KEY`에 키 설정, `pip install youtube-transcript-api`
