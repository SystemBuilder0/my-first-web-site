> 영상 끝 20~30초 / 뉴스레터 하단 / 쓰레드 고정 댓글에 들어갈 문장

```

```

## 리퍼포징 체크리스트

```
[ ] 뉴스레터        — 뼈대 그대로 (4주차~ 발송)
[ ] 유튜브 롱폼      — 훅+블록1~5+실행을 구어체로
     [ ] 설명란 첫 줄에 미끼 링크
     [ ] 고정 댓글에 링크 한 번 더
     [ ] 채널 폐쇄 가드레일 7개 항목 확인
[ ] 쓰레드 5개       — 블록 1개 = 포스트 1개 (월~금 예약)
     [ ] 본문에 링크 넣지 않음 (고정 댓글에)
     [ ] 이번 주 링크 포함 포스트가 1~2개 이하
[ ] 쇼츠 2~3개       — 롱폼에서 블록 구간 클립 (4단계 이후)
[ ] 블로그           — 뉴스레터 원문 + 검색형 제목 (6단계 이후)
```
