# 04. 제품 매트릭스 — 제품을 고민하지 않고 생성하는 법

## 원칙

```
제품 = (검증된 주제) × (상품 형태)
```

주제는 **상상하지 않고 채널에서 추출**한다.
형태는 **아래 표에서 고른다.**
이 둘의 곱이라서, 제품 기획에 쓰는 시간은 사실상 0이어야 한다.

우선순위 공식:
```
우선순위 = (수요 신호 × 만들기 쉬움) / 제작 시간
```
→ 거의 항상 **PDF/워크북이 1등**이다. 수요 위에 있고, 쉽고, 빠르다.

---

## 상품 형태 표

### 무료 (미끼 — 이메일 수집용)
| 형태 | 제작시간 | 비고 |
|---|---|---|
| 셀프체크 / 진단 PDF | 2h | ★ 1순위. "내 유형"을 알려주면 반응이 가장 좋다 |
| 1페이지 체크리스트 | 1h | 가장 빠름 |
| 미니 가이드 (5~10p) | 3h | |
| 노션 템플릿 | 3h | 사용법 안내 필요 |
| 스크립트/문구 모음 | 2h | "이럴 때 이렇게 말하기" |

### 저가 (1만~3만) — **여기서 시작한다**
| 형태 | 제작시간 | 가격대 |
|---|---|---|
| 워크북 PDF | 4h | 1.0~1.5만 |
| 이북 (30~60p) | 6h | 1.5~3만 |
| 노션 시스템 (템플릿+가이드) | 5h | 1.5~2.5만 |
| 오디오 가이드 / 명상 트랙 | 4h | 1.5~2만 |
| 프롬프트팩 / AI 도구 세트 | 3h | 1.5~2.5만 |
| 30일 이메일 챌린지 | 6h | 2~3만 |

### 중가 (10만~50만) — 유닛 3개 SCALE 이후
| 형태 | 비고 |
|---|---|
| 강의 (동영상) | 15~50만 |
| 워크북+강의 패키지 | 20~40만 |

### 구독 / 고가 — 신뢰 자산 형성 이후
| 형태 | 비고 |
|---|---|
| 멤버십 커뮤니티 | 월 1~5만 |
| 뉴스레터 유료 등급 | 월 5~15천원대 |
| 코호트 프로그램 | 고가. 희소성("2자리 남음") 활용 |
| 1:1 컨설팅 | 최고가. 시간이 안 늘어나므로 마지막 |
| 앱 구독 | 개발 비용 있음. SCALE 유닛 3개 이후 |
| 굿즈 / 건강보조식품 | 재고 리스크 있음. 후순위 |

## 주제 × 형태 매트릭스 (심리 채널 기준 예시)

행 = 주제(채널에서 추출), 열 = 형태. 칸 하나가 **제품 후보 1개**다.

| 주제 \ 형태 | 셀프체크(무료) | 워크북(1.5만) | 오디오(1.5만) | 30일챌린지(3만) |
|---|---|---|---|---|
| **불안** | 불안 유형 셀프체크 | 3분 불안 진정 워크북 | 잠들기 전 불안 완화 오디오 | 30일 불안 리셋 |
| 애착유형 | 애착유형 진단 | 관계 패턴 교정 워크북 | — | 30일 애착 회복 |
| 수면 | 수면 습관 진단 | 밤 루틴 설계 워크북 | 수면 유도 오디오 | 30일 수면 재건 |
| 번아웃 | 번아웃 단계 체크 | 회복 워크북 | — | 30일 에너지 복구 |
| 자존감 | 자존감 셀프체크 | 자기대화 교정 워크북 | — | 30일 자존감 훈련 |
| 관계/거절 | 경계 설정 진단 | 거절 문장 워크북 | — | — |

**주제 6개 × 형태 4개 = 24개 제품 후보.** 고민할 게 없다. 표를 채우면 된다.
채널이 2개면(심리 + 자기개발) 이 표가 2장이 된다.

> 자기개발 채널용 주제 축 예시: 습관 · 집중력 · 목표설정 · 시간관리 · 의사결정 · 학습법 · 커리어 방향성

## 제품 생성 프롬프트 (에이전트 위임용)

```
당신은 {주제} 분야의 실무형 콘텐츠 제작자다.

대상: {구체적 상황의 사람 — 예: "밤에 잠들기 전 생각이 멈추지 않는 30대 직장인"}
형태: {워크북 PDF, A4 20페이지 내외}
약속하는 변화: {구체적 결과 — 예: "3분 안에 신체 반응을 진정시키는 절차를 갖게 된다"}

요구사항:
- 이론 설명은 전체의 20% 이하. 나머지는 실행 절차와 빈칸 작성란.
- 각 챕터는 "상황 → 왜 그런가(3줄) → 지금 할 것(단계) → 기록란" 구조.
- 의학적 진단이나 치료 효과를 단정하지 말 것. 필요시 전문가 상담 안내 문구를 넣을 것.
- 첫 페이지에 이 워크북으로 얻게 될 것 3줄.
- 마지막 페이지에 다음 단계 제품 안내 자리를 비워둘 것.
```

## 상품 사다리

```
무료 미끼 → 저가(1~3만) → 중가(15~50만) → 멤버십(월 1~5만) → 코호트/컨설팅(고가) → 앱 구독
```

**지금은 앞의 두 칸만 있으면 된다.**
사다리는 위에서부터 짓는 게 아니라 아래에서부터 쌓는다.

핵심 통찰: **무료 콘텐츠는 상품이 아니라 퍼널이다.**
뉴스레터·유튜브는 무료로 주고, 수익은 다른 곳(제품·강의·스폰서)에서 낸다.
유료 구독은 여러 수익 모델 중 하나일 뿐이지 목표가 아니다.

---

## 승자와 패자를 가르는 것

주제가 아니다. 이 둘이다.

1. **콘텐츠가 구체적인 변화를 약속하는가**
   - ❌ "불안에 대해 알아봅니다"
   - ✅ "3분 안에 불안을 진정시키는 절차를 갖게 됩니다"
2. **가치를 포착할 제품 사다리가 있는가**
   - 광고·구독만으로는 포착되지 않는 가치가 항상 남는다. 그걸 담을 그릇이 제품이다.
