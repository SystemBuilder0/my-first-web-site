# 프로젝트 브리핑 — 설문형 커플 궁합 진단

> 이 문서는 기획 문서 20개를 심사 가능한 형태로 압축한 **자기완결 브리핑**이다.
> 다른 파일을 읽지 않아도 판단에 필요한 결정·숫자·근거가 전부 들어 있다.

---

## 1. 제품 정의

**"우리, 서로를 얼마나 알고 있을까"** — 커플이 6~8분 안에 함께 끝내는 상호 이해 진단.
점술이 아니라 실용 관계 콘텐츠. 진행자는 무당이 아니라 **심리 상담가 '언니'** 캐릭터(흰 가운 + 청진기, 말투는 반말 친근톤).

**레퍼런스**: 청월당(cheongwoldang.com). 한국의 사주 콘텐츠 커머스. UI 문법·결제 퍼널·리포트 구조를 벤치마크했다. 청월당은 37,400원 3택 상품 구조.

**포지셔닝 (확정)**
| | 버린 것 | 취한 것 |
|---|---|---|
| 카피 | `너희 궁합 몇 점?` | `쟤가 진짜 원하는 게 뭔지 알려줄게` |
| 파는 것 | 관계 점수 | 상대방의 속마음 |
| 지불 명분 | 진단 결과 | 내가 절대 알 수 없는 정보 |

논리: "궁합 진단"이라 부르면 사주와 같은 링에 오르는데, 우리는 입력 마찰(설문 15문항 × 2인)이 더 크므로 반드시 진다. "상대 해독"으로 부르면 사주가 구조적으로 못 하는 일이 된다.

**타깃 (확정)**: 서로 호감이 있고 알아가는 중인 초기 커플. 썸 ~ 연애 100일 미만. 정보 비대칭이 최대인 구간.

**목표 UX 5개 (성공 기준)**: ① 재밌었다 ② 서로를 더 이해하게 됐다 ③ 평소 못 할 대화를 했다 ④ 의외의 모습을 알게 됐다 ⑤ 내가 얼마나 오해하고 있었는지 알게 됐다

## 2. 비즈니스 모델

- **단일가 5,900원 단건 결제.** 상품 선택지 없음(저가 구간에서는 3택 앵커링보다 결정 피로가 더 큰 이탈 요인이라 판단)
- 정가 8,900원 취소선 + 얼리버드 -3,000원 + 33%↓ 뱃지
- 간편결제 4종, 토스페이에만 2% 할인 뱃지
- **비회원 결제 기본.** 회원가입 강제 금지
- 업셀(`애프터 질문팩`)은 결제 화면이 아니라 리포트 완독 후
- 재구매 설계: 결과가 고유 URL로 재열람 가능, 대화 주제는 다음 데이트에 다시 열림

**무료 / 유료 절단선**

| 점수판 | 원천 | 무료 | 유료 |
|---|---|---|---|
| 총 궁합점수 | 전체 가중합 | 🔒 블러 (`?점`) | 공개 |
| ① 싱크로율 | 예측 3문항 × 2인 | 공개 | 공개 |
| ② 관계운영 궁합 | 제1장 4문항 | 공개 | 공개 |
| ③ 로망 싱크 | 제2장 3문항 | 🔒 | 공개 |
| ④ 🔞 은밀한 궁합 | 제4장 3문항 | 🔒 | 공개 |

원칙: 무료는 **"우리 이만큼 어긋났네"라는 문제 인식**까지만. **해답과 은밀한 정보는 전부 유료.**
무료 마지막에 "가장 크게 어긋난 문항 1개" 전문을 공개해 결제를 트리거한다.
총점을 잠그면 공유할 숫자가 사라지므로, **공유 카드의 주인공을 총점 → 싱크로율로 이동**했다.

## 3. 설문 구조 (15문항 확정)

```
제1장  우리 사이           4문항   Q1~Q4    관계 운영
제2장  내가 바라는 것       3문항   Q5~Q7    상대에게 '해답지'가 되는 문항
제3장  너는 어떨까          3문항   Q8~Q10   상대 예측 (맞히기 게임)
제4장  조금 더 은밀하게 🔞   4문항   Q11~Q14  Yes/No 게이트, Q14는 자유서술
제5장  마지막 한마디        1문항   Q15      자유서술
```

**측정 축**: Q1 애정수신채널 / Q2 갈등타이밍 / Q3 데이트선호 / Q4 연락페이스 / Q5 설렘트리거 / Q6 원하는케어 / Q7 매력우선순위 / Q11 주도권 / Q12 섹슈얼매력포인트 / Q13 여운·애프터

**문항 예시 (톤 파악용)**

> **Q2.** 서로 좀 부딪힌 날. 나는 보통 어떻게 돼?
> ① 그 자리에서 바로 풀어야 함 ② 감정이 좀 가라앉으면 말함 ③ 각자 시간 갖고 정리되면 꺼냄 ④ 상대가 먼저 다가올 때까지 기다림

> **Q6.** 안 좋은 일 있어서 기분이 바닥일 때, 상대가 이렇게 해주면 딱 좋다면?
> ① 같이 열받아하며 편들어줄 때 ② 말없이 꼭 안아줄 때 ③ 아무것도 안 묻고 옆에만 있어줄 때 ④ 아예 기분 전환시켜줄 때

> **Q15.** 쟤한테 제일 바라는 거, 딱 하나만 적어줘. `자유 서술`

**설계 원칙**
- 제2장 선택지는 **전부 상대가 실제로 할 수 있는 행동**으로 쓴다. 유저가 고른 문장이 리포트 "상대 사용설명서"에 그대로 옮겨진다
- 제3장 예측 문항의 선택지는 Q1·Q6·Q3와 **완전히 동일**하다. 결과에서 두 답을 나란히 놓고 적중/오답을 즉시 보여주기 위해
- 톤 규칙: 갈등·불안·서운함을 전제한 장면 금지. **설문을 마쳤을 때 기분이 좋아져 있어야 한다**
- 인지부하 규칙: `어떻게 할래?`(설계형) 대신 `어떻게 돼?`(반응형)로 묻는다
- 🔞 게이트를 예측 뒤에 배치한 이유: 게이트 도달 시점 누적 투자가 7 → 10문항으로 늘고, 직전이 가장 재미있는 예측 게임이라 몰입 최고조에서 Yes를 묻게 된다

## 4. 진입 구조

- **같이 있어요 (1폰 릴레이)** — A 15문항 → "이제 폰 넘겨, 훔쳐보기 금지" → B 15문항 → 즉시 결과. **완주율 1위 모드. MVP는 이것만 구현**
- **따로 있어요 (링크)** — 2차 확장. DB·세션 저장 필요

**진입장벽 완화 장치**: 진입 즉시 `?점` 게이지 티저 / 1화면 1행동 / **생년월일 불필요**(이름 2개 + 사귄 기간 슬라이더뿐) / 진행률 % 대신 장(章) 표기 / 장 끝마다 언니 한 줄 / 선택지 탭 = 즉시 다음 문항

## 5. 리포트 구조 (결제 후 9장)

| 장 | 제목 |
|---|---|
| 1 | 총평 — 총 궁합점수 잠금 해제 연출 |
| 2 | 싱크로율 — 예측 6페어 대조 |
| 3 | 관계운영 궁합 — 레이더차트 2개 |
| 4 | 로망 싱크 |
| 5 | 🔞 은밀한 온도차 |
| 6 | 가장 어긋난 TOP3 + 해법 |
| 7 | **상대 사용설명서** ← 이 제품의 진짜 상품 |
| 8 | 오늘 나눠볼 대화 주제 3가지 |
| 9 | 언니의 편지 |

분량 약 9,000자(A4 4~5쪽). 언니 일러스트 총 17컷 필요(입력 6 + 무료결과 2 + 리포트 9).

**해석 생성 아키텍처**: 각 섹션이 자기 카테고리 3~4문항만 쓰면 반드시 피상적이 된다. 그래서 **모든 섹션이 30개 응답 전체를 참조하되 결론만 자기 렌즈로 낸다.** 같은 문항을 여러 섹션이 인용해도 되지만 **같은 결론을 두 번 말하지 않는다.**

## 6. 채점 엔진 (규칙 기반, LLM 미사용)

- **애착 2차원 채점**: 모든 선택지에 불안(anxiety)·회피(avoidance) 점수(−1~+2)를 부여. 7개 문항이 기여. 애착 문항을 한 장에 몰지 않고 흩어놓는다 — 몰면 유저가 의도를 알아채고 답을 꾸미지만, 흩어놓으면 결과에서 성향이 나올 때 "이걸 어떻게 알았지" 충격이 발생하고 이게 최대 결제 트리거가 된다
- **정합도 매트릭스 10종**: 문항별 선택지 쌍 궁합 점수. 9개는 유사성 기반(같은 답 = 100), **Q11 주도권만 상보성**(①리드×②받는쪽 = 100, ①×① = 40). Q12는 상대의 Q11과 교차 매칭
- 점수는 전부 결정론적이다. LLM에 맡기면 같은 입력에 다른 점수가 나오고, 재열람 시 숫자가 바뀌면 신뢰가 즉시 무너진다
- LLM은 리포트 2~8장 **해설 서술에만** 투입

---

## 7. 기술 / MVP 범위

- **Next.js (App Router) + Vercel.** LLM 호출은 서버 라우트에서만
- MVP에 포함: 1폰 릴레이 전 흐름, 채점 엔진, LLM 리포트 9장, **페이월 플래그(기본 OFF = 전체 공개)**
- MVP에서 제외: 결제, 링크 모드, DB, 일러스트 17컷, 공유 카드 이미지, 사주 파트
- 현재 코드는 **0줄**. 기획 문서만 존재

**이 답이 충분한지는 검증되지 않았다.**

## 10. 아직 답이 없는 것 (심사 초점)

기획 문서 20개는 문항 설계와 리포트 구조에 대해서는 과할 정도로 촘촘하다. 반면 아래는 거의 비어 있다.

1. **유통** — 첫 1,000명이 어디서 오는가. 문서 전체에서 이 주제를 다룬 건 한 챕터뿐이며 결론은 "랜딩페이지 + 소액 광고 20~30만원 테스트"에 그친다
2. **단가 대비 획득비용** — 5,900원 단건으로 한국 퍼포먼스 광고 CAC를 감당할 수 있는지 계산된 적이 없다
3. **LTV** — 1회성 콘텐츠라 재구매 근거가 약하다. 업셀 상품(`애프터 질문팩`)은 아직 존재하지 않는다
4. **경쟁** — 무료 커플 테스트 콘텐츠가 이미 널려 있는 시장에서 5,900원을 받을 근거가 실증되지 않았다
5. **2인 동시 참여** — 마찰인지 해자인지 판정된 적이 없다
6. **제품 형태** — 웹 단건결제 콘텐츠여야 하는 이유가 검토된 적이 없다
