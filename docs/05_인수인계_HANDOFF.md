## 1. 제품이 무엇인가 (원 기획 요약 — 심사에서 "살릴 것"으로 확정된 부분)

**"우리, 서로를 얼마나 알고 있을까"** — 커플이 6~8분 안에 함께 끝내는 상호 이해 진단.
- **포지셔닝**: "궁합 점수"가 아니라 **"쟤가 진짜 원하는 게 뭔지 알려줄게"** — 파는 것은 관계 점수가 아니라 상대방의 속마음. 사주와 같은 링에 오르지 않기 위한 의도적 선택.
- **타깃**: 썸 ~ 연애 100일 미만 초기 커플 (정보 비대칭 최대 구간).
- **진행자 캐릭터**: 심리 상담가 '언니' (흰 가운 + 청진기, 반말 친근톤).
- **설문 구조 (15문항 확정)**: 제1장 우리 사이(Q1~4, 관계 운영) / 제2장 내가 바라는 것(Q5~7, 상대에게 해답지가 되는 문항) / 제3장 너는 어떨까(Q8~10, 상대 예측 게임 — 선택지는 Q1·Q6·Q3와 동일해 적중/오답 즉시 대조) / 제4장 🔞(Q11~14, Yes/No 게이트, Q14 자유서술) / 제5장 마지막 한마디(Q15 자유서술).
- **진입 모드**: MVP는 **1폰 릴레이만** (A 15문항 → 폰 넘기기 → B 15문항 → 즉시 결과). 링크 모드(따로 있어요)는 2차.
- **채점**: 규칙 기반 결정론 엔진 (LLM 미사용). 애착 2차원(불안/회피) 점수를 7개 문항에 흩어서 채점. 정합도 매트릭스 10종 — 9개는 유사성 기반, Q11 주도권만 상보성. LLM은 리포트 해설 **서술에만** 투입.
- **리포트 9장**: 총평(총점 잠금해제 연출) / 싱크로율(예측 6페어 대조) / 관계운영 궁합(레이더차트) / 로망 싱크 / 🔞 온도차 / 어긋난 TOP3+해법 / **상대 사용설명서(진짜 상품)** / 대화 주제 3가지 / 언니의 편지. 약 9,000자. 모든 섹션이 30개 응답 전체를 참조하되 결론만 자기 렌즈로.
- **무료/유료 절단선**: 무료 = 싱크로율 + 관계운영 궁합 + "가장 크게 어긋난 문항 1개 전문" (문제 인식까지). 유료 = 총점·로망·🔞·해답 전부.
- **결제**: 비회원 기본, 간편결제, 단일 상품 (3택 앵커링 기각됨).
- **기술**: Next.js (App Router) + Vercel. LLM 호출은 서버 라우트에서만. MVP에 결제 제외 (페이월 플래그, 기본 OFF = 전체 공개).

이 제품 층위의 결정들은 심사에서 **전부 유지 판정**을 받았다. 후속 세션은 이 층위를 재설계하지 말 것.

## 2. 심사 최종 판정과 논리 골격

**판정: "고쳐야 한다" (뒤집기 아님).**

논리 골격은 두 층의 분리다:
- **제품 층위** (포지셔닝·문항·채점·리포트·MVP 절단) → 일관되게 수준 높음. **무수정 유지.**
- **시장 진입 층위** (유통·가격·획득 경제성) → **사실상 설계가 없었음.** 원 기획 20개 문서 중 유통을 다룬 것은 한 챕터뿐이었고 결론이 "소액 광고 20~30만원 테스트"에 그쳤다. 심사는 이 층위를 새로 세웠다.

이대로 출시하면 좋은 제품이 아무에게도 도달하지 못한 채 끝난다 — 이것이 수정 지시의 전부다.

## 3. 확정된 전략 결정 10개 (결정 → 근거 → 버린 대안)

### D1. 유료 퍼포먼스 광고를 주력 채널에서 제거한다
- **근거 (수치 계산)**:
  - 공헌이익: 5,900원 − PG 수수료(~3.3%) − LLM 원가(수십~수백 원) ≈ **약 5,300~5,500원**.
  - 한국 Meta CPC 실측 후기: **538~938원** (아이보스 광고주 게시판, 신뢰도 중간).
  - CAC ≤ 5,500원이 되려면 CPC 700원 기준 **랜딩→결제 전환율 13% 필요**.
  - 한국 이커머스 평균 전환율 실측: **1.3~1.8%**. 이 제품은 결제 전 "상대를 옆에 앉히는" 관문까지 있어 평균보다 높을 수 없다.
  - **필요 전환율과 실측의 간극이 10배.** 퍼널 최적화로 메꿀 수 있는 크기가 아니다.
- **단가 인상으로도 못 구한다**: 19,900원 × 전환 2%여도 CAC 35,000원(CPC 700원 기준) > 매출. 광고가 성립하는 사주 상품(청월당 37,400원)은 3만원대 단가 + "사주"라는 기존 검색 수요 위에 있다. 우리는 검색 수요 없는 신규 카테고리라 인텐트 트래픽 자체가 없다.
- **유일한 예외**: 무료 티저(D2) 완료자 대상 리타게팅 — 전환율 분모가 다르므로 성립 가능성 있음 [미검증, 실험 대상].
- **버린 대안**: 단가를 사주 수준(3만원대)으로 올려 광고를 살리는 안 → 가격만 사주를 따라가고 수요 기반(검색 인텐트)은 못 따라가는 어중간한 포지션. "데이트 중 임펄스 결제"라는 소비 맥락과도 충돌.

### D2. 유통 엔진 = 30초 무료 예측 티저의 공유 루프 (마케팅이 아니라 제품 기능)
- **결정**: 제3장 예측 게임 메커니즘만 떼어낸 **3문항 무료 티저**("쟤 마음 맞히기")를 별도 URL로 만든다. 혼자 시작 → 상대 소환 → 결과 카드(싱크로율 %) 공유 → 카드에 본편 딥링크.
- **근거**: 무료 테스트 바이럴은 한국에서 반복 실증된 유일한 저비용 유통 경로다. **푸망: 출시 6개월 누적 683만 명, MAU 224만** (언론 인터뷰, 신뢰도 높음). 봉봉: 누적 참여 2억+. 확산 매체는 전부 인스타 스토리/카톡 공유 카드. "나는 쟤를 몇 % 아는가"는 자기 과시와 상대 소환을 동시에 하는, 일반 심리테스트보다 강한 훅이다.
- **본편 무료 구간이 티저를 겸할 수 없는 이유**: 본편 무료 결과는 30개 응답(15문항×2인, 6~8분) 이후에 나온다. 콜드 트래픽에 이 선투자는 너무 무겁다. 공유 루프의 입구는 30초여야 돈다.
- **보조 채널**: 커플 릴스/유튜브 계정 30~50개 시딩 (무료 코드 + 촬영 허용 — "커플이 서로 맞히기"는 이미 검증된 릴스 문법이라 소재 제공만으로 성립). 광고비가 아니라 노동으로 사는 채널.
- **정직한 표기**: 티저→본편 전환율, 카드 경유 신규 유입 계수(K)는 **미검증**. 첫 1,000명 실험의 목적이 이 두 숫자 획득이다.

### D3. 공유 카드 이미지를 MVP 범위에 포함시킨다 (원 기획의 오류 정정)
- 원 기획은 공유 카드를 MVP 제외 목록에 넣었다. **오류다.** 공유 카드는 부가 기능이 아니라 유일한 유통 엔진이다. 공유 카드의 주인공을 총점→싱크로율로 옮긴 원 기획 판단은 옳았는데 정작 그 카드를 MVP에서 뺀 것은 모순.
- 구현: OG 이미지 동적 생성 (Next.js에서 저비용).

### D4. 2인 동시 참여는 해자가 아니라 마찰이다 — "데이트 중 소비"로 맥락 고정
- **해자 기각 이유**: 해자 = 복제 곤란성. 2인 형식은 무료 밸런스게임도 쓰는 형식이라 복제 장벽 0.
- **마찰 관리법**: 이 상품을 "발견 즉시 소비"가 아니라 **"데이트 중 소비"**로 설계 — 두 사람이 이미 같이 있는 순간에 소비되게 한다. 1폰 릴레이 선택이 이미 이 방향. 추가로: ① 티저는 혼자 시작 가능 (상대 소환은 티저 결과 화면이 수행), ② 공유 카드·인플루언서 콘텐츠의 CTA는 "지금 해봐"가 아니라 **"다음 데이트 때 해봐"** + 저장(북마크) 유도.
- **진짜 해자 후보** (시간이 만드는 자산): 응답 아카이브(재진단 시 변화 비교) + 언니 캐릭터 브랜드.
- **금지**: "상대 없이 나만 해보기" 솔로 모드 → 포지셔닝을 흐리므로 기각 확정.

### D5. 지불 명분을 "정보"에서 "순간"으로 옮긴다 (페이월 = 게임 프레임)
- **원 기획의 답과 그 한계**: "정보 비대칭은 상대방에게서 온다"는 방향은 맞지만 치명적 반례가 있다 — 결제자는 상대가 답하는 동안 **바로 옆에 앉아 있었다**. 결제 안 하면 그냥 물어보면 된다. 정보는 대화로 우회 가능하다 (사주의 정보 비대칭은 우회 불가라는 점이 결정적 차이).
- **진짜 상품 2가지**: ① **대조 구조물** — 30개 응답을 교차한 싱크로율·어긋남 TOP3·상대 사용설명서는 대화로 재구성 불가능한 가공물. ② **공개의 연출** — 결제 순간은 둘 다 궁금해 몸이 달아 있는 데이트 한가운데다. 이때 5,900원은 정보 구매가 아니라 **"게임 다음 라운드 결제"**(오락실 동전 심리).
- **설계 지시**: 페이월 화면 문법을 "잠긴 정보 목록"이 아니라 **"2라운드 시작" 예고**로 쓴다. "가장 어긋난 문항 1개 전문 공개" 트리거는 유지하되 직후 카피는 "나머지 해답 보기"(정보 프레임) ❌ → "2라운드 시작"(게임 프레임) ⭕.
- 애착 채점을 문항에 흩어놓아 "이걸 어떻게 알았지" 충격을 만드는 원 설계는 이 명분을 강화하므로 유지.

### D6. 가격 5,900원은 "확정"에서 "검증 대상"으로 격하 — 5,900/9,900 A/B
- 광고 CAC를 못 감당하는 건 어느 가격이나 마찬가지(D1)이므로, 가격 결정 기준은 "바이럴 유입의 전환 극대화 vs 건당 마진"으로 바뀐다.
- 출시 시 5,900/9,900 A/B. 취소선 앵커도 동반 조정 (8,900 → 9,900 테스트 시 14,900).

### D7. LTV: 구독 기각, "관계 단계별 확장팩" 라인 채택 (단, 2순위 문제)
- 코어 상품 LTV 0은 수용한다. 손익은 **첫 구매 단독으로 성립**해야 하며, 확장팩 구매율[미검증]을 믿고 CAC를 높게 잡는 것은 금지.
- **구독 기각 이유**: 구독은 콘텐츠 공급 능력이 전제인데 현재 자산은 문항 세트 1개. 공급 없는 구독은 해지율로 귀결. (확장팩 5개+ 쌓이면 번들 구독 재검토 가능.)
- **확장팩이 맞는 이유**: 채점 엔진·리포트 파이프라인·언니 캐릭터가 전부 재사용 자산이라 한계비용 = 문항 세트 1개 값. 관계 단계 전환(권태기·장거리·동거·결혼준비·기념일)마다 정보 비대칭이 재발생. 원 기획이 "가치관·미래 블록 → 결혼준비 확장팩 분리"를 해둔 것이 이 라인의 첫 조각.
- **재구매 훅**: 리포트 마지막 장(언니의 편지) 말미에 **"100일 뒤 다시 재보기 — 싱크로율이 얼마나 올랐을까"** 예약 훅. 고유 URL 재열람 설계가 이미 있어 비용 거의 0.

### D8. 제품 형태: 웹 단건결제 유지. 앱·구독·B2B·오프라인 기각, "선물하기"만 2차 카드
- **웹이 맞는 이유**: 데이트 중 발견 → 즉시 실행이 되려면 설치 관문이 없어야 한다. 링크 하나 + 비회원 결제가 유일한 정답.
- 앱 기각(설치 마찰이 임펄스 소비를 죽임, 이벤트성 소비라 리텐션 기반 없음) / B2B 기각(영업 사이클이 검증보다 길고 🔞이 기관 톤과 충돌) / 오프라인 카드 기각(재고·물류가 소프트웨어 반복 속도 강점을 죽임).
- **선물하기 [2차 실험]**: "친구 커플에게 선물" — 결제자≠사용자 구조라 2인 마찰을 우회. 카카오 선물하기에 모바일교환권 카테고리 존재는 확인됐으나 이런 류 콘텐츠의 입점 성공 사례는 못 찾음 → MVP 이후 카드로만 등록.
- 수용하는 약점: 웹 단건은 푸시 채널이 없다. 재방문 수단은 공유 카드와 재열람 URL뿐.

### D9. 경쟁 방어 = 구조가 아니라 속도와 브랜드 축적
- 5,900원을 받을 근거는 존재한다: 무료 테스트가 못 하는 ① 2인 교차 채점 ② 30개 응답 참조 개인화 서술 ③ 연출된 잠금 해제 클라이맥스.
- 그러나 셋 다 기술 장벽이 아니다 (LLM 원가는 누구에게나 수십 원, 교차 채점은 기획력 문제). 잘되면 3개월 안에 카피 등장 예상. 그때 남는 것은 언니 캐릭터 톤·후기·인플루언서 네트워크·확장팩 카탈로그 — 전부 선발주자의 축적물.
- 지불 의사의 선례 [검증됨]: 한국 점술 시장 ~1.4조 원 추정, 점신 운영사 연매출 830억, 포스텔러 MAU 63만. 가장 가까운 선례는 연애의 과학(스캐터랩, 심리학 기반 유료 연애 분석) [심사역 지식 기반, 리서치 재확인 안 됨]. 단 전부 사주·운세 카테고리라 **설문형 커플 진단의 지불 의사는 여전히 이 사업이 스스로 증명해야 할 본질 리스크**다.

### D10. 사주 하이브리드는 계속 보류
- 유입 실패 시에도 이 카드보다 무료 티저(D2)가 먼저다. 티저 지표까지 실패하면 사주 카드 검토가 아니라 유통 가설 자체를 재심사한다.

## 5. 실행 순서 (우선순위대로)

1. **[Opus/기획] MVP 절단선 수정 명세** — 공유 카드 이미지 생성을 "제외→포함". 페이월 화면을 게임 프레임("2라운드 시작")으로 명세 (D3, D5). 결제 자체는 계속 MVP 제외 (페이월 플래그 유지).
2. **[Sonnet/구현] 본편 MVP** — Next.js(App Router)+Vercel, 1폰 릴레이 전 흐름, 규칙 기반 채점 엔진, LLM 리포트 9장, 페이월 플래그. 기획 변경 없음 — §1 사양대로.
3. **[Sonnet/구현] 30초 예측 티저** — 3문항, 별도 라우트, 결과 카드 OG 이미지 동적 생성, 본편 딥링크. 본편과 동시 출시 목표 (D2).
4. **[Opus/기획] 시딩 플랜** — 커플 릴스/유튜브 계정 30~50개 리스트, 아웃리치 메시지, 무료 코드 정책. "광고 예산 배분 금지" 원칙 명문화 (D1, D2).
5. **[Opus/기획] 가격 A/B 설계** — 5,900/9,900, 앵커 동반 조정 규칙, 최소 표본 기준 (D6).
6. **[Opus/판단] 일러스트 우선순위** — 17컷 중 언니 핵심 3컷(페이월·잠금해제·편지)만 선행 제작할지 비용 대비 판단. 나머지는 매출 후 (D9 — 캐릭터가 방어 자산).
7. **[출시 전 필수] 중단 기준 수치화** — 티저 공유율·K계수·본편 전환율의 최소 기준을 출시 전에 숫자로 확정. 미달 시 유통 가설 자체 재심사 (사주 카드 소환이 아님).
