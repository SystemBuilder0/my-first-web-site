## 1. 제품 정의

**"우리, 서로를 얼마나 알고 있을까"** — 커플이 6~8분 안에 함께 끝내는 상호 이해 진단.

점술이 아니라 **실용 관계 콘텐츠**다. 진행자는 무당이 아니라 **심리 상담가 '언니'**다.

### 포지셔닝 (확정)

| | ✗ 버리는 것 | ○ 취하는 것 |
|---|---|---|
| 카피 | `너희 궁합 몇 점?` | **`쟤가 진짜 원하는 게 뭔지 알려줄게`** |
| 파는 것 | 우리 관계의 점수 | **상대방의 속마음** |
| 지불 명분 | 진단 결과 | **내가 절대 알 수 없는 정보** |
| 경쟁 상대 | 사주 궁합 (입력 마찰이 커서 우리가 진다) | **없음** — 사주가 구조적으로 못 하는 일 |

> **핵심 논리**: 설문 제품의 최대 리스크는 "내가 다 말해줬는데 왜 돈을 내?"라는 지불 명분 붕괴다.
> 이걸 뒤집는 열쇠는 하나뿐이다 — **내가 모르는 정보 = 상대의 답변.**
> 그래서 이 제품의 모든 유료 자산은 "상대가 뭐라고 답했는가"에서 나온다.

### 타깃 (확정 · 클라이언트 직접 결정)

**서로 호감이 있고 알아가는 중인 초기 커플.** `썸` ~ `연애 100일 미만`을 아우르되 무게중심은 초기 커플.

이 단계는 서로를 가장 모르고, 가장 알고 싶어 하고, **정보 비대칭이 최대인 구간**이다. "상대 해독" 포지셔닝이 가장 강하게 작동한다.

> 참고 — `05_사업전략_리스크진단`은 "기념일 커플로 좁혀라"라고 권고했으나, 클라이언트 결정으로 **초기 커플 유지**. 기념일 앵글은 나중에 랜딩·광고 카피 레벨에서만 변주 가능하다(문항 변경 불필요).

### 사주 하이브리드 — 미도입 (확정 · 클라이언트 직접 결정)

순수 설문형 포지셔닝을 유지한다.

> 참고 — `05` 문서는 사주를 무료 유입 깔때기로 쓰라고 강하게 권고했다. 이 카드는 **폐기가 아니라 보류**다. MVP 검증 후 유입이 부족하면 그때 다시 꺼낸다. (근거: 만세력 계산은 공개 라이브러리로 해결되고, 해석 텍스트는 LLM 생성 대상이라 착수 비용이 낮다.)

### 목표 UX — 이 다섯 개가 성공 기준이다

1. 재밌었다
2. 서로를 더 이해하게 됐다
3. 평소 못 할 대화를 했다
4. 의외의 모습을 알게 됐다
5. 내가 얼마나 오해하고 있었는지 알게 됐다

## 2. 진행자 캐릭터 — '언니' (확정)

**시각 설정**: 흰 가운 + 청진기 + 클립보드. 갈색 머리를 느슨하게 올려 묶은 30대 초반 여성. 밝은 상담실 배경.

**핵심 원칙 — 병원이 아니라 상담소.**
> 가운은 **전문성의 시각 기호로만** 쓴다. 언어는 전부 반말 친근톤이다.

| ✗ 병원 톤 (헤비) | ○ 상담소 톤 |
|---|---|
| 문진표 · 접수 · 정밀검사 | 상담 노트 · 첫 질문 |
| 진단서 · 소견서 | 언니가 본 우리 |
| 처방전 | 이렇게 해봐 |
| 환자 · 진료 · 내원 | 그냥 너희 |
| `접수 도와드리겠습니다` | `자, 편하게 앉아봐` |

**말투**: 청월당 시아의 `"왔어? 일단 이름 먼저 말해봐."` 문법을 차용하되, 신비주의 대신 **경험 많은 사람의 직설**.

**절대 금지**: 사주·운세·점술 용어 일절 사용 금지.

**기능적 역할**: ① 입력 단계를 대화로 위장 ② 무료→유료 전환의 화자 ③ 마지막 편지로 정서적 마무리

**🔞 장에서는 컷을 노출하지 않는다.** 캐릭터가 선정성을 대변하지 않도록 분리한다.

**필요 컷**: 입력단 6 + 무료결과 2 + 리포트 9 = **총 17컷**

### 충돌 3의 파생 결정 — 애착 엔진은 어디로 가는가

04(9장)를 택하면 06이 설계한 **애착 유형 전용 장(2·3·4장)이 사라진다.** 그런데 `07_설문지`에는 이미 **모든 선택지에 불안·회피 점수가 매겨져 있다.** 이 자산을 버리지 않는다.

> **결론: 애착은 독립된 장으로 세우지 않고, 리포트 전 장의 「해석 근거」로 내부 사용한다.**

- 애착 2차원 점수는 계속 산출한다 (규칙 기반, LLM 불필요)
- 유형명(안정/불안/회피/혼란)을 **전면에 내세우지 않는다** — 대신 제3장(관계운영)·제6장(TOP3)·제7장(사용설명서)의 LLM 프롬프트에 **숨은 근거로 주입**한다
- 효과: "이걸 어떻게 알았지" 충격은 유지하면서, 학술 검사를 표방한다는 오해는 피한다
- 고지 문구는 그대로 유지한다 — `본 콘텐츠는 학술적으로 검증된 심리검사가 아니며, 재미와 자기이해를 위한 콘텐츠입니다.`

### 충돌 3의 파생 결정 2 — 제8장 교체 (클라이언트 직접 결정)

04의 제8장은 「오늘 밤 나눠볼 질문 12」 카드 덱이었다. **이를 「오늘 나눠볼 대화 주제 3가지」로 교체한다.**

> 클라이언트 지시: *"맨 마지막에는 이런 걸 주제로 대화, 이런 질문들에 대해 이런 대화를 나눠보면 좋겠어 라는 세 가지 주제를 던져주면서 마무리해. 이 세 가지 대화 주제를 하면서 너희가 더 가까워지고 서로 이해하게 되고 너희 관계 문제를 해결하는 데 도움이 될 거야."*

12장 카드 덱 대비 이점: 분량 부담이 줄고, **각 주제에 "왜 너희에게 이 주제인가"라는 개인화 근거를 붙일 수 있어** 오히려 밀도가 올라간다. 상세는 `02_리포트_명세.md` 제8장 참조.

## 4. 설문 구조 (확정 · 15문항)

```
제1장  우리 사이           4문항   Q1~Q4    관계 운영
제2장  내가 바라는 것       3문항   Q5~Q7    상대에게 '해답지'가 되는 문항
제3장  너는 어떨까          3문항   Q8~Q10   상대 예측 (맞히기 게임)
제4장  조금 더 은밀하게 🔞   4문항   Q11~Q14  Yes/No 게이트 (Q14는 자유서술)
제5장  마지막 한마디        1문항   Q15      자유서술
────────────────────────────────────────
                        총 15문항
```

### 배치 원칙 — 몰입 계단형

`가벼움 → 중간 → 예측 → 🔞 게이트 → 열린 질문`

- 이탈이 가장 큰 첫 3문항을 가장 가벼운 것으로 채운다
- 예측 문항은 자기 응답을 전부 마친 뒤에 오므로 답하기 쉽고 재미만 남는다
- **🔞 게이트를 예측 뒤로 미루는 이유**: 게이트 도달 시점의 누적 투자가 7문항 → 10문항으로 늘고, 직전 블록이 가장 재미있는 예측 게임이라 **몰입 최고조에서 Yes를 묻게 된다.** 전환율이 구조적으로 높아지는 배치다.

### 문항 수 산정 근거

일반 심리테스트의 "10문항 넘으면 이탈" 기준을 그대로 쓰면 이 제품은 **과소설계**된다.

- 이탈은 총량이 아니라 **"끝이 보이는가"의 함수**다. 첫 3문항에서 가장 크게 터지고, 그 다음은 끝이 안 보일 때 급증한다
- 커플 제품은 **사회적 커밋먼트**가 걸린다. 1폰 릴레이는 상대가 옆에서 보고 있어 중도 포기가 사실상 어렵다
- 진짜 병목은 따로 있다 — 두 사람이 각각 하므로 **실질 부담은 `문항수 × 2`**

→ **목표: 1인 3~4분 / 커플 합산 6~8분.**

### 문항 작성 기준 (03F · 유효)

**형식**: 4택 「딱 하나만」이 주력. 강제선택은 밸런스 게임의 재미인 동시에 **사회적 바람직성 편향을 줄이는 검증된 기법**이다.

**톤 규칙 (엄수)**
- ○ 긍정적이거나 중립적인 상황만
- ✗ 다툼·갈등 직후 상황 / 불안 자극 상황 / 서운함·자책·의심을 전제한 장면 / 상대를 나쁘게 상상하게 만드는 설정 / 정도 차이 선택지(`자주 / 가끔 / 드물게`)

> **원칙**: 유저가 설문을 마쳤을 때 기분이 **좋아져 있어야 한다.** 타깃은 아직 사이가 좋은 초기 커플이다.

**인지부하 규칙 (최우선)**
> **`어떻게 할래?`(설계) 대신 `어떻게 돼?`(반응)를 물어라.**

설계형은 미래를 상상하고 4개를 저울질해야 해서 무겁다. 반응형은 이미 겪어본 장면이라 답이 몸에서 바로 나온다. `딱 하나만 고른다면` 프레임은 **제2장에만** 쓴다.

**선택지 길이**: 12자 내외. 괄호 설명 금지. 두 번 읽게 만들면 실패.

**제2장 전용 규칙**: 선택지는 **전부 상대가 실제로 할 수 있는 행동**으로 쓴다. 이래야 답안지 조건이 자동 충족되고, 유저가 고른 문장을 리포트 제7장에 **그대로 옮겨 적을 수 있다.**

**판별 기준**: 선택지 4개가 서로 다른 「관계 스타일의 사람」을 그려야 한다. 재밌지만 연애적 의미 차이가 없으면 탈락.

| 3 | Q14·Q15 원문 노출 고지 시점 | **입력 화면 상단 고정 배지** | 모달은 탭이 하나 더 필요해 마찰. 배지는 입력 전 내내 보이므로 고지 요건을 더 확실히 충족 |
| 4 | 4장 건너뛴 유저 처리 | **결과 화면에서 인라인 재유도** | 리포트 이탈 없이 모달로 4문항을 받고, 완료 즉시 ④ 점수 산출 + 총점 재계산 |

## 6. 진입장벽 설계 (입력단)

청월당은 생년월일만 넣으면 끝난다. 우리는 설문을 시킨다. 이 격차를 메우는 장치들.

1. **결과를 먼저 보여준다** — 진입 즉시 궁합점수 게이지가 `?점`으로 도는 티저
2. **1화면 1행동, 폼 없음.** 버튼 문구는 사용자 대사 (`"좋아, 시작해볼게"`)
3. **입력 정보 최소화** — 사주가 아니므로 **생년월일 불필요.** 이름 2개 + 사귄 기간 슬라이더면 끝
4. **진행률 바 대신 장(章) 표기** — `제2장 내가 바라는 것 · 2/3`. 남은 분량이 아니라 진행한 이야기로 느끼게
5. **장 사이 중간 피드백** — 매 장 끝에 언니 한 줄
6. **🔞 게이트는 예측 뒤** — `"이 다음은 좀 야한데, 열까?"` / **No 눌러도 손해 없음 명시**
7. **선택지 탭 = 즉시 다음 문항** — 별도 "다음" 버튼 없음
8. **중도 이탈 시 "이어서 하기" 링크** (MVP 이후)

### 진입 모드 — MVP는 1폰 릴레이만 (확정)

- **같이 있어요 (1폰 릴레이)** — A 15문항 → `"이제 폰 넘겨. 훔쳐보기 금지."` 전환 화면(A 답변 완전 차단) → B 15문항 → 즉시 결과
  → **완주율이 가장 높은 모드이므로 MVP는 이것만 구현한다**
- **따로 있어요 (링크)** — 2차 확장. DB·세션 저장이 필요해 개발량이 2~3배

## 7. 무료 / 유료 절단선 — MVP에서는 플래그로만 존재

> **MVP 원칙: 결제 시스템 없이, 입력하면 아웃풋이 즉시 전부 나온다.**
> 단, **어디를 잠글지는 지금 확정해두고 코드에 플래그로 심어둔다.** 나중에 플래그 하나만 켜면 페이월이 복원된다.

### 점수판 구조

| 점수판 | 원천 | MVP | 결제 도입 후 |
|---|---|---|---|
| **총 궁합점수** | 전체 가중합 | 공개 | 🔒 **블러** — 가장 궁금한 숫자 |
| ① 싱크로율 (예측 적중률) | Q8~Q10 × 2인 | 공개 | 공개 |
| ② 관계운영 궁합 | Q1~Q4 | 공개 | 공개 |
| ③ 로망 싱크 | Q5~Q7 | 공개 | 🔒 블러 |
| ④ 🔞 은밀한 궁합 | Q11~Q13 | 공개 | 🔒 블러 |

### 절단선의 원칙 (결제 도입 시)

> 무료 구간은 **"우리 이만큼 어긋났네"라는 문제 인식**까지만 준다.
> **해답과 은밀한 정보**는 전부 유료에 둔다.

- 무료 공개: 점수판 ①②, 관계운영 해설, 서로의 마지막 한마디(Q15) 원문, **"가장 크게 어긋난 문항 1개" 전문** ← 결제 트리거
- 블러: 총점, ③④, 로망 장 전체, 🔞 장 전체 — **제목은 노출**(청월당 방식)
- **총점 블러의 부수효과 대응**: 총점을 잠그면 무료 구간에서 공유될 숫자가 사라진다. 그래서 **공유 카드의 주인공을 총점 → 싱크로율로 이동.** `"우리 싱크로율 67%"`도 충분히 공유되는 숫자다

### 결제 화면 사양 (구현은 2차)

- 단일가 **5,900원**, 선택지 없는 한 버튼 (저가 구간에서는 3택 앵커링보다 결정 피로가 더 큰 이탈 요인)
- 정가 8,900원 취소선 + `얼리버드 -3,000원` + `33%↓` 뱃지
- 간편결제 4종, **토스페이에만 `2%할인` 뱃지**
- 동의 체크 **기본 체크 상태**
- **비회원 결제 기본.** 회원가입 강제 금지
- 업셀은 결제 화면이 아니라 **리포트 완독 후**

## 9. 해석 생성 아키텍처 — 얕은 문항을 깊게 만드는 법

**문제**: 각 섹션이 자기 카테고리 3~4문항만 쓰면 해석이 반드시 피상적이 된다.
**해결**: 모든 섹션이 **30개 응답 전체(15문항 × 2인)를 참조**하되, **결론만 자기 렌즈로 낸다.**

### 4단계 파이프라인

**1단계 — 특성 추출**
- 객관식 11문항 → 규칙 기반 태그 변환 (`갈등:즉시형`, `애정수신:시간형` 등)
- 애착 2차원 점수 산출 (불안 / 회피)
- 자유서술 2문항(Q14·Q15) → LLM으로 키워드·정서톤·요구 유형 추출
- 예측 3문항 → `적중/빗나감` + **빗나간 방향**(과대평가 / 과소평가)

**2단계 — 3종 프로필 생성**
`A 프로필` / `B 프로필` / `관계 프로필(교차)`
관계 프로필에는 **불일치 지도**가 들어간다 — 어느 영역에서, 얼마나, 어느 방향으로 어긋났는지.

**3단계 — 섹션별 생성**
각 섹션에 투입: `전체 프로필 3종` + `해당 섹션의 렌즈` + `이미 사용된 결론 목록`

| 섹션 | 주 데이터 | 반드시 교차 참조할 것 |
|---|---|---|
| 2 싱크로율 | 예측 3문항 | 빗나간 예측이 **어느 영역**인지 → 오해의 구조 |
| 3 관계운영 | Q1~Q4 | 로망 문항(원하는 방식 vs 현재 방식의 격차), 자유서술의 온도, 예측 정확도, **애착 좌표** |
| 4 로망 싱크 | Q5~Q7 | 갈등 대응 방식(로망이 무너지는 지점), 🔞 응답, Q15 서술 |
| 5 🔞 온도차 | Q11~Q13 | 애정 수신 채널, 로망, Q14 원문 |
| 6 TOP3 | 전 영역 격차 스캔 | 해당 문항이 속한 영역의 세부 데이터, **애착 좌표** |
| 7 사용설명서 | Q5~Q7 | Q1~Q4 전부 — 로망을 **실제 상황에서의 실행 방법**으로 번역, **애착 좌표** |

**4단계 — 중복 제거 원칙**

> **같은 문항을 여러 섹션이 인용해도 되지만, 같은 결론을 두 번 말하지 않는다.**

- 섹션마다 `사용한 결론 레지스트리`를 누적하고, 다음 섹션은 같은 결론을 **주 논거로 재사용 금지**(보조 언급은 허용)
- 각 섹션은 **자기 렌즈로만 결론을 낸다**

**예시 — 같은 데이터, 다른 결론**
- *관계운영 섹션*: "A는 로망 문항에서 '먼저 알아채주는 것'을 골랐는데, 갈등 문항에서는 '말로 해줘야 안다'를 골랐어. **A는 평소엔 눈치를, 갈등 때는 말을 원해.** 그런데 B는 정확히 반대로 하고 있어."
- *로망 섹션*: (같은 응답을 쓰되) "**A가 원하는 건 이벤트가 아니라 관찰이야.** B의 예측은 이벤트 쪽으로 빗나갔어."

같은 응답을 근거로 쓰되 **결론의 층위가 다르다.** 이것이 적은 문항으로 9개 장을 채우면서도 반복되지 않게 하는 유일한 방법이다.

### 자유서술 2문항은 LLM이 다듬지 않는다

**Q14(🔞 민감 포인트)와 Q15(바라는 것 하나)는 원문 그대로 상대에게 전달한다.** 다듬는 순간 사람 냄새가 사라진다.
