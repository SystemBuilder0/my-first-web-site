- 02:39 "모션 디자인 비디오 만들어 줘"만 입력 → **퀄리티 미달**

- → **프롬프트에 (a) 구체적 제품/서비스 (b) 용도·매체(TV광고/킥스타터) (c) 브랜드명을 반드시 명시**

### 1-2. 단계 4의 타게팅 로직 (이 영상에서 가장 값어치 있는 부분)
타깃은 **대기업이 아니라 SMB**. 근거: 전통 에이전시 견적이 편당 $3,000~$6,000라 SMB는 못 샀는데, 우리는 그 아래를 칠 수 있음 (07:43–08:02).

| 소스 | 필터 조건 | 왜 이 사람들이 사는가 |
|------|-----------|----------------------|
| Google Maps | 특정 지역(예: 산타모니카) SMB 100곳 | 웹사이트에 이메일 공개, 로컬 광고 수요 |
| Amazon / Shopify | 평점 4.3↑ + 리뷰 500개↑ + **영상 없이 이미지로만 판매** | 리뷰가 쌓였다 = 이미 팔린다 = **지불 여력 있음**, 동시에 영상이 없다 = **명확한 결핍** |
| Kickstarter | 펀딩 달성률 **10~50% 구간** | 전환 장치 하나만 더 있으면 목표 달성 → 절박함이 곧 구매 동기 |

→ 공통 원리: **"돈이 있고(지불 여력) + 구멍이 있는(영상 부재) + 급한(마감 존재)" 3중 교집합**만 친다.

### 1-3. 단계 5의 스팸 회피 규칙 (영상 08:16–08:30, 09:55–10:33)
- CAN-SPAM 준수: 발신자 신원 명확 표시 / 수신거부 링크 포함 / 오해 소지 있는 제목 금지
- **도메인 워밍업**: 도메인 산 직후 대량발송 금지. 1일차 4~5통 → 2일차 5~6통 → 점진 증량

### 영상과 현실의 차이 (정직한 보고)
1. **이 영상은 Higgsfield 협찬 영상입니다.** 설명란 첫 줄이 제휴 링크입니다. "월 1천만 원"은 검증된 수치가 아니라 영상의 주장이므로, 매출 기대치를 그대로 믿고 계획을 세우면 안 됩니다.
2. **영상은 "반나절"이라고 했지 3시간이라고 하지 않았습니다.** 3시간은 더 타이트합니다. 아래 계획은 3시간에 맞춰 **범위를 잘라낸** 버전입니다.
3. **이메일 발송은 자동화되지 않습니다.** Gmail MCP에 발송 기능이 없고, 애초에 도메인 워밍업 원칙상 첫날 4~5통은 손으로 보내는 게 맞습니다. 자동 대량발송은 3시간 계획에 넣으면 안 되는 항목입니다.

## 3. 3시간 설계 — 임계경로 재배치

### 3-1. 가장 중요한 설계 결정: 도메인을 맨 앞으로 뺀다
영상은 도메인/이메일을 3번째(중간)에 배치했습니다. **이걸 그대로 따라 하면 3시간 안에 못 끝납니다.**

이유: 도메인 구매 후 DNS 전파 + Google Workspace의 MX/SPF/DKIM 인증에 **수십 분~수 시간**이 걸립니다. 이건 우리가 빨리 한다고 빨라지는 시간이 아닙니다(= 임계경로). 반면 영상 생성·웹사이트 제작은 우리가 손을 놀리는 만큼 진행됩니다.

→ **T+0에 도메인부터 결제하고, DNS가 익는 동안 영상·웹사이트를 만든다.**

### 3-2. 타임박스 (총 180분)

| 시각 | 단계 | 산출물 | 검증 기준(= 완료 조건) |
|------|------|--------|----------------------|
| **T+00~15** | **A. 결정 & 도메인 선점** | 니치 1개, 브랜드명, 도메인 결제 완료, Workspace 트라이얼 시작 | 도메인 관리 콘솔에서 네임서버 저장 완료 |
| T+15~20 | B. Higgsfield 크레딧 충전 | credits > 0 | `balance` 재호출로 확인 |
| **T+20~75** | **C. 포트폴리오 영상 4편** | mp4 ×4 | 로고 글자 안 깨짐 / 손·얼굴 왜곡 없음 / 15초 내외 |
| T+75~105 | D. 에이전시 웹사이트 | 배포된 URL 1개 | 모바일에서 열리고, 영상 4편 재생됨 |
| T+105~115 | E. 이메일 연결 | `name@도메인` 수신·발신 테스트 | 본인 개인메일로 왕복 1통 성공 |
| **T+115~150** | **F. 리드 리스트** | 이메일 60~100개 (영상의 200개는 3시간엔 과함) | 중복 제거 + 도메인 유효성 확인 |
| T+150~170 | G. 콜드메일 템플릿 | 템플릿 1종 + 개인화 변수 | 한국어 역번역 검증 + CAN-SPAM 3요소 포함 |
| T+170~180 | H. 1일차 발송 | **5통** 수동 발송 | 반송 0건 |

### 3-3. 병렬화 계획 (3시간을 맞추는 유일한 방법)
- C단계 영상 4편은 **순차 생성하면 시간 초과**. 세션/작업을 나눠 동시 진행 (영상 04:50 "여러 세션을 돌려서 열 편을 같은 시간에")
- C가 도는 동안 → D의 웹사이트 카피·브랜드 문구를 미리 확정
- E의 DNS 전파 대기 시간 동안 → F의 리드 수집 시작

### 3-4. 3시간 안에 **하지 않을 것** (의도적 범위 축소)
| 제외 항목 | 이유 |
|-----------|------|
| 리드 200개 | 60~100개면 1주차 발송량으로 충분. 개수보다 필터 정확도가 중요 |
| 대량 자동발송 | 도메인 워밍업 원칙 위반 + 도구상 불가 |
| 결함 영상 수정(글자 깨짐/손) | 재생성 비용·시간 초과. 해당 컷을 **빼는 것**으로 대체 |
| 사업자등록·계약서·결제수단 | 첫 회신이 온 뒤에 해도 늦지 않음 |

## 4. 단계별 실행 사양

### A. 니치 결정 (T+00~15) — 여기서 승부의 70%가 결정됨
영상은 "가상의 제품 4개"로 포트폴리오를 만들었지만, **포트폴리오는 타깃 니치와 일치해야 전환됩니다.**
→ 먼저 F단계 타깃을 정하고, 그 타깃과 같은 카테고리로 포트폴리오를 만드는 **역순 설계**를 권장합니다.

권장 조합 (택 1):
- **(가) Amazon/Shopify 셀러 니치** — 예: 홈·키친 가전. 포트폴리오 4편 = 해당 카테고리 제품 광고 4편
- **(나) 로컬 SMB 니치** — 예: 산타모니카 레스토랑/짐. 영상의 폭립 바베큐·비스트짐이 이 케이스
- **(다) Kickstarter 니치** — 예: 여행 가젯. 영상의 압축 백팩이 이 케이스

3시간이라면 **(가) 또는 (다) 단일 니치**를 권장합니다. (나)는 지역 특화라 통화·시차 대응 부담이 큽니다.

### C. 영상 프롬프트 규격 (영상 02:39 vs 03:11 실패/성공 대조에서 도출)
```
[브랜드명]의 [구체 제품명]을 위한 [매체: TV광고 / 킥스타터 캠페인 / 아마존 리스팅]용
15초 모션 디자인 광고 영상. [핵심 셀링포인트 1개]를 시각적으로 강조.
[톤: 프리미엄 / 활기찬 / 미니멀]. 텍스트 오버레이 최소화.
```
- 텍스트 오버레이 최소화 = 영상에서 발견된 **글자 깨짐 결함**의 사전 회피책
- 인물 클로즈업 회피 = **손 왜곡 결함**의 사전 회피책

### D. 웹사이트 (영상 05:13~06:50의 교훈)
- **핵심 원칙: "우린 비주얼을 파는 회사인데 사이트가 허접하면 아무도 돈을 안 낸다"** (05:37)
- 필수 섹션: Hero / 포트폴리오 4편 / 가격 / 소개 / 문의 CTA
- 함정: 레퍼런스 사이트를 그대로 쓰면 **웹 제작사처럼 보이는 포트폴리오**가 박힘 (영상 06:08에서 실제 발생). 포트폴리오 자리는 반드시 **우리 영상 4편**으로 교체
- 브랜드명: 영상은 미국식 인명 조합(예: CCCA)을 택함. 도메인 확보 가능 여부와 동시에 검토

### G. 콜드메일 필수 요소 (CAN-SPAM)
1. 발신자 신원·실제 주소 명기
2. 수신거부(unsubscribe) 링크
3. 오해 소지 있는 제목 금지
4. (권장) 첫 메일에 포트폴리오 영상 **링크** — 첨부는 스팸 점수 상승

## 6. 리스크 및 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 크레딧 0 → 영상 생성 실패 | **치명 (전 단계 정지)** | T+15 이전에 반드시 충전 |

| 영상 결함(글자·손) | 포트폴리오 신뢰도 하락 | 프롬프트 사전 회피 + 결함 컷 제외 |
| 콜드메일 스팸함 직행 | 전환율 0 | 도메인 워밍업 (1일차 5통) 엄수 |
| Google Maps 스크래핑 | 서비스 약관 이슈 소지 | 공개된 사업체 연락처 위주, 대량 자동수집 지양 |
| 한국 이메일 규제 | 국내 발송 시 **정보통신망법상 사전 동의(옵트인) 필요** | **타깃을 미국 SMB로 한정**하면 CAN-SPAM(옵트아웃) 체계 적용 |
| 수주 후 납기 불이행 | 환불·평판 손상 | 첫 주 수주는 **주 3건 이하**로 제한 |

> ⚠️ 한국과 미국의 상업메일 규제는 정반대에 가깝습니다. 한국은 사전 동의(옵트인)가 원칙이라 이 영상 방식(무동의 콜드메일)을 국내 대상으로 그대로 하면 문제가 됩니다. **미국 타깃으로 가는 것이 규제상으로도 맞습니다.**
