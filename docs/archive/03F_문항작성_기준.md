# 문항 작성 기준 (확정) — 라이트·유쾌·강제선택

> 기존 후보(03D·03E)는 **너무 헤비하고 부정적**이라 폐기. 이 문서 기준으로 전면 재작성한다.

---

## 1. 형식 확정

| 형식 | 비중 | 용도 |
|---|---|---|
| **4택 「딱 하나만」** | 14문항 중 9~10개 | 주력. 축을 정확히 측정 |
| **2택 밸런스 게임** | 4~5개 | 리듬 전환. 3초컷. 결과 화면에서 공유 카드로 재활용 |

### 왜 강제선택인가
`"이 중 딱 하나만 가능하다면?"`은 밸런스 게임의 구조인 동시에, 심리측정에서 **사회적 바람직성 편향을 줄이는 검증된 기법**이다. 넷 다 좋아 보이는데 하나만 골라야 하므로 진짜 선호가 나온다. **재미 있는 형식이 오히려 더 정확한** 드문 경우다.

---

## 2. 톤 규칙 (엄수)

### 해야 할 것
- **긍정적이거나 중립적인 상황**만 사용
- `딱 하나만 고른다면` / `둘 중에 하나만` / `이 중에 제일` 프레임
- 답하면서 `"오 이건 고민되는데"` 소리가 나오게
- 선택지에 현실적 디테일과 유머

### 하지 말아야 할 것
- ✗ 다툼·갈등 직후 상황 (`다투고 하루가 지났는데 연락이 없다`)
- ✗ 불안 자극 상황 (`읽음만 뜨고 1시간째 답이 없다`)
- ✗ 서운함·자책·의심을 전제한 장면
- ✗ 상대를 나쁘게 상상하게 만드는 설정
- ✗ 정도 차이 선택지 (`자주 / 가끔 / 드물게`)

**원칙**: 유저가 설문을 마쳤을 때 기분이 **좋아져 있어야 한다.** 우리 타깃은 아직 사이가 좋은 초기 커플이다.

---

## 2-1. 인지부하 규칙 (최우선)

강제선택은 편향을 줄이지만 **인지부하를 올린다.** 이 트레이드오프를 반드시 관리해야 한다.

> **`어떻게 할래?`(설계) 대신 `어떻게 돼?`(반응)를 물어라.**

| ✗ 설계형 — 부하 높음 | ○ 반응형 — 부하 낮음 |
|---|---|
| 커플 규칙 딱 하나만 만든다면? | 상대가 프사를 커플 사진으로 바꿨다. 나는? |
| "싸우면 이렇게 하자" 룰을 정한다면? | 상대가 먼저 "아까 내가 좀 예민했지" 톡이 왔다. 나는? |
| 이상적인 연락 빈도는? | 자고 일어났더니 상대 톡이 12개 와 있다. 나는? |

**설계형이 무거운 이유** — 미래를 상상하고 4개를 서로 저울질해야 한다. **반응형이 가벼운 이유** — 이미 겪어본 장면이라 답이 몸에서 바로 나온다.

`딱 하나만 고른다면` 프레임은 **제2장(원하는 것)에만** 쓴다. 나머지 축은 전부 반응형 장면으로 간다.

### 선택지 길이 규칙
- **12자 내외.** 한 줄에 안 들어가면 부하가 커진다
- **괄호 설명 금지** — `일주일에 하루는 각자의 날(연락도 최소한으로)` 같은 형태 금지
- 읽는 순간 무슨 뜻인지 알아야 한다. 두 번 읽게 만들면 실패

## 2-2. 제2장 전용 규칙 — 선택지는 「상대가 하는 행동」

제2장(B1·B2·B3)의 선택지는 **전부 상대가 실제로 할 수 있는 행동**으로 쓴다. 내 감정·가치관·성향이 아니다.

- ✗ `나는 안정감을 중요하게 생각한다` → 상대가 뭘 해야 할지 모른다
- ○ `자기 전에 "오늘 어땠어" 물어봐줄 때` → 상대가 내일 바로 할 수 있다

이러면 **답안지 조건이 자동으로 충족된다.** 유저가 고른 선택지가 곧 상대가 하면 되는 행동이기 때문이다. 그리고 리포트 제9장 `이렇게 해봐`에 그 문장을 **그대로 옮겨 적을 수 있다.**

유저가 결과를 읽고 이렇게 느껴야 한다 — `"아, 내가 이렇게 하면 얘가 사랑받는다고 느끼는구나."`

---

## 3. 판별 기준 — 재미만 있고 축이 없는 문항을 걸러내는 법

> **선택지 4개가 서로 다른 「관계 스타일의 사람」을 그려야 한다.**

- ✗ `데이트 중 비가 온다` → 뛴다 / 우산 산다 / 비 맞으며 걷는다
  → 재밌지만 셋 사이에 **연애적 의미 차이가 없다.** 그냥 취향이다. **탈락.**
- ○ `커플 규칙 딱 하나만 만들 수 있다면?` → 자기 전 5분 통화 / 주 1회 각자의 날 / 싸우면 그날 안에 / 서로 폰 안 보기
  → 네 사람이 **완전히 다른 연애를 한다.** 통과.

각 후보마다 이 질문에 답할 것: **"이 선택지를 고른 네 사람을 서로 다른 인물로 묘사할 수 있는가?"**

## 4. 애착 2차원 채점 (필수)

모든 선택지에 **`불안 점수`와 `회피 점수`**를 부여한다. 범위는 `−1 ~ +2`.

```
          회피 낮음      회피 높음
불안 낮음    안정형        회피형
불안 높음    불안형        혼란형
```

**예시**

| 문항 | 선택지 | 불안 | 회피 |
|---|---|---|---|
| 커플 규칙 딱 하나만 | 자기 전 5분 통화는 무조건 | **+2** | 0 |
| 〃 | 일주일에 하루는 각자의 날 | 0 | **+2** |
| 〃 | 싸우면 그날 안에 풀기 | +1 | −1 |
| 〃 | 서로 폰은 절대 안 보기 | 0 | +1 |
| 프사가 커플 사진으로 바뀜 | 나도 바로 바꾼다 | +1 | −1 |
| 〃 | 귀엽네 하고 둔다 | 0 | 0 |
| 〃 | 솔직히 살짝 부담 | 0 | **+2** |
| 〃 | 친구들 반응이 궁금 | +1 | 0 |

### 장별 애착 근거 배분 (목표)
| 입력 장 | 불안 근거 | 회피 근거 |
|---|---|---|
| 제1장 우리 사이 (4문항) | 2 | 2 |
| 제2장 내가 바라는 것 (3문항) | 1 | 2 |
| 제4장 🔞 (3문항) | 1 | 1 |
| 제3장 예측 · 제5장 열린질문 | — | — (해석 보조만) |

**애착을 한 장에 몰지 않는다.** 몰면 유저가 의도를 알아채고 답을 꾸민다. 흩어놓으면 결과에서 애착 유형이 나오는 순간 `"이걸 어떻게 알았지"` 충격이 발생하고, 이게 최대 결제 트리거가 된다.

## 5. 축 체계 (03C 문서 유지)

| 장 | 축 | 무엇을 재는가 |
|---|---|---|
| 1 | **A1 불확실성 대응** | 확실한 걸 좋아하나, 여지를 좋아하나 |
| 1 | **A2 갈등 처리 타이밍** | 문제를 즉시 다루나, 시간을 두나 |
| 1 | **A3 애정 수신 채널** | 언제 사랑받는다고 느끼나 |
| 1 | **A4 거리 조절 욕구** | 붙어 있고 싶나, 혼자 시간이 필요하나 |
| 2 | **B1 설렘 트리거** | 정확히 어떤 순간에 심쿵하나 |
| 2 | **B2 원하는 케어** | 힘 빠질 때 뭘 해주길 바라나 |
| 2 | **B3 표현 개방성** | 속마음을 얼마나, 어떻게 내보이나 |
| 4 | **C1 진도 속도관** | 관계 진전을 어떤 속도로 원하나 |
| 4 | **C2 신호 방식** | 어떻게 티를 내고 어떻게 읽나 |
| 4 | **C3 여운·애프터** | 그 다음에 무엇을 원하나 |

**중요** — A2(갈등)조차 부정적 장면으로 묻지 않는다. `싸웠을 때`가 아니라 **`우리가 만약 싸운다면 어떤 규칙이 좋을까`** 처럼 가정형·규칙형으로 물어 톤을 가볍게 유지한다.

## 6. 각 후보에 붙일 항목

```
### A1-1 · [제목]  |  형식: 4택 / 2택

**질문**: (긍정·중립 상황의 강제선택 문장)

| 선택지 | 내용 | 유형 라벨 | 불안 | 회피 |
|---|---|---|---|---|
| A | ... | ... | +2 | 0 |
| B | ... | ... | 0 | +2 |
| C | ... | ... | +1 | -1 |
| D | ... | ... | 0 | +1 |

**네 사람 묘사**: 각 선택지를 고른 사람이 서로 다른 인물인지 한 줄씩 (판별 기준 통과 증명)
**축 순수도**: 이 문항이 해당 축만 재는 이유
**예상 응답 분포**: A/B/C/D % + 쏠림 자가점검
**교차 추론 예시**: "이 문항 X + 다른 축 Y → 이런 결론" 1개
**재미 포인트**: 왜 유쾌한지 한 줄
**추천도**: ◎ / ○ / △
```
