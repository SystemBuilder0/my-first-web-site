## 0. 제품 한 줄 정의

**"우리, 서로를 얼마나 알고 있을까"** — 커플이 6~8분 안에 함께 끝내는 상호 이해 진단.
점술이 아니라 **실용 관계 콘텐츠**이며, 진행자는 무당이 아니라 **현대 연애상담소의 '언니'**다.

**타깃 (확정)** — **서로 호감이 있고 알아가는 중인 초기 커플.** 썸 단계에 국한하지 않는다.
`썸` ~ `연애 100일 미만`을 아우르되 무게중심은 **초기 커플**에 둔다. 이 단계는 서로를 가장 모르고, 가장 알고 싶어 하고, 불안이 가장 크다. **정보 비대칭이 최대인 구간**이므로 "상대 해독" 포지셔닝이 가장 강하게 작동한다.

호감이 확인된 사이이므로 **1폰 릴레이가 성립한다.** 갈등 대응·화해 방식 같은 문항도 "이미 겪은 일"이 아니라 **"미리 알아두면 좋은 것"**으로 기능하므로 이 타깃에서 오히려 가치가 크다.

**관계 단계 맞춤 (확정)** — 첫 화면에서 관계 단계를 받고, 그에 맞춰 문항 문구를 조정한다. 같은 축을 묻되 단계에 맞는 상황 장면으로 바꾼다.

**포지셔닝 (확정)** — `너희 궁합 몇 점?` ✗ → **`쟤가 진짜 원하는 게 뭔지 알려줄게`** ○
"궁합 진단"으로 부르는 순간 사주와 같은 링에 오르고, 우리는 입력 마찰이 더 크므로 진다. 우리가 파는 것은 관계 점수가 아니라 **내가 절대 알 수 없는 정보 = 상대의 답변**이다.

**사주 하이브리드 — 미도입 (확정).** 순수 설문형 포지셔닝을 유지한다.

**19금 블록 — 단계 무관 Yes/No 게이트 (확정).** 썸 단계에도 게이트를 동일하게 띄우고 **본인이 원하면 넣고 원하지 않으면 뺀다.** 자동으로 스킵하지 않는다.

근거 — 초기 단계일수록 이 주제가 오히려 더 재밌게 작동한다. 아직 서로의 취향을 모르는 사이라 **"어? 너 그래?"** 가 터질 여지가 가장 크고, 평소 꺼내기 어려운 대화를 대신 열어주는 것이 이 제품의 핵심 가치다. 수위는 청월당 유혹비책급으로 가되 톤은 **유쾌하고 살짝 부끄럽고 섹슈얼 텐션이 도는** 쪽이다. 무겁거나 노골적인 방향이 아니다.

**목표 UX (이 다섯 개가 성공 기준이다)**
1. 재밌었다
2. 서로를 더 이해하게 됐다
3. 평소 못 할 대화를 했다
4. 의외의 모습을 알게 됐다
5. 내가 얼마나 오해하고 있었는지 알게 됐다

## 1. 핵심 설계 원리

### 1-1. 문항 수는 "커플 합산 시간"으로 본다

일반 심리테스트의 "10문항 넘으면 이탈" 기준을 그대로 쓰면 우리 제품은 **과소설계**된다.

- 이탈은 총량이 아니라 **"끝이 보이는가"의 함수**다. 첫 3문항에서 가장 크게 터지고, 그 다음은 끝이 안 보일 때 급증한다. 청월당이 장(章)으로 끊는 이유가 이것이다.
- 커플 제품은 **사회적 커밋먼트**가 걸린다. 릴레이 모드는 상대가 옆에서 보고 있어 중도 포기가 사실상 어렵다.
- 대신 진짜 병목은 따로 있다 — **두 사람이 각각 하므로 실질 부담은 `문항수 × 2`.**

→ **목표: 1인 3~4분 / 커플 합산 6~8분. 총 14문항.**

### 1-2. 이상형 문항은 "해답지"여야 한다

제2장은 단순 이상형 유형론이 아니다. 답변이 **상대에게 해답지로 작동**해야 한다.
상대가 그 답을 읽고 `"아, 이렇게 하면 얘가 좋아하겠구나"`를 알 수 있어야 한다.

`내가 뭘 원하는지` → **`내가 당신에게 뭘 원하는지`**가 드러나는 형태로 설계한다.
이 블록이 유료 구간 최대 자산이며, 결제 후 **제7장 "상대 사용설명서"**로 회수된다.

## 2. 문항 구성 (확정)

```
제1장  데이트·애정표현·대화·갈등 (통합)   4문항   ← 워밍업 + 관계 운영
제2장  이상형·내가 원하는 것             3문항   ← 상대에게 '해답지'가 되는 문항
제3장  상대 예측                        3문항   ← 맞추기 게임
제4장  🔞 은밀한 궁합                    3문항   ← Yes/No 게이트
제5장  열린 질문                        1문항   ← 자유 서술, 긍정 방향
─────────────────────────────────────────────
                                      총 14문항
```

**삭제한 블록 — 가치관·미래**: 목표 UX 5개 중 어디에도 직접 기여하지 않으면서 문항 예산만 소모한다. 결혼 준비 커플용은 추후 **유료 확장팩**으로 분리한다(청월당 `추가질문` 구조).

**배치 원칙 — 몰입 계단형**: `가벼움 → 중간 → 예측 → 🔞 게이트 → 열린 질문`
이탈이 가장 큰 첫 3문항을 가장 가벼운 것으로 채운다. 예측 문항은 자기 응답을 전부 마친 뒤에 오므로 답하기 쉽고 재미만 남는다. **🔞 게이트를 예측 뒤로 미루는 이유** — 게이트 도달 시점의 누적 투자가 7문항에서 10문항으로 늘어나고, 직전 블록이 가장 재미있는 예측 게임이라 몰입도가 최고조인 상태에서 Yes를 묻게 된다. 전환율이 구조적으로 높아지는 배치다.

**19금 No 선택 시** — 필수 10문항에 19금 3이 포함되므로 No를 고르면 7문항만 응답하고 점수판 ④가 산출되지 않는다. 이를 **2차 전환 지점**으로 쓴다. 결과 화면에 ④를 "미측정"으로 노출하고 `"지금이라도 열어볼래? 3문항이면 돼"` 재유도 버튼을 배치.

## 3. 전략 ① — 진입장벽 (입력단)

청월당은 생년월일만 넣으면 끝난다. 우리는 설문을 시킨다. 이 격차를 메우는 8개 장치.

1. **결과를 먼저 보여준다** — 진입 즉시 궁합점수 게이지가 `?점`으로 돌아가는 티저 (청월당 "시작하기" 자리)
2. **1화면 1행동, 폼 없음.** 버튼 문구는 사용자 대사 (`"좋아, 시작해볼게"`) — 청월당 `"좋아, 내 이름은..."` 문법
3. **입력 정보 최소화** — 사주가 아니므로 **생년월일 불필요**. 이름 + 사귄 기간 슬라이더면 끝
4. **진행률 바 대신 장(章) 표기** — `제2장 이상형 · 2/3`. 남은 분량이 아니라 진행한 이야기로 느끼게
5. **장 사이 중간 피드백** — 매 장 끝에 한 줄. 청월당이 장마다 게이지를 던지는 원리를 입력단으로 이식
6. **19금 게이트는 제3장(예측) 이후** — 이미 10문항을 투자했고 직전이 가장 재미있는 예측 게임이라 Yes 전환율이 높다. `"이 다음은 좀 야한데, 열까?"` / No 눌러도 손해 없음 명시
7. **이상형 서술 부담 분할** — 태그 선택(필수) + 자유 한 줄(선택). 텍스트 강제 없음
8. **중도 이탈 시 "이어서 하기" 링크** 카톡 발송

### 하이브리드 진입 (첫 화면 분기)

- **같이 있어요 (1폰 릴레이)** — A 14문항 → `"이제 폰 넘겨. 훔쳐보기 금지."` 전환 화면(A 답변 가림) → B 14문항 → 즉시 결과
  → **완주율이 가장 높은 모드이므로 기본 추천으로 배치**
- **따로 있어요 (링크)** — A 완료 → 카톡 링크 → B 완료 시 A에게 알림
  → **B 미응답 방어**: A에게 먼저 "내가 보는 우리" 단독 리포트를 열어주고, B 완료 시 싱크로율 파트가 언락되는 구조

## 4. 전략 ② — 무료 / 블러 절단선

### 점수판 구조

| 점수판 | 원천 | 상태 |
|---|---|---|
| **총 궁합점수** | 전체 | 🔒 **블러** — 가장 궁금한 숫자이므로 결제 후에만 |
| ① 싱크로율 (예측 적중률) | 예측 3문항 | **공개** |
| ② 관계운영 궁합 | 통합 4문항 | **공개** |
| ③ 로망 싱크 | 이상형 3문항 | 🔒 **블러** |
| ④ 🔞 은밀한 궁합 | 19금 3문항 | 🔒 **블러** |

### 무료 공개
- 점수판 ①② 정확한 점수와 해설
- 데이트·대화·갈등(통합 블록) 결과 — 가볍고 안전한 영역
- 서로의 열린 질문 답변 (긍정적 서술이므로 기분 좋게 마무리)
- **마지막에 "가장 크게 어긋난 문항 1개" 전문 공개** ← 결제 트리거

### 블러 처리
- **총 궁합점수** — 최상단 대형 게이지가 `?점`인 채로 남는다. 진입 티저에서 `?점`으로 돌던 게이지가 결과 화면에서도 여전히 `?점`이면 궁금증이 닫히지 않는다 (청월당 오방기 `한 번 뽑은 깃발은 되돌릴 수 없어`와 같은 구조)
- 점수판 ③④는 숫자 자리에 🔒, 게이지는 회색
- 이상형·로망 장, 🔞 장 전체 블러 — **제목은 노출**(청월당 방식)

### 절단선의 원칙
> 무료 구간은 **"우리 이만큼 어긋났네"라는 문제 인식**까지만 준다.
> **해답과 은밀한 정보**는 전부 유료에 둔다.

**결제 유도 카피 방향**
> 결제하면 — 상대가 숨겨둔 **로망·판타지·이상형**과 **🔞 은밀한 온도차**를 볼 수 있고, 방금 본 **어긋난 지점들의 해법**을 받는다. 그리고 **총 궁합점수**가 열린다.

### 총점 블러의 부수효과와 대응
총점을 잠그면 무료 구간에서 공유될 숫자가 사라진다. 그래서 **공유 카드의 주인공을 총점 → 싱크로율로 이동**한다. `"우리 싱크로율 67%"`도 충분히 공유되는 숫자다. 총점은 결제 후 공유 카드가 담당한다.

## 5. 전략 ③ — 결제 및 결제 후

### 결제 화면 — 단일가 5,900원

청월당은 37,400원이라 3택 앵커링이 작동하지만, 5,900원에서는 금액차가 작아 앵커 효과가 약한 반면 **결정 피로만 늘어난다.** 결제 UI 문법은 전부 가져오되 **상품 선택지는 없앤다.**

- 선택지 없이 **한 버튼** — 하단 고정, 금액 박기 `5,900원 결제하기`
- 정가 취소선 + `%` 뱃지 + `얼리버드 -3,000원` 을 금액 내역에 한 줄 명시
- 간편결제 4종(카카오·네이버·토스·일반), **토스페이에만 `2%할인` 뱃지**로 수단 유도
- 동의 체크 **기본 체크 상태**
- **비회원 결제 기본.** 회원가입 강제 금지 — 여기서 이탈시키면 앞의 설계가 전부 무의미
- 업셀은 결제 화면이 아니라 **리포트 완독 후**에 제안

### 결제 후 — 하이브리드 (장 스크롤 + 카드 덱)

각 장 = `상단 점수 게이지 + 시각화 + 해설 + 캐릭터 컷`. 점수를 미끼로 스크롤을 계속 끈다.

| 장 | 내용 | 시각화 |
|---|---|---|
| 1 | **총평 — 총 궁합점수 공개** | 대형 게이지(잠금 해제 연출) + 4개 점수판 타일 |
| 2 | 싱크로율 — 너희는 서로를 얼마나 알고 있나 | 예측 3문항 적중/오답 대조 |
| 3 | 관계운영 (데이트·애정표현·대화·갈등) | 레이더 2개 대조 |
| 4 | 로망 싱크 — 서로가 원한 것 | 이상형 답변 나란히 대조 |
| 5 | 🔞 은밀한 온도차 | 온도 게이지 (Yes 선택자만) |
| 6 | 가장 어긋난 TOP3 + **각각의 해법** | 순위 카드 |
| 7 | **상대 사용설명서** — `이렇게 하면 좋아한다` | 해답지 카드 |
| 8 | **오늘 밤 나눠볼 질문 12** | **인터랙티브 카드 덱** |
| 9 | 언니의 편지 | — |

- **제1장 총점 공개는 연출 포인트다.** 무료에서 `?점`이던 게이지가 잠금 해제되며 채워지는 애니메이션으로 시작 — 결제 직후 만족감을 최대화하는 자리.
- **제7장이 이 제품의 진짜 상품이다.** 제2장 문항의 "해답지" 설계 원칙이 여기서 결과물로 회수된다.
- 각 장 상단에 업셀 배너 반복 삽입 (청월당 빨간 배너 위치)
- 결과는 **고유 URL로 재열람 가능** — 리포트는 한 번 읽고 닫지만 **카드 덱은 다음 데이트에 다시 열린다.** 재구매·바이럴 근거가 여기서 나온다.

## 6. 해석 생성 아키텍처 — 얕은 3문항을 깊게 만드는 법

**문제**: 각 섹션이 자기 카테고리 3~4문항만 쓰면 해석이 반드시 피상적이 된다.
**해결**: 모든 섹션이 **28개 응답 전체(14문항 × 2인)를 참조**하되, **결론만 자기 렌즈로 낸다.**

### 4단계 파이프라인

**1단계 — 특성 추출**
- 객관식 12문항 → 규칙 기반 태그 변환 (`갈등:회피형`, `애정표현:언어형`, `로망:관찰추구` 등)
- 주관식 2문항(이상형 자유 한 줄 + 열린 질문) → LLM으로 키워드·정서톤·요구 유형 추출
- 예측 3문항 → `적중/빗나감` + **빗나간 방향**(과대평가 / 과소평가)

**2단계 — 3종 프로필 생성**
`A 프로필` / `B 프로필` / `관계 프로필(교차)`
관계 프로필에는 **불일치 지도**가 들어간다 — 어느 영역에서, 얼마나, 어느 방향으로 어긋났는지.

**3단계 — 섹션별 생성**
각 섹션에 투입: `전체 프로필 3종` + `해당 섹션의 렌즈` + `이미 사용된 결론 목록`

| 섹션 | 주 데이터 | 반드시 교차 참조할 것 |
|---|---|---|
| 싱크로율 | 예측 3문항 | 빗나간 예측이 **어느 영역**인지 → 오해의 구조 |
| 관계운영 궁합 | 통합 4문항 | 로망 문항(원하는 방식 vs 현재 방식의 격차), 주관식 어휘의 온도, 예측 정확도(=상대를 읽는 능력) |
| 로망 싱크 | 이상형 3문항 | 갈등 대응 방식(로망이 무너지는 지점), 19금 응답(친밀 로망과의 정합), 열린 질문 서술 |
| 🔞 온도차 | 19금 3문항 | 애정표현 방식, 로망, 대화 스타일 |
| 상대 사용설명서 | 이상형 3문항 | 통합 4문항 전부 — 로망을 **실제 상황에서의 실행 방법**으로 번역 |

**4단계 — 중복 제거 원칙**

> **같은 문항을 여러 섹션이 인용해도 되지만, 같은 결론을 두 번 말하지 않는다.**

- 섹션마다 `사용한 결론 레지스트리`를 누적하고, 다음 섹션은 같은 결론을 **주 논거로 재사용 금지**(보조 언급은 허용)
- 각 섹션은 **자기 렌즈로만 결론을 낸다** — 관계운영 섹션이 로망 데이터를 쓰더라도 결론은 반드시 "관계 운영"에 관한 것이어야 한다

**예시 — 같은 데이터, 다른 결론**

- *관계운영 섹션*: "A는 로망 문항에서 '먼저 알아채주는 것'을 골랐는데, 갈등 문항에서는 '말로 해줘야 안다'를 골랐습니다. **A는 평소엔 눈치를, 갈등 때는 말을 원합니다.** 그런데 B는 정확히 반대로 하고 있습니다."
- *로망 섹션*: (같은 로망 응답을 쓰되) "**A가 원하는 건 이벤트가 아니라 관찰입니다.** B의 예측은 이벤트 쪽으로 빗나갔습니다."

같은 응답을 근거로 쓰되 결론의 층위가 다르다. 이것이 3문항으로 9개 장을 채우면서도 반복되지 않게 하는 유일한 방법이다.

## 7. 진행자 캐릭터 — '언니'

- **포지셔닝**: 점술가 아님. 연애상담소의 솔직한 언니. 사주·운세 용어 일절 사용 금지
- **말투**: 반말 친근톤. 청월당 시아의 `"왔어? 일단 이름 먼저 말해봐."` 문법을 차용하되 신비주의 대신 **경험 많은 사람의 직설**
- **기능적 역할**: ① 입력 단계를 대화로 위장 ② 무료→유료 전환의 화자 ③ 제9장 편지로 정서적 마무리
- **필요 일러스트**: 입력단 6컷 + 무료결과 2컷 + 결제후 9컷 ≈ **17컷**
- 19금 장에서는 톤을 낮추고 컷 노출을 줄인다 — 캐릭터가 선정성을 대변하지 않게 분리
