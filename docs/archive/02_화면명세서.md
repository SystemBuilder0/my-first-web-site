# 설문형 커플 궁합 진단 — 화면명세서

> 상위 문서: `01_전략기획서.md` (모든 결정의 원천, 본 문서는 그 확정사항을 화면 단위로 구체화만 한다)
> 범위: 랜딩 진입 ~ 결제 완료 직전까지. 결제 후 리포트(제1장~제9장, 카드 덱)는 `04_리포트명세.md`(예정)가 담당.
> 기기 기준: 모바일 웹, 세로 화면 1행동 원칙
> 작성 기준일: 2026-08-05

## 0. 이 문서에서 새로 정한 것 (01과 상충 아님, 화면 설계를 위한 보완)

01 문서는 문항 "블록" 단위(제1장~제5장 카테고리, 문항 수)까지만 확정했다. 화면 단위로 쪼개려면 아래 사항이 추가로 필요했고, 이 문서에서 임의로 정했다. 추후 조정 가능한 작업용 결정이다.

| 항목 | 이 문서의 결정 | 근거 |
|---|---|---|
| 장 인앱 표기명 | 제1장 "평소 이야기" / 제2장 "이상형" / 제3장 "은밀한 얘기" / 제4장 "맞혀보기" / 제5장 "마지막 한마디" | 01의 카테고리 설명을 그대로 축약 |
| 실제 문항 텍스트 14개 | 전부 예시로 작성 (S-04, S-06, S-08, S-10, S-12) | 01엔 카테고리만 있고 문항 텍스트가 없어 화면 목업을 위해 임시 작성. **문항 확정은 별도 검증 문서(01의 9번, 구글폼 테스트) 영역** |
| 이름·기간 입력 시점 | A만 입력(같이/따로 분기 직후, 상대 이름도 A가 입력). B는 재입력 없이 A가 적은 이름으로 진행 | "입력 정보 최소화" 원칙을 B에게도 적용 |
| 문항 선택 시 전환 방식 | 선택지 탭 = 즉시 다음 문항으로 자동 전환 (별도 "다음" 버튼 없음) | "1화면 1행동, 폼 없음" 원칙의 문항 화면 적용 |
| 서비스 로고/제품명 | 미정 — 와이어프레임엔 `[서비스명]`으로 표기 | 01에 제품명 확정 없음. 임의로 이름 짓지 않음 |

## 1. 전체 화면 흐름

```
S-01 랜딩·티저
  └▶ S-02 같이/따로 분기
       └▶ S-03 기본 정보 입력 (A)
            └▶ S-04 제1장 문항(1-1~1-4, 공통템플릿)
                 └▶ S-05 장전환(1→2)
                      └▶ S-06 제2장 이상형(2-1~2-3, 공통템플릿)
                           └▶ S-07 🔞 게이트
                                ├─ Yes ─▶ S-08 제3장 19금(3-1~3-3) ─▶ S-09 장전환(3→4)
                                └─ No  ────────────────────────────▶ S-09 장전환(2→4, ④ 미측정 플래그)
                                                                          └▶ S-10 제4장 예측(4-1~4-3)
                                                                               └▶ S-11 장전환(4→5)
                                                                                    └▶ S-12 제5장 열린질문 [개인 세션 종료]

같이(릴레이) 모드                              따로(링크) 모드
S-13 폰 넘겨 전환                              S-15 링크 발송 (A)
  └▶ S-14 B 시작화면                             └▶ S-16 B 대기화면 (A)
       └▶ (B도 S-04~S-12 동일 진행)                   ├─ "기다릴게" (대기 유지)
            └▶ S-19 로딩·결과생성                      └─ "먼저 볼래" ─▶ S-17 단독리포트 진입(솔로)
                                                    (B는 별도로) S-18 B 시작화면(링크 진입)
                                                         └▶ (B도 S-04~S-12 동일 진행)
                                                              └▶ S-19 로딩·결과생성 (B 완료 트리거 시 A에게도 알림)

S-19 로딩·결과생성
  └▶ S-20 무료 결과 화면
       └▶ S-21 공유 카드 화면
            └▶ S-22 결제 화면
                 └▶ S-23 결제 완료 화면 ─▶ (04문서: 결제 후 리포트로 이동)
```

**총 화면 수: 23개** (문항 3종 템플릿은 각 3~4문항을 공통 UI로 반복 표시)

## 2. 와이어프레임 표기 범례

```
┌────────────────────────────┐
│ 상단                         │  ← 장 표기 / 뒤로가기 / 진행 정보
├────────────────────────────┤
│ 중단                         │  ← 언니 대사, 질문, 선택지, 입력 UI
├────────────────────────────┤
│ 하단                         │  ← 버튼, 보조 링크
└────────────────────────────┘
```
- 버튼 표기 `[  버튼문구  ]`는 항상 실제 사용 카피
- `※`는 이탈방지 장치 표시

## S-01 · 랜딩·티저

**맥락**: 첫 진입. 청월당의 "게이지가 도는" 티저 문법을 이식.

```
┌────────────────────────────┐
│         [서비스명]           │
├────────────────────────────┤
│                              │
│      ⟳ ??점  (게이지 회전)   │
│                              │
│   "우리, 서로 얼마나 알고     │
│      있을까?"                │
│                              │
│      [언니 캐릭터 컷]         │
│  "안녕. 나 언니야.            │
│   너네 둘, 서로 얼마나        │
│   아는지 한번 까볼까?"        │
│                              │
├────────────────────────────┤
│  [   좋아, 시작해볼게   ]     │
└────────────────────────────┘
```

**카피 전문**

| 요소 | 내용 |
|---|---|
| 헤드카피 | "우리, 서로 얼마나 알고 있을까?" |
| 언니 대사 | "안녕. 나 언니야. 너네 둘, 서로 얼마나 아는지 한번 까볼까?" |
| 게이지 | 숫자 자리에 `??` 표시, 무한 회전 애니메이션 (결과가 아직 없다는 뜻) |
| 버튼 | `좋아, 시작해볼게` |

**전환 조건**: 버튼 탭 → S-02

**이탈 방지 장치**: 결과(점수 게이지)를 진입 즉시 먼저 보여주는 티저 연출로 궁금증부터 건다 (01 문서 전략①-1).

## S-02 · 같이/따로 분기 선택

```
┌────────────────────────────┐
│         [서비스명]           │
├────────────────────────────┤
│  "자, 오늘 이거 어떻게        │
│   할래?"                     │
│  "지금 둘이 같이 있어,        │
│   아니면 따로 있어?"          │
│                              │
│  ┌──────────────────────┐  │
│  │ 같이 있어             │  │
│  │ (한 폰으로 번갈아 할게) │  │
│  │        완주율 1위 뱃지  │  │
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 따로 있어             │  │
│  │ (링크로 보낼게)        │  │
│  └──────────────────────┘  │
├────────────────────────────┤
│                              │
└────────────────────────────┘
```

**카피 전문**

| 요소 | 내용 |
|---|---|
| 언니 대사 | "자, 오늘 이거 어떻게 할래? 지금 둘이 같이 있어, 아니면 따로 있어?" |
| 선택지 A | `같이 있어 (한 폰으로 번갈아 할게)` + 뱃지 `완주율 1위` |
| 선택지 B | `따로 있어 (링크로 보낼게)` |

**전환 조건**: 카드 탭 즉시 선택 확정 → 모드값 저장(`relay` / `link`) → S-03

**이탈 방지 장치**: 첫 선택 자체가 몰입의 시작(01 문서 8번 대응표 "고민 드롭다운 5택 → 같이/따로 분기"). "같이" 모드에 완주율 1위 뱃지를 붙여 기본 추천 유도.

## S-03 · 기본 정보 입력

**맥락**: A만 입력. 생년월일 없음 — 사주가 아니므로 불필요.

```
┌────────────────────────────┐
│  ← 뒤로                     │
├────────────────────────────┤
│  "좋아. 먼저 이름부터         │
│   알려줘."                   │
│                              │
│  내 이름                     │
│  [___________]               │
│                              │
│  상대 이름                   │
│  [___________]               │
│                              │
│  "사귄 지 얼마나 됐어?"       │
│  0───●─────────10년+         │
│      2년 3개월                │
│                              │
├────────────────────────────┤
│  [   다 됐어, 다음   ]        │
└────────────────────────────┘
```

**카피 전문**

| 요소 | 내용 |
|---|---|
| 언니 대사 | "좋아. 먼저 이름부터 알려줘." |
| 입력1 라벨 | "내 이름" (placeholder: 이름) |
| 입력2 라벨 | "상대 이름" (placeholder: 이름) |
| 슬라이더 라벨 | "사귄 지 얼마나 됐어?" |
| 슬라이더 값 표시 | 드래그 중 실시간 "○년 ○개월" (0개월 ~ 10년+) |
| 버튼 | `다 됐어, 다음` |

**전환 조건**: 이름 2개 입력 + 슬라이더 조작(기본값 존재, 미조작 시에도 진행 가능) 후 버튼 탭 → S-04. 이름 미입력 시 버튼 비활성.

**이탈 방지 장치**: 입력 항목을 이름 2개 + 슬라이더 1개로 최소화(01 전략①-3). 폼이 아니라 대화형 단일 화면.

## S-04 · 제1장 문항 (공통 템플릿) — "평소 이야기" 1~4

**맥락**: 4문항 전부 동일 UI 템플릿을 쓴다. 아래는 1-1 전체 예시 + 1-2~1-4 문항 텍스트.

```
┌────────────────────────────┐
│  ← 뒤로   제1장 · 평소 이야기│
│           1 / 4              │
├────────────────────────────┤
│  "데이트 코스, 누가 짜는 게   │
│   좋아?"                     │
│                              │
│  ┌──────────────────────┐  │
│  │ 내가 짜야 마음이 편해   │  │
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 번갈아 짜면 좋겠어      │  │
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 상대가 짜주면 좋겠어    │  │
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 그때그때 즉흥이 제일 좋아│  │
│  └──────────────────────┘  │
├────────────────────────────┤
│                              │
└────────────────────────────┘
```

**장 표기 방식**: `제N장 · [장이름]` + `[현재문항] / [전체문항]`. 진행률 바(%) 대신 이 텍스트만 상단 고정. (01 전략①-4)

**1-1~1-4 카피 전문**

| 문항 | 질문 | 선택지 |
|---|---|---|
| 1-1 (데이트) | "데이트 코스, 누가 짜는 게 좋아?" | 내가 짜야 마음이 편해 / 번갈아 짜면 좋겠어 / 상대가 짜주면 좋겠어 / 그때그때 즉흥이 제일 좋아 |
| 1-2 (애정표현) | "애정표현, 어떤 쪽이 더 진심 같아?" | 말로 확실하게 해주는 거 / 스킨십으로 표현하는 거 / 챙겨주는 행동으로 아는 거 / 같이 있어주는 시간 자체 |
| 1-3 (대화) | "힘든 일 있을 때, 상대한테 바라는 건?" | 일단 다 들어줬으면 / 바로 해결책부터 같이 찾았으면 / 그냥 옆에 있어줬으면 / 웃겨서 기분 풀어줬으면 |
| 1-4 (갈등) | "싸우고 나서, 화해는 누가 먼저 걸어야 편해?" | 내가 먼저 거는 게 편해 / 상대가 먼저 걸어줬으면 / 시간 좀 두고 자연스럽게 / 그 자리에서 바로 풀어야 해 |

**전환 조건**: 선택지 탭 → 즉시 선택 저장 + 다음 문항 자동 전환 (버튼 없음). 1-4 완료 시 S-05.

**이탈 방지 장치**: 가장 가벼운 문항을 최초 배치(01 전략 "몰입 계단형" — 첫 3문항 이탈 최대 구간을 가장 가벼운 걸로 채움). 장 표기로 "남은 양"이 아니라 "진행한 이야기"로 인지시킴.

## S-06 · 제2장 이상형 문항 (공통 템플릿) — "이상형" 1~3

**맥락**: 태그 선택(필수) + 자유 한 줄(선택)로 서술 부담을 분할. 이 응답이 상대에게 "해답지"로 쓰인다(01 문서 1-2).

```
┌────────────────────────────┐
│  ← 뒤로   제2장 · 이상형     │
│           1 / 3              │
├────────────────────────────┤
│  "상대가 이렇게 해주면       │
│   진짜 좋아하는 거,          │
│   골라봐 (최대 3개)"         │
│                              │
│  (#먼저연락) (#깜짝이벤트)   │
│  (#무조건내편) (#눈치껏챙김) │
│  (#스킨십) (#같이있는시간)   │
│  (#선물) (#칭찬)             │
│                              │
│  한 줄로 더 적어볼래? (선택)  │
│  [_______________________]  │
│                              │
├────────────────────────────┤
│  [       다음       ]        │
└────────────────────────────┘
```

**2-1~2-3 카피 전문**

| 문항 | 질문 | 태그 (최대 3개 선택) |
|---|---|---|
| 2-1 | "상대가 이렇게 해주면 진짜 좋아하는 거, 골라봐 (최대 3개)" | #먼저연락 #깜짝이벤트 #무조건내편 #눈치껏챙김 #스킨십 #같이있는시간 #선물 #칭찬 |
| 2-2 | "이런 순간에 제일 설레, 골라봐 (최대 3개)" | #손잡을때 #문자할때 #안아줄때 #웃을때 #챙겨줄때 #데리러올때 #맛있는거해줄때 |
| 2-3 | "지금 제일 받고 싶은 거 하나만 골라봐" | #더많은대화 #더많은스킨십 #더많은칭찬 #더많은이벤트 #더많은시간 #더많은솔직함 (단일 선택) |

각 문항 공통: 자유 입력란 placeholder `"한 줄로 더 적어볼래? (선택)"`, 최대 50자.

**전환 조건**: 태그 최소 1개 선택 시 `다음` 버튼 활성화 → 탭하면 다음 문항. 자유 입력은 비워도 진행 가능. 2-3 완료 시 S-07.
