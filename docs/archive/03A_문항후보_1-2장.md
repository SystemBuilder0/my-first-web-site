### 1-데1 · 웨이팅 200팀

**질문**: 예약도 안 하고 간 맛집, 앱 켜보니 웨이팅 200팀. 나는 보통?

| 선택지 | 내용 |
|---|---|
| A | 바로 지도 앱 켜서 근처 다른 곳부터 찾는다 |
| B | "그래도 여기 먹으러 온 건데" 하고 웨이팅 건다 |
| C | "네가 정해" 하고 상대한테 결정 넘긴다 |
| D | "그냥 편의점 가서 컵라면 먹자" 하고 판을 엎는다 |

**특성 태그**: 돌발대처:즉각대안형 / 목표고수형 / 위임형 / 전환유쾌형
**LLM 추론 재료**:
 - 단독 추론 — 계획이 틀어졌을 때 이 사람이 감정보다 대응을 먼저 꺼내는지(A,B), 상대에게 맡기는지(C), 상황 자체를 유쾌하게 바꿔버리는지(D)를 보여준다.
 - 교차 추론 예시 — 이 문항(즉각대안형=A) + 1-갈1(갈등:즉시직면형) → "이 사람은 위기·갈등 상황 전반에서 '멈추기보다 움직이기'를 택하는 일관된 패턴이 있다. 위급할 때 든든하지만, 상대가 잠깐 멈춰서 같이 속상해해주길 바랄 때는 성急해 보일 수 있다."
**재미 포인트**: 누구나 한 번쯤 겪은 "웨이팅 대참사" 장면이라 읽자마자 자기 얘기가 나온다. 4개 반응이 실제로 커플끼리 자주 부딪히는 지점이라 웃으며 공감함.
**추천도**: ◎ — 가볍고 웃기고 부담 없어 이탈이 가장 큰 첫 문항 자리에 최적. 데이트 성향도 자연스럽게 드러남.

### 1-데2 · 데이트 전날 밤

**질문**: 데이트 전날 밤, 나는 보통 뭐 하고 있어?

| 선택지 | 내용 |
|---|---|
| A | 코스 짜서 예약 링크까지 캡처해 미리 보내놓는다 |
| B | "낼 뭐 먹지" 생각만 하다 잔다 |
| C | 상대가 짜온 계획 보고 "굿" 답장만 한다 |
| D | 웨이팅 앱, 날씨 앱까지 켜놓고 플랜 B, C를 세워둔다 |

**특성 태그**: 데이트준비:기획형 / 즉흥형 / 위임형 / 리스크관리형
**LLM 추론 재료**:
 - 단독 추론 — 데이트를 준비하는 시점(전날 밤)에서의 에너지 투입 방식을 보여준다. 계획을 짜는 사람인지, 상대에게 맡기는 사람인지가 드러남.
 - 교차 추론 예시 — 이 문항(기획형=A) + 1-대1(일상공유:실시간중계형) → "이 사람은 관계를 '미리 준비하고 채워넣는 방식'으로 운영한다. 데이트도 미리 짜고 일상도 실시간으로 공유하려는 성향이 겹치면, 상대가 계획에 없던 즉흥적 순간을 원할 때 답답하게 느낄 수 있다."
**재미 포인트**: "전날 밤에 뭐 하고 있는지"는 서로 한 번도 안 물어봤을 질문이라 답을 보는 순간 "어? 너 그러고 있었어?" 반응이 바로 나온다.
**추천도**: ○ — 무난하지만 1-데1과 함께 채택 시 "돌발상황 대처 vs 사전준비"로 결이 겹치지 않아 조합 가능. 단독 1순위감은 아님.

### 1-데3 · 3주 만의 휴일

**질문**: 3주 연속 야근하다 드디어 생긴 휴일. 상대랑 뭘 하고 싶어?

| 선택지 | 내용 |
|---|---|
| A | 집에서 아무것도 안 하고 붙어서 뒹군다 |
| B | 사람 많은 데 나가서 에너지를 받는다 |
| C | 조용한 데서 밀린 얘기부터 실컷 한다 |
| D | 몸을 움직여서 스트레스부터 확 푼다 |

**특성 태그**: 회복에너지:휴식형 / 자극형 / 교감형 / 활동형
**LLM 추론 재료**:
 - 단독 추론 — 지쳤을 때 무엇으로 회복하는 사람인지 보여준다. 이건 "평소 취향"이 아니라 "방전됐을 때의 우선순위"라 더 정직한 데이터다.
 - 교차 추론 예시 — 이 문항(휴식형=A) + 2-6(다운된 날: 존중/공간형) → "이 사람은 지쳤을 때 '같이 있되 아무것도 안 하는 것'을 원한다. 상대가 이벤트를 짜서 데려나가려 하면 오히려 방전을 가속시킬 수 있다."
**재미 포인트**: "3주 야근"이라는 구체적 피로도 설정이 공감을 확 끌어올리고, 넷 다 실제로 해봤을 법한 선택지라 몰입도가 높다.
**추천도**: ○ — 회복 방식 데이터는 유용하나 1-데1(대처)·1-데2(준비)와 함께면 데이트 카테고리 3개가 전부 채택돼 균형상 택1 필요. 후순위 대기.

### 1-애1 · 완전히 털린 날

**질문**: 회사에서 완전 털리고 온 날. 상대가 이거 하나로 스르르 풀어주면 딱인 건?

| 선택지 | 내용 |
|---|---|
| A | 말없이 꽉 안아준다 |
| B | "무슨 일인데" 하고 끝까지 캐물어 들어준다 |
| C | 저녁 뭐 먹을지 안 묻고 그냥 맛있는 걸 사온다 |
| D | 아무 말 없이 그냥 옆에 붙어서 티비를 같이 본다 |

**특성 태그**: 애정표현:접촉형 / 언어경청형 / 행동형 / 존재형
**LLM 추론 재료**:
 - 단독 추론 — 힘들 때 "사랑받는다"고 느끼는 채널이 스킨십인지, 말(경청)인지, 행동(챙김)인지, 그냥 곁에 있어주는 것인지를 규정한다. 7장 "상대 사용설명서"의 1차 재료.
 - 교차 추론 예시 — 이 문항(접촉형=A) + 1-갈1(갈등:시간필요형) → "이 사람은 싸운 뒤 말로 사과받기보다 먼저 안아주는 걸 화해 신호로 받아들인다. 상대가 '얘기 좀 하자'며 말로 다가가면 오히려 준비가 덜 됐다고 느낄 수 있다."
**재미 포인트**: "완전히 털린 날"이라는 표현 자체가 웃프게 와닿고, 넷 다 실제로 받아본/해본 위로 방식이라 자기 답을 보여주고 싶어짐.
**추천도**: ◎ — 애정표현 채널 불일치는 관계운영 궁합의 핵심축. 결과 리포트(7장) 활용도 최상.

### 1-애2 · 커플사진 찍은 다음

**질문**: 어쩌다 커플사진을 잘 건졌다. 나는 보통?

| 선택지 | 내용 |
|---|---|
| A | 바로 SNS나 프로필에 올린다 |
| B | 혼자 갤러리에 저장해두고 종종 몰래 본다 |
| C | "이거 인화해서 방에 붙이자"고 한다 |
| D | 그날그날 찍은 것도 금방 잊어버린다 |

**특성 태그**: 애정표현:과시형 / 내적소중형 / 기록형 / 무심형
**LLM 추론 재료**:
 - 단독 추론 — 관계를 "드러내고 싶은지" "혼자 간직하고 싶은지"를 보여준다. 공개 연애 성향, SNS 온도차의 원천 데이터.
 - 교차 추론 예시 — 이 문항(과시형=A) + 2-1(설렘: 공개석상 편들기형) → "이 사람은 관계를 공개적으로 드러내는 것 자체가 애정 표현이다. 친구들 앞에서 손 한 번 잡아주거나 자랑해주는 게 실제로 이 사람에게는 큰 의미가 있다."
**재미 포인트**: 커플사진 찍고 나서의 반응 차이는 실제로 다들 겪어본 미묘한 온도차라 "어 나 완전 D인데" 하고 바로 웃음이 나옴.
**⚠️ 지뢰**: D(금방 잊어버린다)를 고르면 사진에 진심인 상대가 서운해할 수 있음. 다만 이 정도 자기인식은 목표 UX 5번에 부합해 허용 범위.
**추천도**: ○ — 공개 애정표현 축은 유용하나 1-애1(위로 채널)만큼 즉각적 재미는 약함. 조합 시 1-애1과 함께면 정보 중복 없이 보완적.

### 1-애3 · 영화관 나란히

**질문**: 영화관에 나란히 앉았다. 나는 보통?

| 선택지 | 내용 |
|---|---|
| A | 자연스럽게 팔 두르거나 손부터 잡는다 |
| B | 상대가 먼저 다가오길 은근히 기다린다 |
| C | 스킨십보다 시작 전까지 계속 소곤소곤 떠들고 싶다 |
| D | 팝콘 확보가 먼저다, 스킨십은 딱히 신경 안 쓴다 |

**특성 태그**: 스킨십주도:주도형 / 수용형 / 언어우선형 / 무심형
**LLM 추론 재료**:
 - 단독 추론 — 스킨십을 먼저 거는 쪽인지 기다리는 쪽인지가 드러나며, 두 사람 다 B(수용형)면 실제로는 아무도 안 다가가고 있다는 뜻이 됨.
 - 교차 추론 예시 — 이 문항(수용형=B) + 1-애1(애정표현:접촉형) → "이 사람은 스킨십으로 사랑받는다고 느끼면서도 정작 먼저 다가가지는 않는다. 상대도 같은 유형(수용형)이면 둘 다 기다리기만 하다가 정작 원하는 스킨십 빈도에 못 미치는 상황이 반복될 수 있다."
**재미 포인트**: "팝콘 확보가 먼저다"라는 D는 특히 웃음 포인트 — 로맨스보다 팝콘이라는 솔직한 답이 실소를 유발함.
**⚠️ 지뢰**: D를 고르면 스킨십에 적극적인 상대가 "나한테 관심 없나" 오해할 수 있음. 결과 해설에서 "무심함이 아니라 표현 방식 차이"로 완충 필요.
**추천도**: ○ — 재미는 확실하나 스킨십 주도권 축은 향후 19금 장(주도권 문항)과 겹칠 가능성이 있어 두 장 배치를 함께 확정할 때 중복 점검 필요.

### 1-대1 · 편의점 계산 실수

**질문**: 편의점에서 계산이 잘못됐다. 완전 별거 아닌 일인데, 나는 상대한테?

| 선택지 | 내용 |
|---|---|
| A | 바로 사진 찍어서 톡으로 실시간 중계한다 |
| B | "만나면 얘기해야지" 하고 아껴둔다 |
| C | 물어보면 그제서야 "아 맞다 그거" 하고 꺼낸다 |
| D | 별거 아니라서 말할 생각도 안 한다 |

**특성 태그**: 일상공유:실시간중계형 / 아낌형 / 질문응답형 / 비공유형
**LLM 추론 재료**:
 - 단독 추론 — 사소한 일상을 공유하는 총량과 타이밍을 규정한다. 대화량 격차는 실제 오해의 가장 흔한 뿌리다.
 - 교차 추론 예시 — 이 문항(비공유형=D) + 1-갈2(억누름형) → "이 사람은 사소한 일도 잘 안 꺼내고, 속상한 것도 잘 안 꺼낸다. 두 축이 겹치면 상대는 '얘가 무슨 생각 하는지 모르겠다'는 답답함을 지속적으로 느낄 수 있다 — 이건 갈등이 아니라 원래 과묵한 사람이라는 뜻이다."
**재미 포인트**: "편의점 계산 실수"라는 지극히 사소한 소재라 오히려 현실감이 확 살고, 커플 각자의 실시간 공유 습관이 웃기게 대조됨.
**추천도**: ○ — 일상공유량 축은 중요하나 1-대2(벤팅 반응)이 파급력이 더 큼. 함께 채택 시 대화 카테고리가 두터워지는 조합.

### 1-대2 · 열받은 얘기 시작할 때

**질문**: 나 회사에서 열받은 일 얘기를 시작하면, 상대가 딱 이렇게 반응해줬으면 좋겠다.

| 선택지 | 내용 |
|---|---|
| A | "헐 진짜 너무했다" 하고 같이 욕해준다 |
| B | "그래서 어떻게 할 거야" 하고 해결책부터 찾아준다 |
| C | 일단 다 듣고 나서 "지금 위로가 필요해, 방법이 필요해?" 물어봐준다 |
| D | 얘기 듣다가 화제를 돌려서 웃긴 걸로 텐션을 풀어준다 |

**특성 태그**: 대화니즈:공감형 / 해결형 / 확인형 / 전환형
**LLM 추론 재료**:
 - 단독 추론 — 공감형 vs 해결형은 실제 다툼 원인 1순위로 꼽히는 축이다. 이 답 하나로 "위로받는 방식"이 정해진다.
 - 교차 추론 예시 — 이 문항(공감형=A) + 1-갈1(즉시직면형) → "이 사람은 감정이 상했을 때 바로 얘기해서 풀고 싶어하면서도, 그 방식은 '해결'이 아니라 '같이 화내주기'다. 상대가 즉시 논리적으로 해결책을 들이밀면 오히려 대화가 더 빨리 틀어질 수 있다."
**재미 포인트**: 누구나 겪어본 "말했더니 해결책만 던지는 상대" 상황을 정면으로 다뤄서 즉시 공감 폭발 지점.
**추천도**: ◎ — 실제 다툼 원인 1순위 축이면서 결과 리포트의 "오해의 구조" 섹션(6장)에 바로 연결되는 최적 후보.

### 1-대3 · 드라이브 중 정적

**질문**: 롱드라이브 중에 갑자기 정적이 흐른다. 나는?

| 선택지 | 내용 |
|---|---|
| A | 그 침묵이 편하다, 그냥 창밖 본다 |
| B | 못 참고 아무 말이나 꺼낸다 |
| C | 그냥 노래부터 튼다 |
| D | "우리 뭔가 얘기해야 하지 않아?" 하고 확인한다 |

**특성 태그**: 침묵반응:편안형 / 불편형 / 전환형 / 확인형
**LLM 추론 재료**:
 - 단독 추론 — 대화가 끊겨도 불안하지 않은 사람인지, 침묵 자체를 관계 이상 신호로 읽는 사람인지를 보여준다.
 - 교차 추론 예시 — 이 문항(불편형=B) + 1-대1(실시간중계형) → "이 사람은 대화의 '끊김' 자체를 견디기 힘들어하는 성향이 강하다. 일상도 실시간으로 채워야 안심하는 타입이면, 상대가 조용한 시간을 편하게 여길 때 '나한테 관심이 식었나' 오해할 수 있다."
**재미 포인트**: 롱드라이브 정적은 커플이라면 다들 겪어봤을 미묘한 순간이라 웃으며 "나 완전 B야ㅋㅋ" 하고 반응하게 됨.
**추천도**: ○ — 침묵에 대한 태도는 재미와 정보가치 둘 다 있으나 1-대2만큼 실용적 파급력(해결형 vs 공감형)은 아님.

### 1-갈1 · 방금 크게 다퉜다

**질문**: 방금 크게 다퉜다. 상대가 방문 닫고 들어가버렸다. 나는?

| 선택지 | 내용 |
|---|---|
| A | 바로 따라 들어가서 얘기하자고 한다 |
| B | 나도 일단 나가서 혼자 삭힌다 |
| C | 톡으로 "미안해, 나와줘" 먼저 보낸다 |
| D | 조용히 좋아하는 야식 시켜서 문 앞에 놔둔다 |

**특성 태그**: 갈등타이밍:즉시직면형 / 시간필요형 / 선사과형 / 행동화해형
**LLM 추론 재료**:
 - 단독 추론 — 갈등 후 재접촉까지 걸리는 시간과 방식을 규정한다. 즉시직면형과 시간필요형이 만나면 "쫓아가는 사람 vs 도망가는 사람" 구도가 매번 반복될 위험이 보임.
 - 교차 추론 예시 — 이 문항(시간필요형=B) + 1-애1(애정표현:접촉형) → "이 사람은 갈등 직후엔 혼자 있고 싶어하지만, 정작 화해의 계기는 말이 아니라 스킨십(안아주기)이다. 상대가 시간을 준 뒤 다가갈 때 '말로 사과'보다 '그냥 안아주기'가 훨씬 잘 통한다."
**재미 포인트**: 방문 닫고 들어가는 장면은 커플싸움의 클리셰라 다들 웃으며 자기 패턴을 인정하게 됨.
**추천도**: ◎ — 갈등 대응 타이밍 불일치는 실제 다툼의 가장 흔한 도화선. 6장 해석 아키텍처의 "화해 신호" 교차 예시가 정확히 이 문항에서 나온다.

### 1-갈2 · 3일째 연락이 뜸함

**질문**: 상대가 3일째 연락이 뜸하다. 바쁜 건 안다. 나는?

| 선택지 | 내용 |
|---|---|
| A | "많이 바쁘구나" 하고 티 안 내고 넘어간다 |
| B | "나 좀 서운한데" 하고 바로 톡을 보낸다 |
| C | 나도 똑같이 연락 텀을 둬본다 |
| D | 답장을 늦게 하고 단답으로 응수한다 |

**특성 태그**: 갈등표현:억누름형 / 직접표현형 / 미러링형 / 은근티형
**LLM 추론 재료**:
 - 단독 추론 — 서운함을 겉으로 드러내는지 숨기는지, 숨긴다면 소극적으로 티를 내는지 완전히 삼키는지를 구분해준다.
 - 교차 추론 예시 — 이 문항(억누름형=A) + 1-대1(비공유형) → "이 사람은 서운함도 일상도 잘 티 내지 않는 패턴이 겹친다. 상대는 '아무 문제 없나보다' 안심하겠지만 실제로는 조용히 쌓이고 있을 가능성이 있다 — 결과 리포트에서 '먼저 물어봐줘야 하는 타입'으로 짚어줘야 함."
**재미 포인트**: 연락 뜸한 3일은 거의 모든 커플이 겪는 국민 상황이라 몰입도가 높고, D(단답 응수)는 특히 "나 완전 이거임" 하고 웃게 만듦.
**추천도**: ◎ — 서운함 표현 방식은 오해가 가장 잘 발생하는 지점이며, 선택지 4개가 명확히 다른 대응 패턴을 그림.
**⚠️ 지뢰**: D(은근히 단답 응수)가 본인 얘기처럼 느껴져 상대가 뜨끔할 수 있음. 다만 자기인식 유발은 목표 UX 5번에 부합.

### 1-갈3 · 싸운 다음날

**질문**: 싸우고 나서, 상대가 먼저 이렇게 하면 나는 화가 스르르 풀린다.

| 선택지 | 내용 |
|---|---|
| A | "미안해" 한마디 |
| B | 말없이 꽉 안아준다 |
| C | 좋아하는 거 사들고 온다 |
| D | 그냥 평소처럼 아무 일 없었다는 듯 대해준다 |

**특성 태그**: 화해신호:언어형 / 접촉형 / 선물행동형 / 시간형
**LLM 추론 재료**:
 - 단독 추론 — 무엇을 "화해가 시작됐다"는 신호로 받아들이는지 규정한다. 1-애1과 짝지으면 평소 사랑받는 채널과 화해 채널이 같은지 다른지 확인 가능.
 - 교차 추론 예시 — 이 문항(언어형=A) + 1-애1(접촉형) → "이 사람은 평소엔 스킨십으로 사랑을 느끼지만, 화해할 때만큼은 '말로 된 사과'가 있어야 진짜 풀린다고 인식한다. 상대가 말없이 안아주기만 하면 '아직 사과 안 했잖아'라는 느낌이 남을 수 있다."
**재미 포인트**: "화 풀리는 스위치"를 직접 공개하는 문항이라 상대에게 치트키를 알려주는 셈 — 답을 보여주고 싶어지는 문항.
**추천도**: ○ — 1-갈1(타이밍)과 개념이 인접해 둘 다 채택하면 갈등 카테고리가 두꺼워짐. 1-갈1의 대안 또는 보완으로 고려.

# 제2장 — 이상형·내가 원하는 것 ("설레는 순간" 프레임)

**설계 원칙**: 이 제품의 핵심 블록. "이상형" 단어·프레임은 전 후보에서 배제. 정서 등록은 "설렘·두근거림"으로 1장 애정표현(안정감·사랑받음)과 명확히 구분했다. 모든 질문은 `내가 어떤 사람을 좋아하나`가 아니라 **`내가 당신에게 무엇을 원하나`**가 답 안에서 드러나도록, 상대가 그대로 따라할 수 있는 행동 단위로 설계했다.

---

### 2-1 · 친구들 앞에서

**질문**: 친구들이랑 다같이 있는 자리. 상대가 이러면 나 완전 설렘.

| 선택지 | 내용 |
|---|---|
| A | 내 말 끝나기도 전에 "얘 완전 대단해" 하고 자랑한다 |
| B | 대화 와중에도 슬쩍슬쩍 내 눈치를 살피며 챙긴다 |
| C | 나만 아는 농담을 던져서 둘만 웃게 만든다 |
| D | 그냥 옆에 붙어서 손 꼭 잡고 있어준다 |

**특성 태그**: 공개설렘:자랑형 / 관찰배려형 / 은밀교감형 / 소유확인형
**LLM 추론 재료**:
 - 단독 추론 — 공개된 자리에서 상대에게 받고 싶은 대우를 규정한다. 이건 그대로 "친구들 앞에서 이렇게 하면 됨"이라는 실행 지침이 된다.
 - 교차 추론 예시 — 이 문항(자랑형=A) + 1-애2(과시형) → "이 사람은 관계를 공개적으로 드러내고 인정받는 데서 오는 설렘이 크다. 상대가 SNS·주변 사람들 앞에서 애정을 잘 드러내지 않는 타입이면, 본인은 무심결에 넘어가는 행동이 상대에게는 채워지지 않는 결핍으로 쌓일 수 있다."
**재미 포인트**: "친구들 앞"이라는 구체적 무대 설정이 각자의 은근한 과시욕/수줍음을 드러내 웃음을 유발함.
**추천도**: ○ — 공개석상 행동지침으로 실용적이나, 사용 빈도(친구 모임)가 일상보다 낮아 3순위권.

---

### 2-2 · 야근 끝 방전

**질문**: 일주일 야근하고 완전 방전된 날. 상대가 이러면 심장이 쿵.

| 선택지 | 내용 |
|---|---|
| A | 아무 말 없이 집 앞에 와서 기다리고 있다 |
| B | "오늘 얼마나 힘들었어" 물어보고 끝까지 들어준다 |
| C | 먼저 자라고 하고 조용히 집안일을 대신 해놓는다 |
| D | "네가 젤 고생 많았어" 한마디를 건넨다 |

**특성 태그**: 설렘포인트:시간투자형 / 경청형 / 실질행동형 / 인정형
**LLM 추론 재료**:
 - 단독 추론 — 지쳤을 때 어떤 형태의 '와줌'이 설렘으로 전환되는지 보여준다. 7장 "상대 사용설명서"에서 방전된 날의 대응 매뉴얼로 그대로 쓰인다.
 - 교차 추론 예시 — 이 문항(시간투자형=A) + 1-데3(회복에너지:휴식형) → "이 사람은 지쳤을 때 '무언가를 해주는 것'보다 '그냥 옆에 있어주는 시간' 자체에서 설렘과 안정을 동시에 느낀다. 이벤트성 위로보다 조용히 곁을 지키는 쪽이 훨씬 효과적이다."
**재미 포인트**: "일주일 야근"은 직장인 커플이라면 누구나 몰입하는 설정이라 자기 답을 상대에게 바로 보여주고 싶어짐.
**추천도**: ○ — 방전 상태에서의 설렘 포인트는 실용성이 높으나, 2-6과 정서적으로 인접(둘 다 '컨디션 저하 시')해 함께 채택 시 중복 검토 필요.

---

### 2-3 · 사용설명서 한 줄

**질문**: 상대한테 나 사용설명서 한 줄 써준다면 — "나는 __하면 완전 넘어가는 사람"

| 선택지 | 내용 |
|---|---|
| A | 말 안 해도 알아서 먼저 챙겨주면 |
| B | 사소한 약속·디테일을 절대 안 잊으면 |
| C | 내가 뭘 하든 리액션을 크게 해주면 |
| D | 예고 없이 이벤트를 터뜨려주면 |

**특성 태그**: 니즈:선제대응형 / 신뢰형 / 반응형 / 서프라이즈형
**LLM 추론 재료**:
 - 단독 추론 — 질문 자체가 "당신에게 원하는 것"을 직설적으로 묻는 해답지 정공법. 결과 리포트에서 이 답을 그대로 인용해 "이렇게 하면 좋아한다" 카드를 만들 수 있다.
 - 교차 추론 예시 — 이 문항(선제대응형=A) + 1-애1(애정표현:행동형/존재형) → "이 사람은 말로 요청받는 것 자체를 부담스러워하고, 눈치껏 먼저 해주는 행동에서 사랑을 확인한다. 상대가 '말을 해야 알지'라는 방식으로 관계를 운영하면 구조적으로 어긋난다 — 이 사람에게는 '물어봐줘'가 아니라 '알아서 해줘'가 정답이다."
**재미 포인트**: "사용설명서"라는 프레임 자체가 웃기고, 넷 다 뼈 때리게 정확한 자기고백이라 스스로도 낄낄대며 고르게 됨.
**추천도**: ◎ — 01번 문서 1-2절 "해답지" 원칙에 가장 정확히 부합하는 정공법 문항.

---

### 2-4 · 설렘 태그 3개 (하이브리드)

**질문**: 요즘 나를 설레게 하는 순간, 아래에서 딱 3개만 골라줘. 그리고 제일 최근에 그랬던 순간을 한 줄로 알려줘.

**태그 풀 (3개 선택)**

| 번호 | 태그 |
|---|---|
| 1 | 예상 못한 다정함 (뜬금없는 챙김) |
| 2 | 나를 자랑스러워해주는 것 |
| 3 | 무조건 내 편을 들어주는 것 |
| 4 | 같이 있을 때의 편안함 |
| 5 | 사소한 걸 기억해뒀다가 꺼내는 것 |
| 6 | 스킨십으로 티내는 것 |
| 7 | 바쁜 와중에도 시간 내주는 것 |
| 8 | 유치하게 애정표현하는 것 (애칭, 장난) |

**자유 한 줄**: 예) "며칠 전에 내가 아무 말 안 했는데 힘든 거 눈치채고 그냥 안아줬을 때"

**특성 태그**: 설렘신호(다중) — 선택된 3개 조합 자체가 프로필이 됨 (+ 자유텍스트는 LLM으로 키워드·정서톤 추출)
**LLM 추론 재료**:
 - 단독 추론 — 단일 선택지보다 해상도가 높다. 3개 조합의 겹침·공백을 보면 "이 사람의 설렘은 한 가지 채널이 아니라 여러 축의 조합"이라는 걸 알 수 있고, 자유 한 줄은 실제 재현 가능한 구체적 행동을 제공한다.
 - 교차 추론 예시 — 이 문항(태그7 "바쁜데도 시간 내주기" 선택) + 1-데1(즉각대안형) → "이 사람에게는 데이트 계획이 틀어지는 것보다 '그럼에도 같이 있는 시간 자체를 지키려는 태도'가 더 크게 어필한다. 데이트가 틀어졌을 때 다른 곳을 찾아서라도 함께 있으려는 선택(1-데1 A)이 실제로 이 사람의 설렘 포인트와 직결된다."
**재미 포인트**: 4지선다에 지칠 때쯤 나오는 자유도 높은 문항이라 환기 효과가 있고, 3개를 고르는 과정에서 스스로도 "어 나 이런 것도 좋아했네" 재발견하게 됨.
**추천도**: ◎ — 태그 3개 + 자유서술 하이브리드 요건 충족. 다면적 설렘 신호를 한 번에 포착해 7장 완성도를 가장 크게 끌어올림.

### 2-5 · 바쁜 시기의 상대

**질문**: 상대가 시험이나 프로젝트로 진짜 바쁜 시기다. 근데 이러면 나 완전 넘어간다.

| 선택지 | 내용 |
|---|---|
| A | 바빠도 5분이라도 시간 내서 목소리 들려준다 |
| B | 바쁜 티 하나도 안 내고 하던 대로 다 챙긴다 |
| C | "오늘 진짜 못 챙겨, 대신 이거" 하고 짧은 톡+기프티콘 |
| D | "너도 바쁘니까 신경 쓰지 마" 하고 오히려 거리를 준다 |

**특성 태그**: 위기설렘:시간투자형 / 일관성형 / 효율형 / 거리존중형
**LLM 추론 재료**:
 - 단독 추론 — 상대가 바쁠 때 무엇을 기대하는지가 드러난다. D를 고른 사람은 오히려 '연락 압박'을 부담으로 느끼는 타입이라는 뜻.
 - 교차 추론 예시 — 이 문항(거리존중형=D) + 2-2(설렘포인트:시간투자형) → "평소엔 시간을 내주는 걸 설렘으로 느끼지만, 상대가 바쁠 때만큼은 오히려 부담 주지 않는 걸 더 배려로 여긴다. '평소'와 '위기 시'의 기대치가 다르다는 걸 상대가 알아야 한다 — 위기 때 연락이 뜸해도 서운함이 아니라 배려로 해석해야 하는 유형."
**재미 포인트**: "시험 기간 남친/여친"은 커플이라면 다들 겪어본 딜레마라 자기 답이 어느 유형인지 궁금해서 서로 비교하게 됨.
**추천도**: ○ — 정보가치 높지만 2-3(직설 해답지)·2-4(태그)와 결이 겹치는 부분(선제대응, 시간투자)이 있어 최종 3개 조합에서는 후순위.

### 2-6 · 컨디션 완전 바닥인 날

**질문**: 부었어, 예민해, 뭘 해도 별로인 그런 날. 상대가 이러면 오히려 더 좋아진다.

| 선택지 | 내용 |
|---|---|
| A | "오늘 무슨 일 있어?" 하고 살살 물어봐준다 |
| B | 아무 말 안 하고 하고 싶은 대로 그냥 냅둔다 |
| C | "예민해도 다 이뻐" 하고 웃으며 받아준다 |
| D | 재밌는 걸로 텐션을 끌어올리려 한다 |

**특성 태그**: 로망:관심확인형 / 공간존중형 / 무조건수용형 / 분위기전환형
**LLM 추론 재료**:
 - 단독 추론 — 최악의 컨디션에서 무엇을 원하는지는 평소 취향보다 훨씬 정직한 신호다. 이 답이 실제 위기 대응 매뉴얼이 된다.
 - 교차 추론 예시 — 이 문항(공간존중형=B) + 1-대2(대화니즈:공감형) → "평소 힘든 일을 얘기할 때는 같이 화내주고 공감해주길 바라지만, 정작 컨디션이 바닥일 때는 오히려 혼자만의 공간을 원한다. 이 둘을 구분 못 하면 상대는 '왜 위로해줘도 반응이 시큰둥하지'라고 오해할 수 있다 — '평소 모드'와 '완전 다운 모드'가 다른 사람이라는 뜻이다."
**재미 포인트**: "부었어, 예민해"라는 생생한 표현이 바로 자기 얘기처럼 느껴져 웃으며 공감하게 됨.
**추천도**: ◎ — 상대의 최악의 컨디션 대응법을 직접 알려주는 문항이라 7장 "상대 사용설명서"의 실전 가치가 가장 높음.

### 2-7 · 작은 성취를 해냈을 때

**질문**: 나 뭔가 작은 거라도 해냈을 때 (다이어트 3일 성공 같은 거). 상대 반응이 이러면 진짜 좋다.

| 선택지 | 내용 |
|---|---|
| A | 오버해서 박수 치고 축하해준다 |
| B | "거봐, 넌 원래 잘하는 애야" 하고 담담하게 인정해준다 |
| C | 작은 선물이나 이벤트로 보상해준다 |
| D | "다음엔 뭐 할 거야" 하고 같이 다음 목표를 짜준다 |

**특성 태그**: 인정욕구:오버리액션형 / 담백인정형 / 보상형 / 동반성장형
**LLM 추론 재료**:
 - 단독 추론 — 성취를 인정받고 싶은 방식이 드러난다. D를 고른 사람은 칭찬 자체보다 '함께 성장하는 파트너십'에서 설렘을 느끼는 타입.
 - 교차 추론 예시 — 이 문항(담백인정형=B) + 2-3(니즈:반응형 아님) → "이 사람은 큰 리액션보다 '원래 잘하는 애'라는 인정을 더 무겁게 받아들인다. 상대가 매번 오버해서 박수치는 스타일이면 오히려 가볍게 느껴질 수 있다 — 리액션의 크기보다 진심의 언어가 더 중요한 유형."
**재미 포인트**: "다이어트 3일 성공"처럼 다들 공감할 소소한 성취 예시라 웃으며 자기 얘기를 떠올리게 됨.
**추천도**: △ — 정보가치는 있으나 발생 빈도(성취의 순간)가 일상 대비 낮아 실전 활용도가 2-3, 2-6보다 떨어짐.

### 2-8 · 말다툼 하다가도

**질문**: 말다툼하다가 상대가 이러면, 오히려 반한다.

| 선택지 | 내용 |
|---|---|
| A | 조곤조곤 논리적으로 자기 입장을 설명한다 |
| B | "미안, 내가 잘못 생각했다" 하고 바로 인정한다 |
| C | 화내다가도 내가 삐질까봐 톤을 낮춘다 |
| D | 할 말은 끝까지 다 한다, 대신 뒤끝은 없다 |

**특성 태그**: 갈등중매력:논리형 / 쿨한인정형 / 배려절제형 / 솔직뒤끝없음형
**LLM 추론 재료**:
 - 단독 추론 — 매력을 느끼는 순간이 늘 좋을 때만은 아니라는 걸 보여준다. 갈등 중 상대의 어떤 태도가 오히려 신뢰를 강화하는지 규정.

**재미 포인트**: "싸우다가 반한다"는 역설적인 설정이라 신선하고, 다들 은근히 공감하는 지점(화내는 모습에서도 매력을 느낀 적)을 건드림.
**추천도**: △ — 흥미도는 높으나 갈등 카테고리(1장)와 정서적으로 인접해 2장의 "설렘" 톤보다는 1장에 더 가까운 인상. 배치 재검토 여지.

### 2-9 · 다른 사람이 관심 보일 때

**질문**: 다른 사람이 나한테 관심 보이는 거, 상대가 눈치챘다. 이러면 나 두근거림.

| 선택지 | 내용 |
|---|---|
| A | 티 안 내다가 슬쩍 내 손을 잡는다 |
| B | "저 사람 뭐래?" 하고 대놓고 물어본다 |
| C | 오히려 쿨하게 넘긴다, 나를 믿는다는 듯이 |
| D | 나중에 "아까 좀 신경 쓰이더라" 하고 솔직히 말해준다 |

**특성 태그**: 질투반응선호:은근소유형 / 직접확인형 / 신뢰형 / 솔직표현형
**LLM 추론 재료**:
 - 단독 추론 — 질투를 어떻게 표현해주길 원하는지가 드러난다. C를 원하는 사람은 과한 질투를 오히려 부담으로 느끼는 타입.
 - 교차 추론 예시 — 이 문항(은근소유형=A) + 1-애3(스킨십주도:수용형) → "이 사람은 평소엔 스킨십을 먼저 걸지 않지만, 질투가 섞인 순간의 스킨십(손 잡기)에는 크게 반응한다. 즉 '먼저 다가가지 않는 성향'과 '은근한 소유욕 표현을 원하는 것'은 모순이 아니라, 특정 상황(위협 신호)에서만 주도권을 넘겨받고 싶어하는 패턴으로 해석된다."
**재미 포인트**: 질투 유발 상황은 다들 은근히 좋아하면서도 티 안 내는 지점이라, 솔직하게 답을 공개하는 재미가 큼.
**추천도**: ○ — 질투/소유욕 축은 흥미롭고 정보가치도 높으나, 수위상 3장(🔞) 톤과 인접해 2장 안에서는 다소 튀는 편. 최종 3개 조합에서는 우선순위 낮음.

# 제2장 추천 3문항 조합

**추천: 2-3 · 2-6 · 2-4**

| 문항 | 각도 |
|---|---|
| **2-3** (사용설명서 한 줄) | 평상시 기본값 — "이렇게 하면 늘 좋아한다"는 일반 지침 |
