# 제1장 — 관계 운영

## A1 · 불확실성 대응

축 정의: 상대의 신호가 애매할 때(아직 다투거나 확실히 나쁜 일이 일어난 게 아닌 상태) 내 내면·행동이 어떻게 움직이는가. A2(다툰 직후)·A4(평상시 거리 욕구)와 구분하기 위해 모든 문항은 **"싸운 것도 아니고 확실한 것도 아닌, 애매한 순간"**으로만 한정했다.

### A1-1 · 데이트 D-3, 조용한 상대

**질문**: 다음 주말에 만나기로 했는데, 벌써 D-3인데 상대가 시간이나 장소 얘기를 한마디도 안 꺼낸다. 나는 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "우리 이번 주 몇 시에 볼까?" 먼저 톡을 보낸다 | 즉시확인형 |
| B | 곧 얘기하겠지 하고 내 할 일 하면서 기다린다 | 여유대기형 |
| C | 티는 안 내는데 폰을 30분에 한 번씩 본다 | 속앓이형 |
| D | 내가 코스까지 짜서 "여기 어때?" 하고 통째로 던진다 | 선제행동형 |

**축 순수도 검증**: 다툼도, 확실한 나쁜 신호도 없는 순수한 '조용함'만 다룬다. 갈등 대응(A2)이나 평소 거리 욕구(A4)와는 무관하게 "애매함을 견디는 방식"만 측정한다.
**예상 응답 분포**: A 30% / B 20% / C 25% / D 25% — A가 가장 "정상적"으로 보이지만 실제로는 C(속으로만 신경 씀)가 매우 흔한 실제 행동이라 쏠림 없이 4분할될 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 애매한 상황에서 이 사람이 외부 확인(A,D)을 하는지, 내부에서 처리(B,C)하는지가 드러난다.
 - 교차 추론 예시 — A1(속앓이형=C) + A4(밀착형) → "이 사람은 붙어 있고 싶어하는 마음이 큰데 정작 애매할 땐 티를 안 내고 혼자 삭인다. 상대가 눈치 못 채면 계속 혼자 불안해할 위험이 있다."
**재미 포인트**: "폰을 30분에 한 번씩 본다"는 누구나 찔리는 구체적 행동이라 웃으며 자기 얘기라고 인정하게 된다.
**추천도**: ◎ — 초기 커플이 가장 자주 겪는 장면이고 4개 선택지 매력·결함이 뚜렷하게 갈린다.

### A1-2 · 읽음만 뜨고 1시간

**질문**: 딱히 싸운 것도 아닌데, 톡을 보냈더니 읽음 표시만 뜨고 1시간째 답이 없다. 나는?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "바빠?" 하고 한 번 더 찔러본다 | 재확인형 |
| B | 나도 폰을 덮어두고 다른 일에 집중한다 | 전환형 |
| C | "혹시 나한테 서운한 거 있나" 하고 생각이 꼬리를 문다 | 확대해석형 |
| D | 아무렇지 않은 척 다른 얘기(사진, 짤)를 툭 보낸다 | 간접찔러보기형 |

**축 순수도 검증**: 갈등의 흔적이 없는 순수한 침묵 상황이라 A2와 겹치지 않는다. "답을 기다리는 동안의 내면"만 재므로 A4(평소 거리 욕구)와도 분리된다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — 확대해석(C)이 초기 커플 특유의 불안으로 살짝 높게 잡히나 나머지도 고르게 분포.
**LLM 추론 재료**
 - 단독 추론 — 침묵을 "사실"로 두는지(B) "의미"로 채우는지(C)가 갈린다.
 - 교차 추론 예시 — A1(확대해석형=C) + B3(완전내면형) → "이 사람은 불안할 때 생각은 커지는데 겉으로는 절대 티를 안 낸다. 상대는 아무 이상 없다고 생각하지만 실제로는 속에서 시나리오가 여러 개 돌아가고 있는 상태다."
**재미 포인트**: "생각이 꼬리를 문다"는 표현에 다들 뜨끔하며 웃게 되는 국민 공감 포인트.
**추천도**: ○ — A1-1과 상황이 유사(둘 다 침묵)해 함께 채택 시 중복. 단독 채택 시엔 좋은 대안.

### A1-3 · 답장이 평소보다 짧다

**질문**: 요 며칠, 상대 답장이 평소보다 확실히 짧다. "ㅇㅇ", "ㄱㅅ" 이런 식으로. 나는 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "나 요즘 뭐 서운하게 한 거 있어?" 하고 바로 물어본다 | 직접확인형 |
| B | 그러려니 하고 넘어간다, 원래 텀이 있는 거라 생각 | 무던형 |
| C | 내가 뭘 잘못했는지 지난 대화를 계속 복기한다 | 자기점검형 |
| D | 나도 같이 단답으로 응수해본다, 반응을 살피려고 | 미러링형 |

**축 순수도 검증**: 관계 초반의 미묘한 온도차만 다루며 실제 다툼이나 평소 거리 욕구와는 별개다. 이 문항의 초점은 '패턴 변화를 감지했을 때의 대응'뿐이다.
**예상 응답 분포**: A 20% / B 30% / C 25% / D 25% — 무던형(B)이 가장 흔한 자기방어적 반응이라 약간 높게, 나머지는 고르게.
**LLM 추론 재료**
 - 단독 추론 — 신호가 미약할 때 확인 행동을 하는지(A,D), 그냥 넘기는지(B), 내부로 침잠하는지(C)를 보여준다.
 - 교차 추론 예시 — A1(미러링형=D) + A2(즉시직면형) → "이 사람은 애매할 때도, 갈등이 터졌을 때도 상대의 반응을 거울처럼 되비추며 확인하려는 패턴이 있다. 상대가 그 의도를 못 읽으면 '왜 갑자기 태도가 바뀌었지'하고 오해할 수 있다."
**재미 포인트**: 다들 "ㅇㅇ" 하나에 오만 생각을 해본 경험이 있어 바로 공감 웃음이 터진다.
**추천도**: ○ — 좋은 장면이지만 A1-2와 결이 가까워(둘 다 텍스트 신호) 최종 조합에서는 후순위.

### A1-4 · 스토리는 올리는데 나한텐 뜸함

**질문**: 상대 SNS 스토리는 계속 올라오는데, 정작 나한테 하는 연락은 며칠째 뜸하다. 나는?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "요즘 좀 바빠?" 하고 직접 물어본다 | 즉시확인형 |
| B | "뭐 바쁜가 보다" 하고 내 할 일에 집중한다 | 무던형 |
| C | "나한테 관심 식었나" 온갖 생각이 스멀스멀 올라온다, 말은 안 함 | 혼자상상형 |
| D | 나도 스토리 올리고 은근슬쩍 먼저 톡을 건다 | 선제행동형 |

**축 순수도 검증**: 신호가 공개 채널과 사적 채널에서 어긋나는 상황에 대한 '내적 반응'만 측정한다. 다툼이 개입되지 않았고, 평소 거리 선호가 아니라 '해석'의 문제라 다른 축과 섞이지 않는다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — 공개활동과 사적연락의 괴리는 불안을 특히 자극하는 장면이라 혼자상상형(C)이 살짝 높게 나올 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 이 사람이 정보 비대칭(남들은 보는데 나는 못 받는 관심)을 견디는 방식이 드러난다.
 - 교차 추론 예시 — A1(혼자상상형=C) + A4(거리형) → "평소엔 혼자만의 공간을 좋아하면서도 상대의 신호가 애매해지면 속으로 크게 불안해하는 사람이다. 겉으로는 쿨해 보이지만 실제로는 세심한 관찰이 필요한 타입."
**재미 포인트**: SNS 스토리와 개인 연락의 괴리는 요즘 커플이라면 다들 겪는 '국룰 불안 포인트'라 몰입도가 높다.
**⚠️ 지뢰**: 이 문항이 상대의 실제 SNS 습관을 떠올리게 해 다소 예민한 반응을 부를 수 있다. 결과 해설에서 "관심이 식은 게 아니라 채널 습관 차이"로 완충 필요.
**추천도**: ○ — 재미와 정보가치 모두 좋으나 SNS라는 특정 매체에 의존해 응답자에 따라 공감도 편차가 있을 수 있음.

## A2 · 갈등 처리 타이밍

축 정의: 이미 부딪힌 **직후**에 내가 어떻게 움직이는가. B3(평소 표현 개방성)와 겹치지 않도록 모든 문항을 '방금 다퉜다'는 명확한 사건 이후로만 한정했다.

### A2-1 · 카페에서 말이 끊겼다

**질문**: 카페에서 언쟁하다가 상대가 갑자기 말을 멈추고 창밖만 본다. 그 순간 나는?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "왜, 뭔데" 하고 바로 파고든다 | 즉시직면형 |
| B | "나 화장실 좀" 하고 자리를 뜬다, 일단 서로 식힐 시간부터 | 냉각필요형 |
| C | 화제를 뚝 끊고 "우리 뭐 먹을까" 하고 딴 얘기로 넘긴다 | 봉합회피형 |
| D | 말없이 상대가 다시 입 열 때까지 기다린다 | 수동대기형 |

**축 순수도 검증**: 다툼 '직후'의 즉각 행동만 다뤄 평소 자기 표현 정도(B3)와는 별개다. 평소엔 속마음을 잘 안 터놓는 사람도 갈등 상황에서는 바로 파고드는 경우가 흔해 두 축이 실제로 갈린다.
**예상 응답 분포**: A 25% / B 25% / C 20% / D 30% — 즉석에서 대응하기보다 일단 지켜보는 D(수동대기형)가 공공장소라는 조건상 가장 흔할 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 갈등 발생 즉시 개입하려는지, 거리를 두려는지, 회피하려는지, 관망하려는지가 드러난다.
 - 교차 추론 예시 — A2(즉시직면형=A) + A1(즉시확인형) → "이 사람은 애매한 순간이든 갈등 상황이든 '멈추기보다 먼저 움직이는' 일관된 패턴이 있다. 위기에서 든든하지만 상대가 잠깐 혼자 정리할 시간이 필요할 때는 몰아붙이는 것처럼 느껴질 수 있다."
**재미 포인트**: 카페에서 다투다 정적이 흐르는 장면은 커플이라면 누구나 겪어본 클리셰라 웃으며 자기 패턴을 인정하게 된다.
**추천도**: ◎ — 장면이 선명하고 4개 선택지가 실제로 균등하게 갈릴 만한 자연스러운 반응들이다.

### A2-2 · 톡다툼 중 30분째 무응답

**질문**: 톡으로 다투다가 상대가 읽고 30분째 답이 없다. 나는?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 전화를 걸어서 "얘기 좀 하자" 한다 | 즉시직면형 |
| B | 나도 톡을 닫고 딴 일을 한다, 나중에 이어간다 | 냉각필요형 |
| C | "미안해ㅠ" 이모티콘부터 도배해서 분위기를 풀려 한다 | 즉각봉합형 |
| D | 답답해서 친구한테 하소연 톡부터 보낸다 | 외부발산형 |

**축 순수도 검증**: 사건은 명확히 '다투는 중'으로 고정돼 있어 A1(애매함)과 구분되고, 감정 표현의 방식이 아니라 대응 타이밍만 재므로 B3와도 겹치지 않는다.
**예상 응답 분포**: A 20% / B 30% / C 25% / D 25% — 텍스트 다툼은 전화보다 회피가 쉬워 냉각필요형(B)이 살짝 높게 나올 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 갈등을 즉시 봉합하려는 성향(A,C)인지 시간을 벌려는 성향(B,D)인지 규정한다.
 - 교차 추론 예시 — A2(냉각필요형=B) + A4(거리형) → "이 사람은 평소에도 혼자만의 공간을 좋아하는데 갈등 상황에서도 같은 패턴이 반복된다. 상대가 즉시 대화로 풀고 싶어하는 타입이면, '왜 답을 피하냐'는 오해가 쌓이기 쉽다."
**재미 포인트**: "친구한테 먼저 하소연"은 다들 몰래 해본 행동이라 들켰다는 듯 웃게 된다.
**추천도**: ○ — A2-1과 상황 결이 비슷(둘 다 침묵 국면)해 조합 시 A2-1 우선.

### A2-3 · 언쟁 후 귀갓길

**질문**: 저녁 먹다가 사소한 걸로 언성이 높아졌다. 밥은 다 먹었고, 이제 각자 집에 가는 길이다. 나는 보통?

| A | 헤어지기 전에 "아까 나도 예민했어, 미안" 하고 먼저 정리한다 | 즉시봉합형 |
| B | 그냥 인사만 하고 헤어진다, 집 가서 생각 정리한 뒤 연락한다 | 시간필요형 |
| C | 헤어지고 나서도 계속 신경 쓰여서 도착하자마자 장문 톡을 쓴다 | 지연폭발형 |

**축 순수도 검증**: '헤어지는 시점'이라는 고정된 장면 안에서 타이밍 반응만 비교한다. 감정을 어떻게 표현하느냐(B3)가 아니라 언제 움직이느냐만 잰다.
**예상 응답 분포**: A 20% / B 30% / C 25% / D 25% — 얼굴 맞대고 있을 때보다 헤어진 뒤 정리하고 싶어하는 시간필요형(B)이 가장 자연스러운 다수 반응일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 갈등을 그 자리에서 끝내고 싶은지, 물리적 거리가 생긴 후에야 정리가 되는지 보여준다.

**재미 포인트**: "도착하자마자 장문 톡"은 다들 한 번쯤 써본 적 있는 국민 행동이라 뜨끔하며 웃게 된다.
**추천도**: ○ — 좋은 장면이나 A2-1보다 상황이 한 단계 더 진행된(헤어진 뒤) 시점이라 즉각성이 살짝 떨어짐.

### A2-4 · 다투고 하루가 지났다

**질문**: 어제 다퉜다. 하루가 지났는데 상대에게 아직 연락이 없다. 나는 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 못 참고 내가 먼저 연락한다 | 즉시직면형 |
| B | 나도 안 한다, 먼저 연락 오길 기다린다 | 자존심대치형 |
| C | 화해 대신 그냥 평소처럼 짤이나 밈을 보낸다 | 능청봉합형 |
| D | 마음을 정리해서 장문 메시지로 보낸다 | 정리형 |

**축 순수도 검증**: '하루 지난 뒤'라는 명확한 갈등 후 시점만 다뤄 다른 축과 섞이지 않는다. 감정을 밖으로 얼마나 꺼내는지가 아니라 '누가 먼저, 언제 움직이는가'만 잰다.
**예상 응답 분포**: A 25% / B 25% / C 25% / D 25% — 자존심·성격·감정처리 방식이 고르게 갈리는 전형적인 4분할 장면.
**LLM 추론 재료**
 - 단독 추론 — 하루라는 냉각기를 거친 후에도 먼저 움직이는지, 대치하는지, 우회하는지, 정돈된 방식으로 다가가는지가 드러난다.
 - 교차 추론 예시 — A2(자존심대치형=B) + B3(완전내면형) → "이 사람은 갈등이 생기면 먼저 다가가지 않는 데다 평소에도 속마음을 잘 안 꺼낸다. 두 축이 겹치면 화해까지 시간이 오래 걸리는 커플이 될 수 있어, 둘 중 한쪽이 먼저 다가가는 규칙을 정해두는 게 실질적인 조언이 된다."
**재미 포인트**: "짤이나 밈으로 능청스럽게 화해 시도"는 실제 초기 커플이 자주 쓰는 귀여운 전략이라 웃음과 공감을 동시에 유발한다.
**추천도**: ○ — A2-1만큼 즉각적이진 않지만 '하루 뒤'라는 설정이 갈등 지속 시간을 보여줘 보완적 가치가 있다.

## A3 · 애정 수신 채널

축 정의: 평상시(위기·갈등 아님) 나는 무엇을 통해 "사랑받는다"고 느끼는가. B2(위기 시 케어)와 명확히 구분하기 위해 모든 장면을 특별할 것 없는 평범한 일상으로 고정했다. 어휘도 '설렘'이 아니라 '편안함·안심'으로 통일해 B1과 분리했다.

### A3-1 · 평범한 화요일 저녁

**질문**: 딱히 특별한 이벤트도 없는 그냥 그런 화요일 저녁. 상대가 이러면 나는 사랑받는 기분이 든다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 자기 전에 "오늘 하루 어땠어" 톡을 꼭 보낸다 | 언어관심형 |
| B | 내가 말 안 해도 좋아하는 간식을 사다 놓는다 | 행동케어형 |
| C | 나란히 있으면 자연스럽게 손을 잡거나 기댄다 | 스킨십형 |
| D | 딱히 뭘 안 해도 그냥 같이 있는 시간 자체가 많다 | 존재형 |

**축 순수도 검증**: 위기·이벤트가 전혀 없는 순수 평시 상황이라 B2(무너졌을 때)와 명확히 분리된다. '설렌다'가 아니라 '사랑받는 기분'을 물어 B1과도 다른 정서를 겨냥한다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — 국내 20~30대 커플 특성상 스킨십형(C)이 살짝 높게 나올 것으로 보이나 4분할 대체로 균등.
**LLM 추론 재료**
 - 단독 추론 — 이 사람이 사랑을 확인하는 채널이 말인지, 행동인지, 접촉인지, 존재인지 규정한다.
 - 교차 추론 예시 — A3(스킨십형=C) + B2(공간존중형) → "평소엔 스킨십으로 사랑을 느끼지만 힘들 땐 오히려 혼자 두길 원하는 사람이다. 상대가 '평소처럼 안아주면 되겠지'라고 생각하면 힘든 순간에 오히려 부담스러울 수 있다 — 평소와 위기 시 원하는 게 다른 유형."
**재미 포인트**: 흔한 애정표현 4갈래를 콕 집어줘서 "아 나 완전 이거네" 하고 바로 답이 나오는 문항.
**추천도**: ◎ — 장면이 가장 보편적이고, 결과 리포트(7장 상대 사용설명서)의 기본값으로 그대로 쓸 수 있는 정공법 문항.

### A3-2 · 장 보러 갔을 때

**질문**: 같이 장 보러 갔다. 별거 없는 일상 데이트인데, 상대가 이러면 마음이 몽글몽글해진다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|

| C | 카트 밀면서 자연스레 옆에 붙어 걷는다 | 근접스킨십형 |
| D | 계산 줄 서 있는 동안 시시콜콜한 얘기를 편하게 나눈다 | 존재편안형 |

**축 순수도 검증**: A3-1과 같은 채널 축을 다른 장면으로 재확인하는 후보. 위기·설렘 요소가 없어 축이 순수하게 유지된다.
**예상 응답 분포**: A 25% / B 30% / C 20% / D 25% — 구체적으로 '기억해서 말해주는' 순간이 장보기라는 소재와 잘 맞아 B가 살짝 높을 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — A3-1과 같은 채널 정보를 다른 상황으로 교차 검증할 수 있는 백업 문항.
 - 교차 추론 예시 — A3(기억인정형=B) + B1(기억실행형 심쿵) → "이 사람은 평소엔 상대가 자신의 취향을 기억해주는 것에서 안정을, 심쿵하는 순간에도 비슷하게 '기억을 실행해주는 것'에서 설렘을 느낀다. 안정과 설렘의 스위치가 같은 채널에서 작동하는 사람."
**재미 포인트**: 장보기라는 지극히 소소한 일상 소재라 오히려 현실감이 살고 공감이 크다.
**추천도**: ○ — A3-1과 축이 겹쳐 함께 채택하지 않음. 대체 후보로는 좋음.

### A3-3 · 친구 단톡방에서 나온 얘기

**질문**: 우리 얘기가 상대 친구 단톡방에서 나왔다는 걸 나중에 전해 들었다. 이러면 마음이 편안해진다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "여친/남친이 요즘 이런 걸 잘한다"고 구체적으로 칭찬했다더라 | 언어인정형 |
| B | "요즘 많이 챙겨준다"고 행동을 자랑했다더라 | 행동인정형 |
| C | 그냥 "얘기만 나와도 표정이 풀린다"고 하더라 | 존재애착형 |
| D | 별말은 안 했지만 프사가 나로 되어있다더라 | 상징물형 |

**축 순수도 검증**: 남 앞에서의 언급이지만 정서는 '안심'이지 '설렘'이 아니라서 B1과 어휘상 분리된다. 갈등·위기 요소가 전혀 없어 B2와도 구분된다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — 간접 정보를 통해 확인받는 형태 특성상 '표정이 풀린다'는 정서적 신호(C)에 반응하는 사람이 살짝 많을 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 눈에 보이지 않는 곳에서의 태도까지 신경 쓰는 사람인지, 상징적 표시(프사) 하나로 안심하는 사람인지가 드러난다.
 - 교차 추론 예시 — A3(상징물형=D) + A1(속앓이형) → "이 사람은 애매한 순간엔 불안해하면서도, 작은 상징(프사 하나)만으로 크게 안심하는 사람이다. 거창한 확신보다 사소하고 꾸준한 신호가 이 사람에게는 더 크게 작동한다."
**재미 포인트**: "몰래 전해 들은 얘기"라는 설정 자체가 두근거리는 상황이라 몰입감이 높다.
**추천도**: ○ — 정보가치는 있으나 '간접 정보'라는 조건이 응답자의 실제 경험 여부에 따라 편차가 클 수 있음.

### A3-4 · 바빠도 지켜지는 것

**질문**: 요즘 둘 다 바빠서 연락이 좀 뜸해졌다. 그래도 상대가 이거 하나는 꼭 지켜주면 안심된다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 짧아도 굿모닝·굿나잇 인사는 거른 적이 없다 | 루틴형 |

| D | "바빠서 그런 거지 딴맘 없다"고 미리 확실히 말해준다 | 확언형 |

**축 순수도 검증**: 이미 확립된 습관(사실)을 다루는 문항이라 '애매함에 대한 반응'을 묻는 A1과 구분된다. 바쁜 시기라는 조건도 위기가 아닌 일상의 변주라 B2와 겹치지 않는다.
**예상 응답 분포**: A 30% / B 20% / C 25% / D 25% — 루틴형(A)이 가장 손쉽고 흔한 습관이라 약간 높게, 나머지는 고르게 분포.
**LLM 추론 재료**
 - 단독 추론 — 바쁜 시기에도 최소한 무엇이 지켜져야 안심하는지가 드러나며, 7장 "상대 사용설명서"의 바쁜 시기 대응 매뉴얼로 바로 쓸 수 있다.
 - 교차 추론 예시 — A3(확언형=D) + A1(즉시확인형) → "이 사람은 애매한 상황에서 먼저 확인하는 성향인 동시에, 상대가 먼저 확실히 말해주는 것에서 크게 안심한다. 즉 이 사람에게는 '눈치껏'보다 '말로 확실히'가 훨씬 효과적인 소통 방식이다."
**재미 포인트**: 바쁜 시기 커플이라면 누구나 겪는 딜레마라 "이거 완전 내 얘기"라는 반응이 바로 나온다.
**추천도**: ○ — A1과 인접한 상황(바쁨·연락 텀)이라 두 축을 같이 채택할 경우 문항 배치 순서에 주의 필요.

## A4 · 거리 조절 욕구

축 정의: 갈등·애매함과 무관한 평상시, 붙어 있고 싶은 욕구와 혼자만의 시간 욕구 사이 어디에 있는가. A1과 달리 상대의 신호는 명확하고, A2와 달리 다툼 상황이 아니다.

### A4-1 · 주말 스케줄이 붕 떴다

**질문**: 둘 다 이번 주말 약속이 갑자기 취소돼서 스케줄이 붕 떴다. 나는 보통 상대한테 뭐라고 해?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "그럼 오늘 하루 종일 같이 있자"고 먼저 제안한다 | 밀착형 |
| B | "너 볼일 보고 저녁에 보자" 하고 각자 시간을 챙긴다 | 거리형 |
| C | 상대가 정하는 대로 따라간다, 딱히 욕구가 없다 | 무계획형 |
| D | 일단 각자 시간 보내다 저녁에 즉흥적으로 정하자 한다 | 즉흥형 |

**축 순수도 검증**: 관계가 애매하거나 갈등이 있는 상태가 아닌, 순수하게 남는 시간을 어떻게 쓰고 싶은가만 묻는다. 다른 축의 조건(다툼, 애매함, 위기)이 전혀 개입되지 않는다.
**예상 응답 분포**: A 25% / B 25% / C 20% / D 30% — 확답보다 여지를 남기는 즉흥형(D)이 초기 커플 특성상 가장 흔한 반응일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 자유 시간이 생겼을 때 본능적으로 뭘 원하는지가 가감 없이 드러난다.
 - 교차 추론 예시 — A4(거리형=B) + A3(존재형 아님/언어관심형) → "이 사람은 붙어있는 시간보다 각자의 시간을 확보하는 걸 우선하면서도, 사랑은 짧은 연락으로 확인받길 원한다. 상대가 '거리를 둔다=관심이 없다'로 오독하면 안 되는 조합이다."
**재미 포인트**: 갑자기 생긴 자유시간 앞에서 본능이 드러나는 장면이라 다들 자기 반응을 솔직하게 인정하게 된다.
**추천도**: ○ — 무난하고 안전하지만 A4-2보다 갈등 소지(오해로 이어질 여지)가 약해 진단적 임팩트는 한 단계 아래.

### A4-2 · 사귄 지 얼마 안 됐는데 매일 연락

**질문**: 사귄 지 얼마 안 됐는데 상대가 벌써 매일 연락, 거의 매일 만나자고 한다. 나는?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 완전 좋다, 나도 이 정도로 붙어있고 싶었다 | 밀착환영형 |
| B | 좋긴 한데 살짝 숨 막힌다, 나만의 시간이 아쉽다 | 거리필요형 |
| C | 좋다고는 하는데 실제로는 하루 이틀 텀을 슬쩍 만든다 | 완곡거리형 |
| D | 상대 페이스에 그냥 맞춘다, 나는 딱히 상관없다 | 맞춤형 |

**축 순수도 검증**: 상대의 태도는 명확(매일 연락)하고 애매함이 없어 A1과 구분되며, 갈등 요소도 없다. "관계 초반 페이스"라는 초기 커플 특유의 현실적 딜레마만 순수하게 겨냥한다.
**예상 응답 분포**: A 25% / B 25% / C 25% / D 25% — 관계 초반 밀착도에 대한 선호는 실제로 매우 고르게 갈리는 지점이라 자연스러운 4분할.
**LLM 추론 재료**
 - 단독 추론 — 초반부터 밀착을 편하게 느끼는지, 티 안 나게 거리를 조절하는 사람인지가 드러난다. 7장 "상대 사용설명서"에서 연락 페이스 조율 팁으로 바로 쓰인다.
 - 교차 추론 예시 — A4(완곡거리형=C) + B3(간접신호형) → "이 사람은 부담스러워도 직접 말하지 않고 행동으로 은근히 거리를 조절하는 패턴이 겹친다. 상대는 눈치채지 못한 채 계속 같은 페이스를 유지하다가 어느 순간 이 사람이 지쳐 있는 걸 발견할 수 있다."
**재미 포인트**: 초기 연애의 '요즘 좀 과한가?' 딜레마를 정면으로 다뤄 다들 뜨끔하며 웃는다.
**⚠️ 지뢰**: B, C를 고르면 상대가 "내가 부담을 준 건가" 싶어 위축될 수 있다. 해설에서 "속도 차이는 애정의 차이가 아니다"로 완충 필요.
**추천도**: ◎ — 초기 커플에게 가장 현실적이고 절실한 장면이며, 오해로 직결되는 정도가 가장 크다.

### A4-3 · 오랜만의 혼자 시간

**질문**: 오랜만에 생긴 혼자만의 저녁 시간. 근데 상대가 "심심한데 놀러 갈까?" 톡을 보냈다. 나는 속으로?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "오 좋아!" 하고 바로 나갈 준비한다 | 밀착형 |
| B | "오늘은 혼자 있고 싶은데" 싶어서 다음으로 미루자고 한다 | 거리형 |
| C | 내키진 않지만 일단 나가서 만나고 온다 | 절충형 |
| D | 오늘은 힘들다고 솔직히 말하고 다른 날을 잡자고 한다 | 솔직조율형 |

**축 순수도 검증**: 상대의 요청이 명확하고 다툼도 없어 A1·A2와 무관하다. '내가 확보한 혼자 시간을 지키고 싶은 정도'만 순수하게 측정한다.
**예상 응답 분포**: A 20% / B 25% / C 30% / D 25% — 거절이 부담스러워 일단 나가는 절충형(C)이 초기 커플 특성상 가장 많을 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 확보한 개인 시간을 실제로 지키는 사람인지, 관계를 우선해 양보하는 사람인지가 드러난다.
 - 교차 추론 예시 — A4(절충형=C) + B3(축소형) → "이 사람은 자기 욕구(혼자 있고 싶음)를 억누르고 맞춰주는 패턴이 있는데, 평소에도 서운함을 대수롭지 않게 넘기는 경향이 겹친다. 겉으론 문제없어 보여도 속에서는 작은 양보가 쌓이고 있을 수 있어 상대가 먼저 물어봐줘야 하는 유형이다."
**재미 포인트**: "내키진 않지만 일단 나간다"는 뼈 때리게 정직한 선택지라 다들 웃으며 인정하게 된다.
**추천도**: ○ — A4-2와 정서가 유사(초반 밀착도)해 조합 시 A4-2를 우선 채택하는 게 낫다.

### A4-4 · 여행 중 낮잠 시간

**질문**: 같이 여행 갔다. 숙소에서 상대가 낮잠 자는 동안 나는 뭐 해?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 옆에서 같이 눕는다, 자든 안 자든 붙어있고 싶다 | 밀착형 |
| B | 혼자 카페라도 갔다 오거나 산책하러 나간다 | 거리형 |
| C | 방에서 조용히 폰 보거나 책 보며 각자 시간을 보낸다 | 병존형 |
| D | 깰까 봐 조심히 나갔다 오고 뭔가 사온다 | 배려밀착형 |

**축 순수도 검증**: 여행이라는 특수 상황이지만 갈등·애매함이 없는 순수한 '함께 있는 시간의 밀도' 선호만 측정한다. 다른 축과 겹치는 조건이 없다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — 같은 공간에 있되 서로 방해 안 하는 병존형(C)이 실제로 가장 흔한 커플 습관일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — '같은 공간에 있는 것'과 '붙어있는 것'을 구분하는 사람인지 아닌지가 드러난다.
 - 교차 추론 예시 — A4(병존형=C) + A3(존재형) → "이 사람은 딱히 스킨십이나 대화가 없어도 같은 공간에 있는 것 자체로 사랑을 느끼는 사람이다. 여행 중 각자 딴짓해도 서운해할 필요가 없는 유형이라는 걸 상대가 알아야 한다."
**재미 포인트**: 여행 중 낮잠이라는 로맨틱해 보이는 순간에도 현실적인 반응(각자 폰 보기)이 나와 웃음을 유발한다.
**추천도**: ○ — 여행이라는 특정 맥락에 기대고 있어 A4-2보다 보편성은 낮지만 장면 자체의 몰입감은 높음.

# 제2장 — 원하는 것 (해답지 프레임)

이 장의 모든 문항은 "나는 어떤 사람을 좋아하나"가 아니라 **"내가 당신에게 무엇을 원하나"**가 답 안에서 드러나도록 설계했다. "이상형" 프레임과 어휘를 배제하고 "설레는 순간"으로만 접근한다.

## B1 · 설렘 트리거

축 정의: 정확히 어떤 순간에 심쿵·설렘(각성)을 느끼는가. A3(평시 안정감)와 분리하기 위해 모든 문항에 '설렌다/심쿵/두근'류 어휘만 사용하고 '편안하다/안심된다'는 쓰지 않는다.

---

### B1-1 · 친구들 앞에서

**질문**: 친구들이랑 다 같이 있는 자리. 상대가 이러면 나 완전 심쿵.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 내 얘기 나오니까 갑자기 으쓱대며 자랑한다 | 자랑형 |
| B | 대화 중에도 슬쩍슬쩍 눈 마주치며 챙긴다 | 관찰형 |
| C | 나만 알아듣는 드립을 쳐서 둘만 씩 웃는다 | 은밀교감형 |
| D | 그냥 손을 슬쩍 잡거나 옆에 붙어 있어준다 | 스킨십형 |

**축 순수도 검증**: '심쿵'이라는 각성 정서로만 한정해 A3(안정감)와 갈린다. 공개석상이라는 조건이 A4(거리 욕구)와 헷갈릴 수 있으나, 이 문항은 '설레는 이유'를 묻지 '붙어있고 싶은 정도'를 묻지 않아 분리된다.
**예상 응답 분포**: A 20% / B 30% / C 25% / D 25% — 티 안 나게 챙기는 관찰형(B)이 가장 은근하면서도 강한 설렘 포인트로 흔할 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 공개된 자리에서 어떤 형태의 관심이 설렘으로 전환되는지 규정한다. 그대로 "친구들 앞에서 이렇게 하면 됨"이라는 실행 지침이 된다.
 - 교차 추론 예시 — B1(자랑형=A) + A4(밀착형) → "이 사람은 붙어있는 것 자체도 좋아하지만, 특히 남들 앞에서 드러내놓고 자랑해주는 순간에 더 크게 설렌다. 스킨십만으로는 부족하고 '공개적 인정'이 더해져야 완성되는 유형."
**재미 포인트**: "친구들 앞"이라는 구체적 무대 설정이 각자의 은근한 과시욕·수줍음을 드러내 웃음을 유발한다.
**추천도**: ○ — 실용적이나 발생 빈도(친구 모임)가 일상보다 낮아 B1-4보다 후순위.

---

### B1-2 · 작은 성취를 해냈을 때

**질문**: 뭔가 작은 걸 해냈다(다이어트 3일 성공, 발표 잘 끝냄 같은 거). 상대 반응이 이러면 심장이 쿵.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "거봐, 넌 원래 잘해" 하고 담백하게 인정해준다 | 담백인정형 |
| B | 오버해서 방방 뛰며 축하해준다 | 오버리액션형 |
| C | 작은 선물이나 이벤트로 보상해준다 | 서프라이즈형 |
| D | "그래서 다음 목표는?" 하고 같이 다음 걸 짜준다 | 동반형 |

**축 순수도 검증**: 성취라는 특정 순간에 한정돼 있고 위기·평시가 아니므로 B2·A3와 겹치지 않는다. '심쿵'이라는 각성 어휘를 유지해 A3와 분리된다.
**예상 응답 분포**: A 25% / B 25% / C 20% / D 30% — 함께 다음을 그려주는 동반형(D)이 초기 커플 관계에서 파트너십을 확인시켜주는 강한 포인트로 작동할 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 성취를 인정받고 싶은 방식이 드러난다. D를 고른 사람은 칭찬 자체보다 '함께 성장하는 파트너십'에서 설렘을 느끼는 타입.
 - 교차 추론 예시 — B1(동반형=D) + A2(즉시직면형) → "이 사람은 좋을 때든 갈등이 생겼을 때든 '같이 다음 스텝을 만들어가는' 적극적 태도에 크게 반응한다. 상대가 문제나 성취를 혼자 처리하려 들면 파트너로 존중받지 못한다고 느낄 수 있다."
**재미 포인트**: "다이어트 3일 성공"처럼 누구나 공감할 소소한 성취 예시라 웃으며 자기 얘기를 떠올리게 된다.
**추천도**: △ — 성취의 순간은 일상 대비 빈도가 낮아 실전 활용도가 다른 후보보다 떨어짐.

### B1-3 · 예상 못 한 타이밍

**질문**: 아무 이유 없는 평범한 날, 상대가 이러면 뇌정지 오고 완전 심쿵함.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 아무 이유 없이 "그냥 보고싶어서" 톡이 온다 | 불시애정표현형 |
| B | 몇 달 전 지나가듯 한 말을 기억해뒀다가 실행해준다 | 기억실행형 |
| C | 뜬금없이 진심 담긴 손편지나 장문 메시지를 준다 | 진심고백형 |
| D | 갑자기 계획에 없던 데이트를 들이민다("나와, 5분 뒤") | 즉흥돌발형 |

**축 순수도 검증**: '예상 못한 순간'이라는 설정 자체가 설렘(각성)의 핵심 조건이라 A3(평시 안정)의 루틴적 정서와 명확히 구분된다.
**예상 응답 분포**: A 30% / B 25% / C 20% / D 25% — 가장 손쉽고 흔하게 상상 가능한 불시애정표현형(A)이 살짝 높게, 나머지는 고르게 분포.
**LLM 추론 재료**
 - 단독 추론 — 예상치 못한 자극 중 어떤 형태가 이 사람에게 가장 강하게 작동하는지 규정한다.
 - 교차 추론 예시 — B1(기억실행형=B) + A3(기억인정형) → "이 사람은 평소 안정감도, 특별한 설렘도 같은 채널(기억해준다는 것)에서 나온다. 상대에게는 '거창한 이벤트'보다 '사소한 걸 오래 기억해뒀다가 실행하는 것'이 압도적으로 잘 통하는 사람이라는 뜻."
**재미 포인트**: "나와, 5분 뒤" 같은 즉흥돌발형은 상상만 해도 웃기고 설레는 포인트라 반응이 즉각적이다.
**추천도**: ○ — 좋은 후보지만 B1-4(하이브리드)가 같은 정보를 더 풍부하게 담아내 단독 채택 시 후순위.

### B1-4 · 심쿵 태그 3개 + 한 줄 (하이브리드)

**질문**: 요즘 나를 심쿵하게 만드는 순간, 아래에서 딱 3개만 골라줘. 그리고 제일 최근에 그랬던 순간을 한 줄로 알려줘.

**태그 풀 (3개 선택)**

| 번호 | 태그 | 유형 라벨 |
|---|---|---|
| 1 | 예상 못한 다정함 (뜬금없는 챙김) | 불시애정형 |
| 2 | 나를 자랑스러워해주는 것 | 인정형 |
| 3 | 무조건 내 편을 들어주는 것 | 편들기형 |
| 4 | 사소한 걸 기억했다가 꺼내는 것 | 기억형 |
| 5 | 스킨십으로 티내는 것 | 접촉형 |
| 6 | 바쁜 와중에도 시간 내주는 것 | 시간투자형 |
| 7 | 유치한 애정표현 (애칭, 장난) | 유쾌형 |
| 8 | 나한테만 보여주는 다른 모습 | 독점형 |

**자유 한 줄**: 예) "며칠 전 내가 아무 말 안 했는데 힘든 거 눈치채고 그냥 안아줬을 때"

**축 순수도 검증**: 8개 태그 모두 '설렘·심쿵'이라는 각성 정서에만 한정했고 '안정·편안'류 표현은 배제해 A3와 분리했다. 다중 선택이라 특정 축 하나로 수렴하지 않고 B1축의 다면성을 그대로 드러낸다.
**예상 응답 분포(태그 선택률 추정)**: 1(다정함) 35% · 4(기억) 30% · 6(시간투자) 30% · 5(스킨십) 25% · 7(유쾌) 25% · 3(편들기) 20% · 2(인정) 20% · 8(독점) 15% — 8개 중 3개를 고르는 구조라 상위 태그 쏠림 위험은 낮음. 다만 8(독점)이 상대적으로 낮게 나올 것으로 예상돼 문항 노출 순서 조정 고려.
**LLM 추론 재료**
 - 단독 추론 — 단일 선택지보다 해상도가 높다. 3개 조합의 겹침·공백을 보면 이 사람의 설렘이 한 채널이 아니라 여러 축의 조합이라는 걸 알 수 있고, 자유 한 줄은 실제 재현 가능한 구체적 행동을 제공한다.
 - 교차 추론 예시 — B1("6. 바쁜 와중에도 시간 내주는 것" 선택) + A1(즉시확인형 아님/여유대기형) → "이 사람에게는 데이트 계획이 틀어지는 것보다 '그럼에도 시간을 지키려는 태도' 자체가 크게 어필한다. 평소 애매한 상황에서도 여유 있게 기다릴 수 있는 이유가, 상대가 결국 시간을 내줄 거란 신뢰에서 온다는 해석으로 연결된다."
**재미 포인트**: 4지선다에 지칠 때쯤 나오는 자유도 높은 문항이라 환기 효과가 있고, 3개를 고르는 과정에서 "어 나 이런 것도 좋아했네" 재발견하게 된다.
**추천도**: ◎ — 다면적 설렘 신호를 한 번에 포착해 7장 "상대 사용설명서"와 8장 "오늘 밤 나눠볼 질문" 카드덱 완성도를 가장 크게 끌어올린다.

## B2 · 힘들 때 원하는 케어

축 정의: 완전히 무너졌을 때(위기) 상대가 뭘 해주길 바라는가. A3(평시)와 명확히 다른 시점으로만 한정했다.

### B2-1 · 완전히 털린 날

**질문**: 회사에서 완전히 털리고 온 날. 상대가 이거 하나 해주면 스르르 풀린다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 말없이 꽉 안아준다 | 접촉위로형 |
| B | "무슨 일인데" 하고 끝까지 캐물어 들어준다 | 경청형 |
| C | 아무 말 없이 맛있는 거 사들고 온다 | 행동케어형 |
| D | 그냥 혼자 있게 냅두고 연락도 최소한만 한다 | 공간존중형 |

**축 순수도 검증**: '완전히 털린 날'이라는 명확한 위기 트리거로 한정해 A3(평시)와 구분된다. 케어의 방식만 물어 표현 개방성(B3)과는 무관하다.
**예상 응답 분포**: A 30% / B 20% / C 25% / D 25% — 스킨십 위로(A)가 국내 20~30대 커플에서 가장 직관적인 선택으로 살짝 높게, 나머지는 고르게 분포.
**LLM 추론 재료**
 - 단독 추론 — 위기 시 사랑받는다고 느끼는 채널을 규정한다. 7장 "상대 사용설명서"의 1차 재료.
 - 교차 추론 예시 — B2(공간존중형=D) + A3(스킨십형) → "평소엔 스킨십으로 사랑을 느끼지만 정작 힘들 땐 혼자 있길 원하는 사람이다. 상대가 '평소처럼 안아주면 되겠지'라고 접근하면 힘든 순간에 오히려 부담스러울 수 있다 — 평소와 위기의 니즈가 정반대인 유형."
**재미 포인트**: "완전히 털린 날"이라는 표현 자체가 웃프게 와닿고, 넷 다 실제로 받아본/해본 위로 방식이라 자기 답을 보여주고 싶어진다.
**추천도**: ◎ — 위기 시 애정표현 채널 불일치는 관계운영 궁합의 핵심축이며 결과 리포트 활용도 최상.

### B2-2 · 이유 모를 며칠째 바닥

**질문**: 며칠째 기분이 바닥이다. 이유는 나도 잘 모르겠다. 상대가 이러면 오히려 더 좋다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "무슨 일 있어?" 물어보되 대답 안 해도 안 캐묻는다 | 조심스러운접근형 |
| B | 아무것도 안 묻고 하고 싶은 대로 냅둔다 | 완전존중형 |
| C | 재밌는 거(넷플릭스, 드라이브)로 텐션을 끌어올리려 한다 | 전환유도형 |
| D | "네 옆에 있을게" 하고 말없이 그냥 붙어있어 준다 | 조용동행형 |

**축 순수도 검증**: 원인 불명의 저하라는 조건 자체가 명확한 위기 트리거이며, 이 사람이 '평소'가 아니라 '무너졌을 때' 무엇을 원하는지만 측정한다.
**예상 응답 분포**: A 25% / B 20% / C 25% / D 30% — 말없이 곁을 지키는 조용동행형(D)이 원인 불명 상황에서 가장 안전하게 느껴지는 선택으로 살짝 높을 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 이유를 알 수 없는 저하 상태에서도 개입을 원하는지, 완전한 자유를 원하는지가 드러난다.
 - 교차 추론 예시 — B2(완전존중형=B) + A4(거리형) → "평소에도 혼자만의 시간을 중요하게 여기는 사람인데 힘들 때는 그 욕구가 더 강해진다. 상대가 위로한답시고 계속 곁에 붙어있으려 하면 오히려 회복을 방해할 수 있다."
**재미 포인트**: "이유는 나도 모르겠다"는 매우 흔한 감정 상태라 다들 크게 공감하며 자기 답을 확신 있게 고르게 된다.
**추천도**: ○ — B2-1과 위기 상황이라는 결이 유사해 함께 채택 시 B2-1을 우선.

### B2-3 · 큰 실수로 자책할 때

**질문**: 진짜 큰 실수를 해서 자책하고 있다. 상대가 이렇게 해주면 좀 낫다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | "네 잘못 아니야" 하고 확실히 편들어준다 | 무조건편들기형 |
| B | "그래서 이제 어떡할 거야" 하고 같이 해결책부터 찾는다 | 해결형 |
| C | 일단 아무 말 없이 옆에서 같이 있어준다 | 동행형 |
| D | 다른 얘기로 화제를 돌려서 잠깐이라도 잊게 해준다 | 환기형 |

**축 순수도 검증**: '자책'이라는 특정 위기 정서에 한정돼 있어 평시 A3, 갈등 A2와 겹치지 않는다. 실수의 원인이 상대가 아니라 나 자신이라 갈등 축(A2)과도 명확히 분리된다.
**예상 응답 분포**: A 30% / B 20% / C 25% / D 25% — 자책하는 사람에게 편을 들어주는 게 가장 직관적인 위로로 여겨져 A가 살짝 높게, 나머지는 고르게.
**LLM 추론 재료**
 - 단독 추론 — 자책 상황에서 감정적 지지가 먼저인지, 실질적 해결이 먼저인지가 드러난다.
 - 교차 추론 예시 — B2(해결형=B) + A2(즉시직면형) → "이 사람은 힘들 때도, 갈등이 생겼을 때도 '문제를 실제로 해결하는 것'에서 안정을 찾는다. 상대가 감정적 위로만 건네면 오히려 답답해하며 '그래서 어떻게 할 건데'를 계속 묻는 이유가 여기 있다."
**재미 포인트**: 다들 자책 모드에 빠져본 경험이 있어 "나 완전 이거 원해" 하고 바로 반응하게 된다.
**추천도**: ○ — B2-1과 정서가 인접(둘 다 감정적 위로 대 실질적 케어 구도)해 조합 시 후순위.

### B2-4 · 몸이 아파 뻗은 날

**질문**: 몸이 아파서 완전히 뻗은 날. 상대가 이러면 진짜 고맙다.

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 죽·약 사들고 집까지 와준다 | 실질케어형 |

| D | 옆에 와서 그냥 같이 누워있어 준다 | 존재형 |

**축 순수도 검증**: 신체적 위기라는 A3와 확연히 다른 조건으로 고정돼 있어 축이 섞이지 않는다.
**예상 응답 분포**: A 30% / B 20% / C 20% / D 30% — 실질적 도움(A)과 그냥 곁에 있기(D)가 대표적인 두 축으로 갈릴 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 신체적으로 무너졌을 때 원하는 게 실질적 도움인지, 곁에 있는 존재감인지 구분된다.
 - 교차 추론 예시 — B2(원격챙김형=B) + A4(거리형) → "이 사람은 평소에도 혼자만의 공간을 선호하는데, 아플 때조차 옆에 붙어있는 것보다 적절한 거리를 두고 챙겨주는 걸 편하게 느낀다. 상대가 무조건 달려오는 걸 최선이라 여기면 오히려 부담을 줄 수 있다."
**재미 포인트**: 아파서 초췌한 순간에 원하는 케어를 솔직히 고르는 문항이라 웃음보다는 잔잔한 공감이 큰 편.
**추천도**: ○ — B2-1과 상황이 유사(신체·정서 위기)해 함께 채택 시 B2-1 우선.

## B3 · 표현 개방성

축 정의: 평소 속마음을 얼마나, 어떻게 내보이는가. A2(갈등 직후 행동)와 겹치지 않도록 모든 문항에서 다툼 요소를 제거하고 일상적인 감정 기복만 다뤘다.

---

### B3-1 · 오늘 하루 어땠어

**질문**: 오늘 기분이 별로였다. 상대가 "오늘 하루 어땠어?" 물어본다. 나는 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 있었던 일, 느낀 감정까지 다 풀어놓는다 | 전면공개형 |
| B | "그냥 그랬어" 하고 대충 넘긴다, 캐물으면 그때 말한다 | 유도형 |
| C | 무슨 일 있었는지는 말하는데 감정은 잘 안 드러낸다 | 사실전달형 |
| D | "괜찮아~" 하고 아예 티를 안 낸다, 걱정 끼치기 싫어서 | 은닉형 |

**축 순수도 검증**: 다툼이 전혀 없는 평범한 하루의 감정 공유 습관만 다뤄 A2와 분리된다. 갈등 처리 타이밍이 아니라 '평소 노출 정도'가 핵심이다.
**예상 응답 분포**: A 20% / B 25% / C 30% / D 25% — 사실은 말하되 감정은 감추는 사실전달형(C)이 한국 커플 특성상 가장 흔한 절충안일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 이 사람이 감정을 있는 그대로 드러내는지, 캐물어야 여는지, 사실만 전하는지, 아예 숨기는지가 드러난다.
 - 교차 추론 예시 — B3(은닉형=D) + A1(속앓이형) → "이 사람은 애매한 상황에서도, 평소 기분이 안 좋을 때도 겉으로 티를 안 내는 일관된 패턴이 있다. 상대는 '괜찮다'는 말을 그대로 믿기 쉽지만, 실제로는 먼저 살펴봐줘야 하는 타입이라는 뜻이다."
**재미 포인트**: "괜찮아~" 뒤에 숨은 진짜 속마음은 모두가 찔리는 국민 공감 포인트라 웃음이 터진다.
**추천도**: ◎ — 장면이 가장 보편적이고 갈등(A2)과 명확히 분리돼 축 순수도가 가장 높다.

### B3-2 · 상대 탓 아닌 서운함

**질문**: 오늘 진짜 별거 아닌데 좀 서운한 일이 있었다(상대 탓은 전혀 아니고 그냥 하루 컨디션). 나는 보통 상대한테?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 바로 "나 오늘 이래서 좀 그래" 하고 말한다 | 즉시공유형 |
| B | 물어보면 그제서야 말한다 | 유도형 |
| C | 티를 조금 내긴 하는데 말로 설명은 안 한다(한숨, 텐션 낮음) | 간접신호형 |
| D | 아예 말 안 하고 넘긴다, 혼자 정리하는 편이다 | 완전내면형 |

**축 순수도 검증**: 문항 자체에 "상대 탓 아님"을 명시해 갈등(A2)과 확실히 분리했다. 이 서운함은 관계 문제가 아니라 개인 컨디션이라 순수하게 표현 습관만 잰다.
**예상 응답 분포**: A 20% / B 25% / C 30% / D 25% — 말 대신 티만 살짝 내는 간접신호형(C)이 실제로 가장 흔한 한국식 표현 방식일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 사소한 감정도 먼저 꺼내는 사람인지, 안 꺼내면 상대가 알아챌 방법이 없는 사람인지 규정한다.
 - 교차 추론 예시 — B3(간접신호형=C) + A3(존재형) → "이 사람은 평소 사랑도 요란하지 않은 방식으로 확인하고, 서운함도 말보다 분위기로 티를 낸다. 상대가 눈치가 없는 편이면 이 사람의 신호를 계속 놓칠 위험이 크다 — 이 사람에게는 '말해줘야 알지'보다 '눈치껏 알아채는 게' 필요하다."
**재미 포인트**: "상대 탓 아닌 서운함"이라는 미묘한 설정이 오히려 더 현실적이라 자기 얘기처럼 느껴진다.
**추천도**: ◎ — 갈등과 완전히 분리된 순수한 평소 개방성만 측정하는 가장 깨끗한 문항.

### B3-3 · 부끄러운 얘기를 꺼내는 타이밍

**질문**: 상대한테 나만 아는 부끄러운 얘기(과거 흑역사, 콤플렉스 같은 거)를 하는 편은 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 사귀자마자 먼저 술술 다 얘기하는 편 | 빠른개방형 |
| B | 신뢰가 쌓였다 싶을 때 조금씩 꺼낸다 | 점진개방형 |
| C | 물어봐야 마지못해 얘기한다 | 방어적개방형 |
| D | 아직 아무한테도 얘기 안 한 것도 있다, 나만 알아도 된다고 생각 | 비공개유지형 |

**축 순수도 검증**: 특정 사건이 아니라 관계 전반에 걸친 자기노출 성향을 묻는 문항이라 A2와 무관하며, 애정·위기 요소도 없어 다른 축과 섞이지 않는다.
**예상 응답 분포**: A 15% / B 40% / C 25% / D 20% — 신뢰가 쌓이면서 점진적으로 여는 B가 가장 보편적인 개방 방식이라 다소 높게 잡히나, 초기 커플 특성상 나머지도 유의미한 비중을 차지한다.
**⚠️ 지뢰**: B가 사회적으로 '건강한 정답'처럼 보여 쏠릴 위험이 있다. 실제 채택 시 선택지 문구를 더 대등하게 다듬을 필요.
**LLM 추론 재료**
 - 단독 추론 — 신뢰를 얼마나 빨리, 얼마나 깊게 여는 사람인지가 드러난다.

**재미 포인트**: '흑역사 공개 타이밍'은 다들 흥미로워하는 소재라 서로 답을 비교하고 싶어진다.
**추천도**: △ — 좋은 소재지만 B가 사회적 정답처럼 보이는 쏠림 위험이 커 B3-1·B3-2보다 후순위.

### B3-4 · SNS에 새어 나오는 감정

**질문**: SNS나 톡 프로필에 내 감정 상태(기분 안 좋음, 힘듦 등)가 은근히 드러난 적, 나는 보통?

| 선택지 | 내용 | 유형 라벨 |
|---|---|---|
| A | 자주 있다, 나도 모르게 티가 난다 | 무의식노출형 |
| B | 가끔 의도적으로 암시성 문구를 올린다 | 의도적신호형 |
| C | 거의 없다, 감정과 SNS는 철저히 분리한다 | 완전분리형 |
| D | 오히려 안 좋을 때일수록 더 밝은 척 올린다 | 반대위장형 |

**축 순수도 검증**: SNS라는 제3의 채널을 통해 평소 노출 습관을 재는 문항이라 갈등·위기 상황과 무관하며 A2·B2와 섞이지 않는다.
**예상 응답 분포**: A 25% / B 20% / C 30% / D 25% — SNS와 감정을 분리하는 완전분리형(C)이 조금 더 흔한 편일 것으로 본다.
**LLM 추론 재료**
 - 단독 추론 — 이 사람의 감정 신호가 사적 채널(연인과의 대화) 밖으로도 새어 나오는지, 아니면 철저히 관리되는지가 드러난다.
 - 교차 추론 예시 — B3(반대위장형=D) + B2(공간존중형) → "이 사람은 힘들 때 겉으로는 오히려 더 밝은 척하면서 동시에 혼자만의 공간을 원한다. 상대가 SNS만 보고 '별일 없나 보다' 안심하면 정작 이 사람이 힘든 시기를 혼자 넘기고 있을 수 있다 — 표정과 진짜 상태가 반대로 가는 유형이라는 걸 알아야 한다."
**재미 포인트**: 다들 은근히 찔리는 'SNS 감정 티내기' 습관이라 웃으며 자기 유형을 인정하게 된다.
**추천도**: ○ — 흥미로운 각도지만 응답자의 SNS 사용 빈도에 따라 편차가 있을 수 있어 B3-1·B3-2보다 후순위.

| **B1-4** (심쿵 태그, 하이브리드) | 태그 8 "나한테만 보여주는 다른 모습" (예상 15%) | 8개 중 3개를 고르는 구조상 관념적인 태그(추상적 표현)가 구체적 태그보다 덜 선택될 가능성. | 태그 8을 더 구체적인 행동 묘사("남들한텐 안 하는 장난을 나한테만 친다" 등)로 재작성해 선택 장벽을 낮춘다. |

이 다섯 건을 제외한 23개 후보는 4개(또는 8개) 선택지 간 매력·결함이 비교적 고르게 설계돼 있어 실제 응답 시 특정 선택지로 쏠릴 위험이 낮다고 판단했다.
