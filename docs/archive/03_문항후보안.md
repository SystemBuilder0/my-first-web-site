## 제1장 — 데이트·애정표현·대화·갈등 (통합)

**설계 원칙**: 워밍업이자 관계 운영 진단. 첫 문항(1-A)은 가장 가볍고 웃긴 것으로 배치. 데이트 방식(1-A~C) / 애정표현 방식(1-D~F) / 대화 스타일(1-G~H) / 갈등 대응(1-I~J)이 골고루 커버되도록 배분했다.

### 1-A · 데이트 — 돌발상황 대응 (첫 문항 후보)

**질문**: 데이트 중에 갑자기 비가 쏟아진다. 나는?

| 선택지 | 내용 |
|---|---|
| A | 일단 뛴다. 웃으면서 뛴다 |
| B | 편의점으로 직행해서 우산부터 산다 |
| C | 오히려 좋다. 비 맞으며 걷자고 한다 |
| D | 상대부터 챙긴다. 내 옷 벗어준다 |

**태그**: 돌발상황대응:유쾌형 / 대비형 / 낭만형 / 챙김형
**추천도**: ◎ 강력추천 — 가볍고 웃기고 부담 없어 이탈이 가장 큰 첫 문항 자리에 최적. 데이트 성향도 자연스럽게 드러남

### 1-B · 데이트 — 계획형 vs 즉흥형

**질문**: 이번 주말 데이트, 어떤 쪽이 더 끌려?

| 선택지 | 내용 |
|---|---|
| A | 완벽하게 짜여진 코스 (예약, 동선까지) |
| B | 일단 만나서 그때그때 정하기 |
| C | 큰 틀만 정하고 세부는 즉흥으로 |
| D | 상대가 짜온 대로 따라가는 게 편하다 |

**태그**: 데이트스타일:계획형 / 즉흥형 / 절충형 / 위임형
**추천도**: ○ 무난 — 기본적이지만 관계운영 궁합 리포트에 필요한 축

### 1-C · 데이트 — 선호 에너지

**질문**: 둘이 있을 때 제일 편한 데이트는?

| 선택지 | 내용 |
|---|---|
| A | 집에서 뒹굴며 둘만의 시간 |
| B | 사람 많은 핫플레이스 나들이 |
| C | 조용한 카페에서 대화 |
| D | 몸을 움직이는 액티비티(운동, 여행 등) |

**태그**: 데이트에너지:내향형 / 외향형 / 대화형 / 활동형
**추천도**: ○ 무난 — 1-B와 함께 채택 시 데이트 축이 과다해질 수 있어 택1 권장

### 1-D · 애정표현 — 표현 채널

**질문**: "나 너 좋아해"가 제일 잘 느껴지는 순간은?

| 선택지 | 내용 |
|---|---|
| A | "예쁘다", "고생했어" 같은 말을 들을 때 |
| B | 손을 잡거나 안아줄 때 |
| C | 필요한 걸 먼저 챙겨줄 때 (선물, 행동) |
| D | 옆에서 조용히 시간을 함께 보내줄 때 |

**태그**: 애정표현:언어형 / 접촉형 / 행동형 / 존재형
**추천도**: ◎ 강력추천 — 애정표현 채널 불일치는 관계운영 궁합의 핵심축. 결과 리포트(7장 상대 사용설명서) 활용도 최상

### 1-E · 애정표현 — 표현 빈도

**질문**: 애정표현, 어느 정도가 딱 좋아?

| 선택지 | 내용 |
|---|---|
| A | 사소한 거라도 자주자주 |
| B | 진짜 필요할 때 확실하게 |
| C | 말보다 행동으로 꾸준히 |
| D | 무드 탈 때 몰아서 화끈하게 |

**태그**: 애정표현빈도:잦은형 / 절제형 / 행동누적형 / 몰아형
**추천도**: △ 보류 — 1-D와 축이 겹쳐 함께 채택 시 정보 중복. 1-D 대체용으로만 고려

### 1-F · 애정표현 — 스킨십 주도권

**질문**: 먼저 스킨십(손잡기, 안기 등)을 시작하는 쪽은 보통?

| 선택지 | 내용 |
|---|---|
| A | 내가 먼저 하는 편 |
| B | 상대가 해주길 기다리는 편 |
| C | 분위기 봐서 반반 |
| D | 스킨십보다 말로 먼저 표현하는 편 |

**태그**: 애정표현주도:주도형 / 수용형 / 상황형 / 언어우선형
**추천도**: ○ 무난 — 3장 은밀한 궁합의 "주도권" 문항(3-D)과 결이 겹칠 수 있어 3장에서 주도권을 다룰 경우 1-F는 제외 권장

### 1-G · 대화 — 일상 공유 방식

**질문**: 퇴근하고 만나면 오늘 하루 얘기, 나는?

| 선택지 | 내용 |
|---|---|
| A | 처음부터 끝까지 디테일하게 다 말한다 |
| B | 있었던 일 중 재밌는 것만 골라 말한다 |
| C | 먼저 안 꺼내고 물어봐야 말한다 |
| D | "그냥 똑같았어" 하고 넘긴다 |

**태그**: 대화스타일:서술형 / 선별형 / 질문응답형 / 과묵형
**추천도**: ◎ 강력추천 — 대화량 차이는 오해의 주 원인이자 재미있는 대조가 나오는 문항

### 1-H · 대화 — 고민 상담 니즈

**질문**: 고민이 생겼을 때 상대에게 바라는 건?

| 선택지 | 내용 |
|---|---|
| A | 일단 들어주고 공감만 해줬으면 |
| B | 같이 해결책을 찾아줬으면 |
| C | 내가 먼저 말할 때까지 기다려줬으면 |
| D | 분위기 바꿔서 기분을 풀어줬으면 |

**태그**: 대화니즈:공감형 / 해결형 / 대기형 / 전환형
**추천도**: ◎ 강력추천 — 공감형 vs 해결형은 실제 다툼 원인 1순위로 꼽히는 축. 4장 예측 문항(4-F)과 연결하면 파급력이 가장 큼

### 1-I · 갈등 — 대응 타이밍

**질문**: 다투고 나면 나는 보통?

| 선택지 | 내용 |
|---|---|
| A | 바로 얘기해서 풀어야 직성이 풀린다 |
| B | 시간을 좀 두고 각자 식힌 다음 얘기한다 |
| C | 먼저 사과하고 넘어가는 편 |
| D | 말없이 행동으로 화해를 건다 (선물, 챙기기 등) |

**태그**: 갈등:즉시직면형 / 시간필요형 / 선사과형 / 행동화해형
**추천도**: ◎ 강력추천 — 갈등 대응 타이밍 불일치는 실제 다툼의 가장 흔한 도화선. 6장 해석 아키텍처의 "해법" 파트에서 바로 활용 가능

### 1-J · 갈등 — 표현 여부

**질문**: 속상한 게 있는데 상대가 눈치를 못 챈다. 나는?

| 선택지 | 내용 |
|---|---|
| A | 티 안 내고 넘어간다 (알아서 눈치채길 바람) |
| B | "나 삐졌어" 하고 바로 말한다 |
| C | 은근히 티를 낸다 (한숨, 단답 등) |
| D | 시간이 지나면 그냥 괜찮아진다 |

**태그**: 갈등표현:회피형 / 직면형 / 암시형 / 자연소멸형
**추천도**: ○ 무난 — 1-I와 축이 유사하나 "표현 여부" 각도가 달라 상호보완 가능. 1-I와 함께 채택 시 갈등 문항이 2개가 되어 균형 재검토 필요
**⚠️ 지뢰**: C(은근히 티를 낸다)가 본인 얘기처럼 느껴져 상대가 찔릴 수 있음. 다만 이 정도의 자기인식 유발은 제품 목표 5번("내가 얼마나 오해하고 있었는지 알게 됐다")에 부합하므로 허용 범위로 판단

## 제2장 — 이상형·내가 원하는 것 ("설레는 순간" 프레임)

**설계 원칙**: 이 제품의 핵심 블록. "이상형"이라는 단어와 프레임은 지뢰이므로 전 후보에서 배제하고 **"설레는 순간(모먼트)"** 프레임으로 통일했다. 질문은 전부 `내가 어떤 사람을 좋아하나`가 아니라 `내가 당신에게 무엇을 원하나`가 드러나도록 행동·상황 중심으로 설계했다. 2-D는 태그 선택 + 자유 한 줄 하이브리드 형태다.

### 2-A · 행동 기반 설렘 포인트

**질문**: 이럴 때 나 완전 설레(두근거림 폭발)

| 선택지 | 내용 |
|---|---|
| A | 무심하게 툭 챙겨줄 때 (내가 말 안 했는데 알아서) |
| B | 나만 아는 다른 모습을 보여줄 때 |
| C | 사람들 앞에서 내 편을 들어줄 때 |
| D | 바쁜데도 시간 쪼개서 연락해줄 때 |

**태그**: 설렘포인트:배려형 / 반전매력형 / 편들기형 / 시간투자형
**추천도**: ◎ 강력추천 — "이상형"이 아니라 "행동"을 묻기 때문에 상대가 답을 읽고 그대로 따라할 수 있는 해답지가 됨

### 2-B · 데이트 중 심쿵 포인트

**질문**: 데이트 중에 상대가 이러면 심쿵 포인트

| 선택지 | 내용 |
|---|---|
| A | 내가 말하기 전에 먼저 알아서 챙겨줄 때 |
| B | 사소한 걸 기억해뒀다가 꺼낼 때 |
| C | 계획에 없던 이벤트를 만들어줄 때 |
| D | 그냥 내 얘기를 눈 맞추고 들어줄 때 |

**태그**: 설렘포인트:눈치형 / 기억형 / 이벤트형 / 경청형
**추천도**: ○ 무난 — 2-A와 유사축을 데이트 상황으로 구체화한 버전. 2-A와 함께 채택 시 중복 우려

### 2-C · 직설 해답지형

**질문**: 나한테 "이렇게 해주면 진짜 좋아해" 딱 하나만 고르라면

| 선택지 | 내용 |
|---|---|
| A | 예고 없이 서프라이즈 |
| B | 힘든 티 안 내도 먼저 알아채기 |
| C | 사소한 약속도 칼같이 지키기 |
| D | 내 이야기에 리액션 크게 해주기 |

**태그**: 니즈:이벤트형 / 눈치형 / 신뢰형 / 리액션형
**추천도**: ◎ 강력추천 — 질문 자체가 "당신에게 원하는 것"을 직설적으로 묻는 해답지 정공법. 01번 문서 1-2절 원칙에 가장 정확히 부합

### 2-D · 태그+자유서술 하이브리드

**질문**: 요즘 나를 설레게 하는 거 하나 고르고, 왜 그런지 한 줄로 알려줘

| 선택지 | 내용 |
|---|---|
| A | 예상 못한 다정함 |
| B | 나를 자랑스러워해주는 것 |
| C | 내 편이 되어주는 것 |
| D | 함께 있을 때의 편안함 |

**자유 한 줄(선택)**: 예) "지난번에 내가 아무 말 안 했는데 힘든 거 알아채고 안아줬을 때"
**태그**: 설렘축:다정형 / 자부심형 / 지지형 / 편안형 (+ 자유텍스트는 LLM으로 키워드·정서톤 추출)
**추천도**: ◎ 강력추천 — 태그 선택 + 자유 한 줄 하이브리드 요건을 충족하는 후보. 자유란에서 나오는 구체적 사례가 7장 "상대 사용설명서"의 완성도를 가장 크게 끌어올림

### 2-E · 일상 vs 이벤트

**질문**: 기념일보다 나를 더 설레게 하는 건

| 선택지 | 내용 |
|---|---|
| A | 평범한 화요일에 받는 뜬금없는 연락 |
| B | 내가 싫어하는 티 냈던 걸 기억해서 안 해주는 것 |
| C | 힘든 하루 끝에 와주는 문자 한 통 |
| D | "네 덕분에"라는 말 한마디 |

**태그**: 설렘포인트:일상형 / 배려기억형 / 타이밍형 / 인정형
**추천도**: ○ 무난 — 기념일 이벤트 vs 일상 다정함 대비축이 뚜렷해 해답지로서 실용성 있음

### 2-F · 언어적 해답지

**질문**: 이런 말 들으면 하루 종일 기분 좋음

| 선택지 | 내용 |
|---|---|
| A | "너 오늘 진짜 고생했다" |
| B | "너 이런 거 진짜 잘한다, 멋있다" |
| C | "너 없으면 안 될 것 같아" |
| D | "그냥 너라서 좋아" |

**태그**: 언어니즈:인정형 / 칭찬형 / 필요형 / 존재형
**추천도**: ○ 무난 — 언어적 해답지로 유용하나 1-D(애정표현 언어형)와 축이 겹쳐 두 문항 함께 채택 시 정보 중복

### 2-G · 설렘 포인트 변화 (비교 프레임)

**질문**: 연애 초반과 비교하면, 요즘 나를 설레게 하는 건

| 선택지 | 내용 |
|---|---|
| A | 여전히 이벤트, 서프라이즈 위주 |
| B | 이제는 편안함, 일상의 안정감 |
| C | 나를 성장시켜주는 자극 |
| D | 무조건적인 내 편이라는 확신 |

**태그**: 설렘변화:이벤트지속형 / 안정추구형 / 자극추구형 / 신뢰추구형
**추천도**: △ 보류 — 정보 가치는 있으나 "초반보다 못하다"는 뉘앙스로 읽힐 위험이 커 우선순위 낮음
**⚠️ 지뢰**: 비교 프레임 자체가 "요즘 설렘이 식었다"는 인상을 줄 수 있어 상대가 서운해할 가능성 있음

### 2-H · 취급설명서형

**질문**: 상대가 "이것만 알아도 반은 성공"이라고 할 만한 나의 포인트는?

| 선택지 | 내용 |
|---|---|
| A | 나는 말보다 행동을 봐야 믿는 사람 |
| B | 나는 사소한 걸 오래 기억하는 사람 |
| C | 나는 리액션을 잘 받아야 힘이 나는 사람 |
| D | 나는 혼자만의 시간이 필요한 사람 |

**태그**: 관계운영힌트:행동신뢰형 / 기억중시형 / 리액션필요형 / 독립형
**추천도**: ○ 무난 — 7장 "상대 사용설명서"와 직결도가 높지만, "설렘"보다는 "취급설명서"에 가까워 2장의 정서적 톤(두근거림)과는 결이 약간 다름

## 제3장 — 🔞 은밀한 궁합

**설계 원칙**: 수위는 직설적으로(청월당 '유혹비책' 수준), 다만 커플 관계 안에서의 친밀도·선호·리듬을 다루는 것이지 노골적 묘사가 목적은 아니다. 연령 확인 게이트 뒤에만 노출된다는 전제로, 무드 조성 → 자극 포인트 → 리듬 → 주도권 → 소통 → 애프터케어까지 축을 넓게 배치했다.

### 3-A · 무드 조성 방식

**질문**: 둘만의 시간, 나는 보통 무드를 어떻게 만들어?

| 선택지 | 내용 |
|---|---|
| A | 말보다 분위기(조명, 음악)로 자연스럽게 |
| B | 스킨십으로 천천히 신호를 보낸다 |
| C | 직접적으로 말로 물어본다 |
| D | 상대가 리드해주길 기다린다 |

**태그**: 은밀함무드:분위기형 / 스킨십형 / 직설형 / 수용형
**추천도**: ◎ 강력추천 — 무드 조성 방식의 차이는 실제 커플 사이의 잦은 미스커뮤니케이션 요인이며, 직설적이되 품위 있게 구성됨

### 3-B · 자극 포인트

**질문**: 이럴 때 스위치 켜짐

| 선택지 | 내용 |
|---|---|
| A | 예상 못한 순간의 스킨십 |
| B | 서로 눈 맞추고 대화를 나눈 뒤 |
| C | 평소와 다른 모습(향수, 옷차림 등)을 봤을 때 |
| D | 편안하고 안전하다고 느껴질 때 |

**태그**: 자극포인트:돌발형 / 정서형 / 시각형 / 안정형
**추천도**: ◎ 강력추천 — 청월당 '유혹비책' 수준의 직설적 톤이면서 자극 유형 데이터로서 리포트 활용도가 높음

### 3-C · 리듬(빈도) 선호

**질문**: 리듬(빈도), 나는 어느 쪽?

| 선택지 | 내용 |
|---|---|
| A | 자주 확인하고 싶은 편 |
| B | 텀을 두고 진하게가 좋은 편 |
| C | 그때그때 컨디션 따라 다르다 |
| D | 빈도보다 얼마나 좋았는지가 중요하다 |

**태그**: 리듬:빈도추구형 / 텀추구형 / 가변형 / 질추구형
**추천도**: ◎ 강력추천 — 은밀한 궁합의 본질적 축. 빈도 불일치는 실제 최상위 갈등 요인이지만 무료 구간에 노출되지 않고 해법 파트가 뒤따르므로 오히려 제품 취지에 정확히 부합
**⚠️ 지뢰**: 결과가 적나라하게 드러나면 상처가 될 수 있음. 단, 결제 후 블러 해제 구간에만 노출되고 "해법" 카드가 항상 동반되므로 위험은 관리 가능한 수준

### 3-D · 주도권 선호

**질문**: 주도권, 나는 어느 쪽이 편해?

| 선택지 | 내용 |
|---|---|
| A | 내가 리드하는 게 편하다 |
| B | 상대가 리드해주는 게 편하다 |
| C | 그때그때 바뀌는 게 좋다 |
| D | 리드보다 합이 맞는 게 중요하다 |

**태그**: 주도성:주도형 / 수용형 / 전환형 / 합형
**추천도**: ○ 무난 — 직설적이면서도 선택지가 품위 있게 구성됨. 1-F(스킨십 주도권)와 축이 겹치므로 둘 중 하나만 채택 권장

### 3-E · 소통 방식

**질문**: 원하는 걸 표현하는 방식은?

| 선택지 | 내용 |
|---|---|
| A | 그 순간 원하는 걸 직접 말하는 편 |
| B | 말보다 반응(행동)으로 보여주는 편 |
| C | 상대가 물어보면 그때 말한다 |
| D | 말로 하기 좀 부끄럽다 |

**태그**: 소통방식:직설형 / 행동형 / 반응형 / 수줍음형
**추천도**: ○ 무난 — 소통 방식은 실제 만족도에 큰 영향을 미치나 3-A(무드 조성)와 축이 일부 중복

### 3-F · 애프터케어 니즈

**질문**: 끝나고 난 뒤, 나에게 중요한 건?

| 선택지 | 내용 |
|---|---|
| A | 꼭 안고 대화하는 여운의 시간 |
| B | 편하게 각자 정리하는 시간 |
| C | 장난스럽게 텐션 유지하기 |
| D | 특별히 안 챙겨도 상관없음 |

**태그**: 애프터케어:여운형 / 독립형 / 장난형 / 무관심형
**추천도**: ◎ 강력추천 — 전희만큼 소외되기 쉬운 애프터케어 니즈를 직접 물어 실질적 해법으로 바로 이어짐. 수위는 낮으면서 정보 가치는 높음

### 3-G · 판타지·로망

**질문**: 판타지·로망이 있다면 어느 쪽에 가까워?

| 선택지 | 내용 |
|---|---|
| A | 색다른 장소, 이벤트성 (여행지, 특별한 날 등) |
| B | 평소와 다른 컨셉이나 역할 |
| C | 안전하고 편안한 익숙함 속의 로망 |
| D | 특별히 없다, 지금이 좋다 |

**태그**: 판타지:이벤트형 / 컨셉형 / 안정형 / 무로망형
**추천도**: ○ 무난 — 흥미도는 높으나 답변이 추상적이라 해법 리포트로의 연결이 다른 후보보다 약함

### 3-H · 거절 방식

**질문**: 내키지 않을 때, 나는 보통?

| 선택지 | 내용 |
|---|---|
| A | 솔직하게 바로 말한다 ("오늘은 좀 그래") |
| B | 돌려서 다른 이유를 댄다 |
| C | 미안해서 일단 맞춰준다 |
| D | 다음을 기약하는 말로 넘긴다 |

**태그**: 거절방식:직설형 / 우회형 / 맞춤형 / 유예형
**추천도**: △ 보류 — 동의·소통 관점에서 정보 가치는 높지만 톤이 자칫 무겁게 흐를 위험이 있어 5,900원 가벼운 제품 무드와 어긋날 수 있음
**⚠️ 지뢰**: C(맞춰준다)가 드러나면 상대가 죄책감을 느낄 수 있음. 다만 "너 억지로 맞춰주고 있었어?"로 이어지는 결과가 오히려 건강한 대화의 트리거가 될 여지도 있어 채택 시 해법 카피의 톤 관리가 중요

## 제4장 — 상대 예측

**설계 원칙**: "상대는 이 문항에 뭐라고 답했을까?"를 맞추는 문항. 앞서 본인이 답한 1~3장 문항 중 하나를 예측 대상으로 삼는다. 선택지는 원문항의 A~D를 그대로 예측용 보기로 제시한다. **예측이 빗나갔을 때 가장 흥미로운 대화가 터지는 문항**을 우선 배치했다.

### 4-A · 예측대상: 갈등 대응 타이밍 (1-I)

**질문**: 상대는 다투고 나면 어떻게 대응한다고 답했을까?
**보기**: 1-I의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:갈등대응
**추천도**: ◎ 강력추천 — 갈등 대응 방식은 스스로도 왜곡해서 인지하는 경우가 많아("나는 안 그런데 쟤가...") 빗나갈 확률이 높고, 빗나갔을 때 "야 나 안 그런데?" 하는 대화가 즉시 터짐

### 4-B · 예측대상: 설렘 포인트 (2-A / 2-C 등)

**질문**: 상대는 이럴 때 설렌다고 답했을까?
**보기**: 2장 채택 문항의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:설렘포인트
**추천도**: ◎ 강력추천 — 연애 기간이 길수록 서로의 설렘 포인트를 "안다고 착각"하는 경향이 커서 격차가 크게 벌어질 확률이 높음. 오답 확인 시 "어 진짜? 몰랐네" 반응이 자연스럽게 나와 유료 "로망 싱크" 섹션과 시너지가 큼

### 4-C · 예측대상: 애정표현 채널 (1-D)

**질문**: 상대는 어떤 표현을 받을 때 사랑받는다고 느낀다고 답했을까?
**보기**: 1-D의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:애정표현
**추천도**: ○ 무난 — "주는 방식"과 "받고 싶은 방식"이 어긋나는 경우가 흔해 좋은 예측 소재이지만, 1장 관계운영 섹션에서 이미 다루는 데이터라 4장에서 재사용 시 결론 중복 방지(6장 원칙)에 유의 필요

### 4-D · 예측대상: 데이트 스타일 (1-B)

**질문**: 상대는 계획형과 즉흥형 중 어느 쪽이라고 답했을까?
**보기**: 1-B의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:데이트스타일
**추천도**: △ 보류 — 표면적으로 드러나는 행동 패턴이라 적중률이 높은 편이어서, "재미"보다 "안도감"으로 흐르기 쉬움. 오답 시의 임팩트가 상대적으로 약함

### 4-E · 예측대상: 은밀한 리듬 (3-C, Yes 선택자만)

**질문**: 상대는 리듬(빈도)에 대해 뭐라고 답했을까?
**보기**: 3-C의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:은밀한리듬
**추천도**: ○ 무난 — 커플이 가장 안 물어보고 넘어가는 주제라 실제 격차가 클 확률이 높고 결과 대조가 "은밀한 온도차" 섹션의 핵심 소재로 바로 이어짐. 다만 예측 시점에 긴장감을 줄 수 있어 문항 톤을 가볍게("니 생각엔 쟤가 뭐 골랐을까~") 조정할 필요

### 4-F · 예측대상: 고민 상담 니즈 (1-H)

**질문**: 상대는 고민이 생겼을 때 어떤 반응을 바란다고 답했을까?
**보기**: 1-H의 선택지 A~D를 그대로 사용
**태그**: 예측대상축:대화니즈
**추천도**: ◎ 강력추천 — 공감형 vs 해결형은 실제 다툼 원인 1순위로 꼽히는 축이면서, 본인은 정반대로 인지하는 경우가 많아("나는 공감해주는데 쟤는 해결책만 던진다") 오답률이 높음. 오답 시 대화가 즉시 터지고, 6장 해석 아키텍처의 "오해의 구조"로 바로 연결되는 최적 후보

## 제5장 — 열린 질문 (자유 서술)

**설계 원칙**: 이 제품의 정서적 마무리. 조건 세 가지를 전부 만족해야 한다 — ① 긍정적인 답변이 나올 것 ② 상대에게 메시지가 전달될 것 ③ 자유롭게 말이 오갈 것. 무료 구간에서 서로에게 공개되므로 불평·불만이 나올 수 있는 프레임은 전부 배제했다.

### 5-A

**질문**: 지금 이 순간, 상대에게 꼭 한마디 하고 싶은 말이 있다면?
**예상 답변 예시**: "항상 옆에 있어줘서 고마워. 요즘 좀 무뚝뚝했는데 사실 더 표현하고 싶었어."
**추천도**: ◎ 강력추천 — 조건 ①②③을 가장 직접적으로 충족. 개방형이지만 "지금 하고 싶은 말"이라는 프레이밍상 고마움/애정 방향으로 수렴할 확률이 높음

### 5-B

**질문**: 우리 연애에서 제일 잘한 결정 하나를 꼽자면?
**예상 답변 예시**: "먼저 고백한 거. 그때 용기 안 냈으면 지금 이 사람 없었을 거야."
**추천도**: ◎ 강력추천 — 과거 회상형이라 불만이 끼어들 여지가 거의 없고, 관계 자체를 긍정적으로 재확인시키는 구조

### 5-C

**질문**: 상대의 이런 점은 진짜 못 따라가겠다, 싶은 장점은?
**예상 답변 예시**: "나는 화나면 티가 다 나는데 얘는 상황 봐가면서 참을 줄 알아. 그게 진짜 대단해."
**추천도**: ○ 무난 — "장점" 프레이밍이지만 "못 따라가겠다"는 표현이 은근한 비교로 읽힐 여지가 있어 5-A/B보다 후순위

### 5-D

**질문**: 이 사람이랑 있으면서 새로 알게 된 내 모습은?
**예상 답변 예시**: "나 원래 이렇게 잘 웃는 사람 아니었는데, 얘 만나고 나서 표정이 많아졌다는 얘기를 들었어."
**추천도**: ◎ 강력추천 — 목표 UX 4번("의외의 모습을 알게 됐다")과 정확히 맞물리는 문항. 자기 성찰형이라 불만이 유입될 여지가 거의 없음

### 5-E

**질문**: 이 사람과 함께한 순간 중 두고두고 생각나는 장면 하나는?
**예상 답변 예시**: "작년 겨울에 편의점 앞에서 컵라면 먹던 거. 별거 아닌데 그날따라 되게 행복했어."
**추천도**: ◎ 강력추천 — 구체적 추억 회상은 감정을 가장 안전하게 긍정적으로 끌어올리는 형태이며 대화 확장성이 최고 수준

### 5-F

**질문**: 상대에게 아직 안 해본 말인데, 지금 해보고 싶은 말은?
**예상 답변 예시**: "나 사실 요즘 결혼 얘기 은근 생각하고 있었어. 무겁게 듣지 말고 그냥 알아만 둬."
**추천도**: △ 보류 — 흥미도는 높으나 통제 불가능한 개방형이라 무거운 고백(권태, 미래 불안 등)이 나올 위험이 있음
**⚠️ 지뢰**: "안 해본 말"이라는 프레이밍 자체가 부정적 주제를 끌어낼 수 있어 조건 ①(긍정적 답변)을 보장하지 못함

### 5-G

**질문**: 상대한테 고맙다고 말 못 했던 거, 지금 하나만 말해준다면?
**예상 답변 예시**: "지난달 나 아팠을 때 말없이 죽 사다준 거, 그때 진짜 고마웠는데 표현을 못 했다."
**추천도**: ◎ 강력추천 — "고맙다"로 방향을 못박아 조건 ①(긍정적 답변)을 구조적으로 보장하면서, "말 못 했던 것"이라는 설정 덕에 조건 ②(새로운 메시지 전달) 가치도 확보

### 5-H

**질문**: 우리 관계를 한 문장으로 정의한다면?
**예상 답변 예시**: "같이 있으면 숨쉬기 편한 사이."
**추천도**: ○ 무난 — 감성적이고 공유하기 좋으나 추상적이라 "그냥 좋은 사이" 식으로 부실하게 나올 위험이 있어 대화 확장성이 5-E/5-G보다 약함
