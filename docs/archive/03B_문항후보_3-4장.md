## 제3장 — 상대 예측

**설계 원칙**: "상대는 이 질문에 뭐라고 답했을까?"를 맞추는 문항. 사용자는 제1·2장에서 자기 응답을 이미 마친 상태로 진입하므로 부담 없이 게임처럼 풀 수 있다. 이 장은 제품에서 가장 재미있어야 하는 구간 — 청월당 '오방기 뽑기'에 해당하는 몰입 장치다. **빗나갈 확률이 구조적으로 높은 축**을 절반 이상 배치해, 결과 대조 시 "어? 나 완전 다르게 생각했는데" 하는 반응이 나오도록 설계했다.

### 3-1 · 다툰 날 밤, 상대는 뭘 하고 있을까

**질문**: 너랑 크게 다툰 날 밤, 상대는 집에 가서 뭘 하고 있을 것 같아?
**예측 대상 축**: 갈등 대응 타이밍

| 선택지 | 내용 |
|---|---|
| A | 당장 전화해서 끝장을 본다. 안 풀고는 잠을 못 잔다 |
| B | 일단 자기부터 재운다. 다음날 멀쩡한 얼굴로 얘기 꺼낸다 |
| C | 먼저 "미안해" 톡부터 보낸다. 누가 잘못했는지는 안 따진다 |
| D | 아무 말 없이 있다가, 다음날 밥 사들고 나타난다 |

**특성 태그**: 갈등대응타이밍:즉시직면형 / 시간필요형 / 선사과형 / 행동화해형
**LLM 추론 재료**:
 - 단독 추론 — 예측 결과 자체가 "상대의 갈등 패턴을 얼마나 정확히 읽고 있는가"의 지표가 된다.
 - 교차 추론 예시 — "이 문항에서 B(시간필요형)로 예측했는데 실제 답이 A(즉시직면형)로 나오면 → '지난 싸움에서 왜 자꾸 바로 전화해서 몰아붙이냐고 느꼈다면, 그건 성격이 급한 게 아니라 안 풀고는 못 견디는 쪽이라 그런 것'이라는 오해 해소형 결론이 나온다."
**재미 포인트**: 예측하면서 "쟤 성격에 딱 저거지" 하고 낄낄대다가 틀리면 바로 "어? 나 완전 다르게 생각했는데" 반응이 터진다.
**추천도**: ◎ — 갈등 대응 방식은 자기 인식과 실제 행동의 괴리가 큰 축이라 예측 문항으로 최적.
**예상 오답률**: 높음 — 사람은 갈등 상황에서 자기 행동을 왜곡해서 인지하는 경향이 강하고("나는 안 그런데 쟤가"), 연애 초반엔 다툰 모습을 직접 볼 기회 자체가 적어 추측이 틀리기 쉽다.

### 3-2 · 연락이 뜸했을 때, 상대는 속으로 어땠을까

**질문**: 너가 요 며칠 바빠서 연락이 뜸했다. 상대는 그럴 때 자기가 어떻게 반응한다고 답했을까?
**예측 대상 축**: 무관심(연락 공백)에 대한 반응

| 선택지 | 내용 |
|---|---|
| A | 서운해도 티 안 낸다. 먼저 연락 올 때까지 그냥 기다린다 |
| B | "바빠?" 톡 한 번은 보낸다. 그 이상은 안 함 |
| C | 이유를 이것저것 상상하다 서운함이 점점 커진다 |
| D | 오히려 안 서운하다. 각자 바쁠 수 있지 하고 넘긴다 |

**특성 태그**: 무관심반응:침묵형 / 최소확인형 / 불안증폭형 / 무던형
**LLM 추론 재료**:
 - 단독 추론 — 연락 빈도로 인한 갈등을 사전에 예방할 수 있는 실전 정보다.
 - 교차 추론 예시 — "이 예측이 빗나갔고 실제 답이 C(불안증폭형)로 나오면 → '평소엔 무던해 보여도 연락이 뜸하면 속으로 불안이 커지는 타입인데 티는 안 낸다'는 결론이 나오고, 관계운영 섹션의 '먼저 연락하는 습관을 만들어야 하는 이유'와 바로 연결된다."
**재미 포인트**: "티 안 낸다"는 겉모습이 침묵형(사실 서운함)과 무던형(진짜 안 서운함)에서 똑같이 나타나서, 정반대인 두 속마음을 헷갈려 틀리는 경우가 재밌게 드러난다.
**추천도**: ◎ — 브리핑의 대표 예시 상황("3일째 연락이 뜸하다")을 예측형으로 살린 문항. 실생활 밀착도가 가장 높다.
**예상 오답률**: 높음 — 침묵형과 무던형은 행동만 보면 구분이 거의 안 되는데 속마음은 정반대라, 오래 사귄 커플도 자주 틀린다.

### 3-3 · 상대는 어떤 순간에 사랑받는다고 느낄까

**질문**: 상대는 "아, 얘가 날 진짜 좋아하는구나" 싶은 순간이 언제라고 답했을까?
**예측 대상 축**: 애정표현 채널

| 선택지 | 내용 |
|---|---|
| A | "잘했어", "고생했어" 같은 말을 들을 때 |
| B | 손 잡거나 안아줄 때 |
| C | 말 안 했는데 필요한 걸 먼저 챙겨줄 때 |
| D | 바쁜 와중에도 옆에 있어줄 때 |

**특성 태그**: 애정표현채널:언어형 / 접촉형 / 행동형 / 존재형
**LLM 추론 재료**:
 - 단독 추론 — 애정표현 궁합의 핵심 원재료. 예측 정확도 자체가 "표현 채널을 얼마나 이해하고 있나"를 보여준다.
 - 교차 추론 예시 — "이 예측(B 접촉형)이 실제 답(A 언어형)과 다르고, 관계운영 문항에서 '나는 주로 스킨십으로 애정표현한다'가 나오면 → '정작 상대가 원하는 채널은 안 쓰고 있었다'는 명확한 실행 지침이 나온다. 이건 7장 상대 사용설명서로 그대로 회수된다."
**재미 포인트**: 내가 표현하는 방식과 상대가 원하는 방식을 같다고 착각하는 경우가 많아, 예측할 때 자기 취향을 투사하다 틀린다.
**추천도**: ◎ — 예측 실패 시 즉시 실행 가능한 조언으로 이어지는 축.
**예상 오답률**: 중간 — 오래 사귄 커플은 어느 정도 파악하고 있지만, 초기 커플이나 표현이 서툰 커플은 잘 틀린다. 전반적으로 중간 수준.

### 3-4 · 상대는 언제 완전 설렌다고 답했을까

**질문**: 상대는 이럴 때 완전 설렌다고(두근거림 폭발) 답했을까?
**예측 대상 축**: 설렘 포인트

| 선택지 | 내용 |
|---|---|
| A | 무심한 척 툭 챙겨줄 때 (말 안 했는데 알아서) |
| B | 나만 아는 다른 모습을 보여줄 때 |
| C | 사람들 앞에서 내 편을 들어줄 때 |
| D | 바쁜데도 시간 쪼개서 연락해줄 때 |

**특성 태그**: 설렘포인트:배려형 / 반전매력형 / 편들기형 / 시간투자형
**LLM 추론 재료**:
 - 단독 추론 — 로망·이상형 섹션의 핵심 원재료. "지금도 유효한 설렘 포인트"를 짚어준다.
 - 교차 추론 예시 — "예측 실패 + 갈등 대응 축(즉시직면형)이 결합되면 → '이 사람은 갈등은 빨리 풀고 싶어하지만, 평소 설렘은 조용히 알아채주는 쪽에서 온다'는 식으로 '로망이 무너지는 지점'을 짚는 결론이 나온다."
**재미 포인트**: "이 정도는 알지" 하다가 의외로 틀리는 대표 문항 — 오래된 커플일수록 자신만만하게 골랐다가 허를 찔린다.
**추천도**: ◎ — 결제 후 "로망 싱크" 섹션과 시너지가 가장 큰 예측 문항.
**예상 오답률**: 높음 — 설렘 포인트는 시간이 지나며 계속 바뀌고 본인도 정확히 언어화하지 못하는 경우가 많아, 파트너의 예측이 특히 잘 빗나간다.

### 3-5 · 힘든 얘기 꺼낼 때, 상대가 진짜 원하는 반응은

**질문**: 상대가 회사 일로 스트레스받은 얘기를 너한테 꺼낸다. 상대는 그럴 때 진짜 원하는 반응이 뭐라고 답했을까?
**예측 대상 축**: 고민 상담 니즈 (공감형 vs 해결형)

| 선택지 | 내용 |
|---|---|
| A | 일단 "헐 진짜 힘들었겠다" 공감부터 |
| B | "그래서 이렇게 해보는 건 어때" 해결책 |
| C | 내가 먼저 말 꺼낼 때까지 그냥 기다려주는 것 |
| D | 화제 돌려서 기분부터 풀어주는 것 |

**특성 태그**: 대화니즈:공감형 / 해결형 / 대기형 / 전환형
**LLM 추론 재료**:
 - 단독 추론 — 실제 다툼 원인 1순위로 꼽히는 축("나는 도와주려고 한 건데 왜 화내?")의 원재료.
 - 교차 추론 예시 — "예측 실패(해결형으로 예상했으나 실제는 공감형) + 갈등 대응 축(즉시직면형)이 결합되면 → '이 사람은 갈등은 빨리 풀고 싶어하지만, 평소 고민은 그냥 들어주기만 해도 충분한 타입'이라는 구체적 실행 지침이 나온다."
**재미 포인트**: 자기가 상대와 같은 유형일 거라고 투사해서 예측하는 경향이 강해, 자기 답을 그대로 골랐다가 틀리는 경우가 흔하다.
**추천도**: ◎ — 다툼 원인 1순위 축을 예측 게임으로 안전하게 풀어내는 문항.
**예상 오답률**: 높음 — "나라면 이럴 텐데 쟤도 그렇겠지"라는 투사 편향이 특히 강하게 작동하는 축으로 알려져 있다.

### 3-6 · 이번 주말 데이트, 상대는 어느 쪽일까

**질문**: 이번 주말 데이트, 상대는 어느 쪽에 더 끌린다고 답했을까?
**예측 대상 축**: 데이트 스타일 (계획형 vs 즉흥형)

| 선택지 | 내용 |
|---|---|
| A | 예약부터 동선까지 완벽하게 짠 코스 |
| B | 일단 만나서 그때그때 정하기 |
| C | 큰 틀만 정하고 세부는 즉흥으로 |
| D | 상대가 짜온 대로 따라가는 게 편함 |

**특성 태그**: 데이트스타일:계획형 / 즉흥형 / 절충형 / 위임형
**LLM 추론 재료**:
 - 단독 추론 — 관계운영 궁합 리포트에 필요한 기본 축.
 - 교차 추론 예시 — "이 문항은 대체로 정답이 잘 맞는 편이라, 다른 예측 문항(예: 3-5)에서 오답이 나온 것과 대비시켜 '겉으로 드러나는 건 잘 알지만 속마음은 아직 모른다'는 리포트 문장의 근거로 쓸 수 있다."
**재미 포인트**: 대부분 맞혀서 "역시 나 너 잘 알지" 하는 으쓱함이 나오는 문항 — 예측 세트 전체가 다 틀리면 좌절감만 남기 때문에 이런 '맞히는 재미'도 하나는 필요하다.
**추천도**: ○ — 오답률이 낮아 안전판 역할. 다른 고오답률 문항과 세트로 채택할 때 균형추로 유용.
**예상 오답률**: 낮음 — 데이트 스타일은 겉으로 드러나는 행동 패턴이라 몇 번만 같이 다녀봐도 대체로 파악된다.

### 3-7 · 상대가 서운할 때, 티가 날까 안 날까

**질문**: 상대가 속상한 게 있는데 너가 눈치를 못 챘다. 상대는 그럴 때 보통 어떻게 한다고 답했을까?
**예측 대상 축**: 서운함 표현 방식

| 선택지 | 내용 |
|---|---|
| A | 티 안 내고 그냥 넘어간다 (알아서 눈치채길 바람) |
| B | "나 삐졌어" 하고 바로 말한다 |
| C | 한숨, 단답 등으로 은근히 티를 낸다 |
| D | 시간이 지나면 그냥 괜찮아진다 |

**특성 태그**: 갈등표현:회피형 / 직면형 / 암시형 / 자연소멸형
**LLM 추론 재료**:
 - 단독 추론 — 회피형·암시형 조합이면 "지금까지 놓친 신호가 있었을 수 있다"는 경고성 인사이트로 이어진다.
 - 교차 추론 예시 — "예측(B 직면형)이 실제 답(C 암시형)과 다르면 → '지금까지 한숨이나 단답을 그냥 넘겼다면, 사실 그게 신호였을 수 있다'는 실전 조언으로 바로 연결된다."
**재미 포인트**: "쟤 원래 잘 삐지는데 티는 안 냄" 같은 자기 규정과 실제 행동이 다른 경우가 많아 반전이 잘 나온다.
**추천도**: ◎ — 3-1(갈등 타이밍)과 짝을 이루면 "싸운 뒤"와 "서운한데 안 싸운 순간" 두 각도를 모두 커버.
**예상 오답률**: 중간 — 암시형과 자연소멸형은 겉보기엔 비슷해 헷갈리기 쉽지만, 회피형·직면형은 비교적 구분이 잘 된다.

### 3-8 · 진짜 지친 날, 상대는 뭐가 회복될까

**질문**: 상대는 진짜 지친 날, 뭐가 제일 회복된다고 답했을까?
**예측 대상 축**: 스트레스 회복 방식

| 선택지 | 내용 |
|---|---|
| A | 아무도 없이 혼자 있는 시간 |
| B | 아무 말 안 해도 그냥 옆에 있어주는 것 |
| C | 나가서 기분 전환할 거리를 만드는 것 |
| D | 실컷 얘기하고 다 털어내는 것 |

**특성 태그**: 스트레스회복:독립형 / 존재형 / 전환형 / 토로형
**LLM 추론 재료**:
 - 단독 추론 — 힘든 시기에 어떻게 곁을 지켜줘야 하는지 알려주는 실전 정보.
 - 교차 추론 예시 — "평소 데이트 에너지 축에서 '내향형'으로 답한 사람이 스트레스 회복은 B(존재형)로 나오면 → '혼자 있고 싶어하는 것처럼 보여도, 정작 힘들 땐 곁을 원하는 사람'이라는 미묘하지만 중요한 구분을 짚어줄 수 있다."
**재미 포인트**: 평소 성격(내향/외향)으로 유추해서 예측했다가, 정반대인 걸 알고 놀라는 반응이 잘 나온다.
**추천도**: ○ — 정보 가치는 높지만 3-2(무관심 반응)와 정서적 결이 비슷해 함께 채택 시 균형 재검토 필요.
**예상 오답률**: 중간 — 평소 성격으로 어느 정도는 유추 가능하지만, "혼자 vs 옆에 있어주길"은 실제로 자주 헷갈리는 지점이라 완전히 낮지는 않다.

## 제4장 — 🔞 은밀한 궁합

**설계 원칙**: 연령 확인 게이트와 별도 동의 뒤에만 노출된다. 수위는 직설적으로 가되, 목적은 노골적 묘사가 아니라 **서로의 무드·리듬·주도권·소통·마무리 방식을 확인하는 것**이다. 필수 커버 축(무드·시작 신호 / 리듬과 빈도 / 주도권 / 소통 / 애프터케어 / 거절과 표현 / 새로운 시도 / 로망·판타지) 8개에 웃음 포인트를 담당하는 축 1개(방해요소 대처)를 더해 총 9개를 제시했다. 9개 중 **4-1, 4-9 두 문항을 유쾌한 톤**으로 설계해, 장 전체가 진지하기만 해서 이탈하는 걸 막는다.

### 4-1 · 나만 안다고 믿는 그 신호

**질문**: 나만 안다고 착각하는 "오늘 그거 하자" 시그널이 있다. 상대한테 그 신호, 어떻게 보내?

| 선택지 | 내용 |
|---|---|
| A | 말없이 조명 낮추고 음악부터 튼다 |
| B | 스킨십 강도를 슬쩍 올리며 반응을 본다 |
| C | "오늘 뭐해?" 하고 대놓고 물어본다 |
| D | 딱히 신호는 안 보낸다. 상대가 먼저 오길 기다린다 |

**특성 태그**: 시작신호:분위기형 / 스킨십형 / 직설형 / 수용형
**LLM 추론 재료**:
 - 단독 추론 — 무드 시작 지점의 소통 오류는 실제 커플 사이 미스커뮤니케이션의 흔한 원인이다.
 - 교차 추론 예시 — "이 답(분위기형) + 소통 축(수줍음형)이 결합되면 → '신호를 보내긴 하는데 알아채기 어려운 방식이라 상대가 자주 놓친다'는 결론이 나온다."
**재미 포인트**: 다들 은근히 "나만의 신호"가 있다고 믿는데 정작 상대는 전혀 눈치 못 채고 있었다는 게 드러나는 문항 — 질문 자체의 자기고백적 문구("착각한다")가 웃음 포인트다.
**추천도**: ◎ — 무드 시작점은 실제 오해가 가장 많이 생기는 지점이면서, 톤은 가볍게 열 수 있는 문항이라 4장의 도입에 적합.
**⚠️ 지뢰**: 없음.

### 4-2 · 리듬, 솔직히 어느 쪽

**질문**: 리듬(빈도), 솔직히 나는 어느 쪽에 더 가까워?

| 선택지 | 내용 |
|---|---|
| A | 자주 확인하고 싶은 편 (며칠 비면 좀이 쑤신다) |
| B | 텀을 두고 진하게가 좋은 편 |
| C | 그날 컨디션에 따라 완전히 달라진다 |
| D | 빈도보다 그날 얼마나 잘 맞았는지가 훨씬 중요하다 |

**특성 태그**: 리듬:빈도추구형 / 텀추구형 / 가변형 / 합추구형
**LLM 추론 재료**:
 - 단독 추론 — 은밀한 궁합의 본질적 축이자 실제 최상위 갈등 요인.
 - 교차 추론 예시 — "이 답(가변형) + 스트레스 회복 축(3-8, 독립형)이 결합되면 → '지친 날엔 오히려 빈도가 떨어지는 유형'이라는 해석이 가능하고, 이건 컨디션 탓이지 애정 문제가 아니라는 안심 카피로 이어진다."
**재미 포인트**: 직설적인 만큼 재미보다는 정보성이 강한 문항.
**추천도**: ◎ — 빈도 불일치는 실제 최상위 갈등 요인이지만, 결제 후 블러 구간에서만 노출되고 해법 카드가 항상 동반되므로 제품 취지에 정확히 부합한다.
**⚠️ 지뢰**: 결과가 적나라하게 드러나면 상처가 될 수 있다. 결제 후 블러 해제 구간에만 노출되고 "해법" 카드가 항상 동반되므로 위험은 관리 가능한 수준.

### 4-3 · 리드는 누가

**질문**: 그 시간, 나는 누가 리드하는 게 제일 편해?

| 선택지 | 내용 |
|---|---|
| A | 내가 리드하는 게 편하다 |
| B | 상대가 리드해주는 게 편하다 |
| C | 그때그때 바뀌는 게 좋다 |
| D | 리드보다 합이 맞는 게 훨씬 중요하다 |

**특성 태그**: 주도권:주도형 / 수용형 / 전환형 / 합형
**LLM 추론 재료**:
 - 단독 추론 — 실행 단계로 바로 연결되는 궁합 재료.
 - 교차 추론 예시 — "이 답(수용형) + 4-1 시작신호 축(수용형)이 겹치면 → '둘 다 상대가 먼저 오길 기다리는 타입이면, 애초에 시작 자체가 잘 안 될 수 있다'는 재밌는 경고 문장이 나온다."
**재미 포인트**: 두 사람이 똑같이 "상대가 리드해주길" 골랐을 때 "그래서 둘 다 기다리고만 있었던 거야?" 하는 웃긴 반전이 나온다.
**추천도**: ◎ — 4-1과 교차했을 때 나오는 결론이 가장 실용적이면서 재밌는 조합 중 하나.
**⚠️ 지뢰**: 없음.

### 4-4 · 원하는 걸 말로 하는 편인가

**질문**: 원하는 게 있을 때, 나는 보통 어떻게 표현해?

| 선택지 | 내용 |
|---|---|
| A | 그 순간 바로 말로 요청한다 |
| B | 말없이 행동이나 반응으로 티를 낸다 |
| C | 상대가 물어보면 그때 말한다 |
| D | 말로 하기 부끄러워서 거의 못 한다 |

**특성 태그**: 소통방식:직설형 / 행동형 / 반응형 / 수줍음형
**LLM 추론 재료**:
 - 단독 추론 — 만족도와 직결되는 소통 격차를 파악하는 핵심 문항.
 - 교차 추론 예시 — "이 답(수줍음형) + 거절 표현 축(4-6, 맞춤형)이 결합되면 → '원하는 것도 못 말하고 싫은 것도 못 말리는 타입'이라는, 사용설명서의 핵심 결론이 나온다."
**재미 포인트**: 중간 — 재미보다는 정보성이 앞서는 문항.
**추천도**: ○ — 정보 가치는 높지만 단독으로는 임팩트가 약해, 4-6과 교차될 때 가치가 커지는 문항.
**⚠️ 지뢰**: 없음.

### 4-5 · 끝나고 난 뒤 5분

**질문**: 끝나고 난 뒤 5분, 나한테 제일 중요한 건?

| 선택지 | 내용 |
|---|---|
| A | 꼭 안고 얘기 나누는 여운의 시간 |
| B | 각자 편하게 정리하는 시간 |
| C | 장난치면서 텐션 유지하기 ("나 어땠어" 놀리기 등) |
| D | 딱히 안 챙겨도 상관없다. 바로 핸드폰 봐도 됨 |

**특성 태그**: 애프터케어:여운형 / 독립형 / 장난형 / 무심형
**LLM 추론 재료**:
 - 단독 추론 — 전희만큼 소외되기 쉬운 애프터케어 니즈를 직접 발굴하는 문항.
 - 교차 추론 예시 — "이 답(여운형) + 대화 니즈 축(3-5, 공감형)이 결합되면 → '평소에도 그렇지만 이 순간에도 그냥 말없이 안아만 줘도 충분한 사람'이라는 결론이 나온다."
**재미 포인트**: 중간 — D를 고른 쪽이 살짝 서운하게 비칠 수 있어 위트 있게 다뤄야 하는 문항.
**추천도**: ◎ — 전희·과정만큼 소외되는 니즈를 실질적 해법으로 바로 이어주는 축. 수위는 낮은데 정보 가치는 높다.
**⚠️ 지뢰**: D(핸드폰 봐도 됨)가 무심하게 비칠 수 있음. 해석 카피에서 "무심형=애정 없음이 아니라 텐션을 빨리 회복하는 타입"으로 순화 필요.

### 4-6 · 오늘은 내키지 않을 때

**질문**: 오늘은 내키지 않을 때, 나는 보통 어떻게 해?

| 선택지 | 내용 |
|---|---|
| A | 솔직하게 바로 말한다 ("오늘은 좀 그래") |
| B | 다른 핑계를 대며 돌려 말한다 ("나 피곤해서") |
| C | 내키지 않아도 일단 맞춰준다 |
| D | "다음에" 하고 슬쩍 넘긴다 |

**특성 태그**: 거절방식:직설형 / 우회형 / 맞춤형 / 유예형
**LLM 추론 재료**:
 - 단독 추론 — 동의와 소통의 건강도를 진단하는 문항.
 - 교차 추론 예시 — "이 답(맞춤형) + 소통 축(4-4, 수줍음형)이 결합되면 → '말을 못 해서 맞춰주고 있었을 가능성'이 있다는 경고성 조언이 나오고, 이건 관계에 실질적으로 중요한 조언이 된다."
**재미 포인트**: 낮은 편 — 톤 관리가 필요한 문항.
**추천도**: ○ — 정보 가치는 높지만 무거워질 위험이 있어, 유쾌한 해석 카피로 감싸야 채택 가능.
**⚠️ 지뢰**: C(맞춰준다)가 드러나면 상대가 죄책감을 느낄 수 있다. 해법 카피는 "억지로 맞추지 말고 솔직하게 말해도 괜찮다"는 톤으로 순화할 것.

### 4-7 · 안 해본 걸 시도해보자고 하면

**질문**: 안 해본 걸 시도해보자고 하면, 나는?

| 선택지 | 내용 |
|---|---|
| A | 완전 좋다. 오히려 내가 먼저 제안하는 편이기도 함 |
| B | 상대가 먼저 얘기하면 어지간하면 오케이 |
| C | 궁금하긴 한데 먼저 말 꺼내기는 부끄럽다 |
| D | 지금 이대로가 제일 좋다. 안 바꿔도 됨 |

**특성 태그**: 새로운시도:주도적개방형 / 수용적개방형 / 소극적호기심형 / 안정추구형
**LLM 추론 재료**:
 - 단독 추론 — 판타지 축과 직결되는 개방성 지표.
 - 교차 추론 예시 — "이 답(소극적호기심형) + 판타지 축(4-8, 컨셉형)이 결합되면 → '머릿속엔 궁금한 게 있는데 먼저 말은 절대 못 꺼내는 타입'이라는 구체적 결론이 나온다."
**재미 포인트**: 중간~높음 — "나 사실 궁금한 거 있었는데" 하는 실제 대화가 터질 가능성이 높은 문항.
**추천도**: ◎ — 판타지 축과 짝을 이룰 때 가장 실용적인 결론이 나오는 문항.
**⚠️ 지뢰**: D를 고른 쪽이 A·B를 고른 상대에게 위축감을 줄 수 있다. "지금이 좋다"도 존중받아야 할 취향임을 해석 카피에서 명시할 것.

### 4-8 · 판타지가 있다면

**질문**: 판타지·로망이 있다면 어느 쪽에 가까워?

| 선택지 | 내용 |
|---|---|
| A | 색다른 장소, 특별한 날 (여행지, 이벤트 등) |
| B | 평소와 다른 컨셉이나 역할 |
| C | 안전하고 편안한 익숙함 속의 로망 |
| D | 특별히 없다. 지금 이대로가 좋다 |

**특성 태그**: 판타지:이벤트형 / 컨셉형 / 안정형 / 무로망형
**LLM 추론 재료**:
 - 단독 추론 — 로망 데이터로서 결제 후 섹션에 활용도가 높다.
 - 교차 추론 예시 — "이 답(컨셉형) + 새로운 시도 축(4-7, 소극적호기심형)이 결합되면 → '판타지는 있는데 절대 먼저 말을 꺼내지 않을 사람'이라는 결론이 나온다."
**재미 포인트**: 중간.
**추천도**: △ — 흥미도는 있으나 답변이 다소 추상적이라 단독으로는 해법 리포트로의 연결이 다른 후보보다 약하다. 4-7과 짝을 이룰 때만 가치가 크게 오른다.
**⚠️ 지뢰**: 없음.

### 4-9 · 한창 좋은 분위기인데 배에서 꼬르륵

**질문**: 한창 좋은 분위기인데 배에서 꼬르륵 소리가 난다. 혹은 하필 그때 전화벨이 울린다. 나는?

| 선택지 | 내용 |
|---|---|
| A | 일단 무시하고 계속 간다. 티도 안 낸다 |
| B | 빵 터져서 분위기고 뭐고 같이 웃는다 |
| C | 잠깐 끊고 처리한 다음 다시 이어간다 (전화 받거나 뭐 좀 먹거나) |
| D | 오히려 그때부터 텐션이 확 식는다 |

**특성 태그**: 방해요소대처:무시돌파형 / 유쾌전환형 / 일시정지형 / 텐션저하형
**LLM 추론 재료**:
 - 단독 추론 — 사소하지만 실제로 자주 겪는 상황이라 현실감각·유머감각 궁합을 보여주는 실용적인 문항.
 - 교차 추론 예시 — "이 답(유쾌전환형) + 대화 니즈 축(3-5, 전환형)이 결합되면 → '평소에도 분위기가 어색해지면 유머로 넘기는 걸 잘 받아들이는 타입'이라는 결론이 나온다."
**재미 포인트**: 최상 — 이 문항 자체가 웃음 포인트다. "완전 B야 우리 둘 다" 하고 같이 웃게 되는 문항.
**추천도**: ◎ — 9개 중 유쾌 톤을 전담하는 문항. 4장 중간에 배치해 텐션을 한 번 풀어주는 역할로 추천.
**⚠️ 지뢰**: 없음.

## 제3장 추천 3문항 조합

**추천: 3-5(고민 상담 니즈) · 3-3(애정표현 채널) · 3-6(데이트 스타일)**

- **오답률 분포**: 3-5(높음) · 3-3(중간) · 3-6(낮음) — 높음·중간·낮음이 정확히 1개씩 섞이도록 구성했다. 전부 높음이면 "우리 진짜 서로 몰랐네"라는 좌절감만 남고, 전부 낮음이면 "다 맞혔는데 그래서 뭐"라는 심심함만 남는다. 이 조합은 한 번은 크게 틀려서 대화가 터지고(3-5), 한 번은 애매하게 갈려서 흥미롭고(3-3), 한 번은 대체로 맞혀서 "그래도 우리 아는 것도 있네" 하는 안도감으로 마무리된다.
- **주제 다양성**: 갈등기(3-5) · 애정표현(3-3) · 데이트 운영(3-6) — 관계의 서로 다른 세 국면을 하나씩 짚어, 예측 게임이 한 주제에 쏠리지 않는다.
- **다음 장과의 연결**: 3-5는 갈등 대응 방식과 직결되어 결제 후 "관계운영 궁합" 섹션의 핵심 근거가 되고, 3-3은 "상대 사용설명서"로 바로 회수되며, 3-6은 예측 세트 안에서 유일하게 "잘 맞았다"는 성취감을 담당해 제3장 전체가 좌절감으로만 끝나지 않게 잡아준다.

## 제4장 추천 3문항 조합

**추천: 4-1(나만 안다고 믿는 그 신호) · 4-9(방해요소 대처) · 4-5(끝나고 난 뒤 5분)**

세 문항이 하나의 서사로 읽힌다.

- **시작 — 4-1**: "그 시간"이 시작되는 순간, 서로 신호를 어떻게 주고받는지부터 연다. 유쾌한 자기고백형 질문이라 19금 장 진입 직후의 긴장을 풀어주는 역할도 한다.
- **과정 — 4-9**: 한창 진행 중에 벌어지는 리얼한 방해요소(꼬르륵, 전화벨)에 어떻게 반응하는지를 물어, 무겁지 않게 텐션을 유지하면서도 실제 관계에서 자주 벌어지는 순간을 짚는다. 4장 전체가 진지하기만 하면 이탈하므로, 서사 중간에 웃음 포인트를 배치했다.
- **마무리 — 4-5**: 끝난 직후 5분, 애프터케어 니즈로 서사를 마무리한다. 시작(신호) → 과정(방해요소 대처) → 마무리(여운)로 이어지는 하나의 완결된 장면이 되어, 19금 장이 자극의 나열이 아니라 **한 번의 온전한 순간을 함께 그려보는 경험**으로 읽힌다.

리듬·빈도(4-2), 주도권(4-3) 같은 축은 정보 가치는 높지만 이 조합에서는 제외했다. 이유는 두 가지다 — ① 이미 채택된 세 문항만으로도 "시작-과정-마무리"라는 서사가 완결되고, ② 리듬·주도권·거절 같은 무거운 축까지 더하면 3문항 예산 안에서 톤이 과도하게 진지해져 4-9가 담당하는 유쾌함이 희석된다. 다만 리듬(4-2)과 주도권(4-3)은 정보 가치가 매우 높으므로, 추후 유료 확장팩(청월당 `추가질문` 구조)의 1순위 후보로 남겨둔다.
