# 사업 전략 리스크 진단 및 권고안

> 질문: "청월당은 사주라는 검증된 수요 위에 있다. 우리는 설문 기반 심리진단인데 온라인 수요가 있을까? 지금 기획을 수정해야 하나, 일단 만들고 봐야 하나?"

---

## 1. 우려의 실체 — 3개로 분해된다

| # | 리스크 | 심각도 |
|---|---|---|
| A | **수요 존재 여부** — 사주는 검색량·지불 이력이 검증됐지만 커플 심리진단은? | 중 |
| B | **진입 마찰** — 설문 + 상대방 필요 = 2중 마찰 | 중 |
| C | **지불 명분 붕괴** — "내가 다 말해줬는데 왜 돈을 내?" | **최상** |

### C가 진짜 문제다

사주는 **정보 비대칭이 명확**하다. 생년월일이라는 최소 정보를 넣으면 내가 모르는 방대한 해석이 나온다. 사용자는 "내가 모르는 걸 알려주니까" 돈을 낸다.

설문은 정반대로 보인다. 내가 14문항을 다 답했는데, 그걸 정리해서 되판다? **자기가 입력한 정보에 돈을 내는 구조**로 인식되는 순간 지불 명분이 무너진다.

### 그런데 이걸 뒤집는 열쇠가 이미 우리 안에 있다

> **내가 모르는 정보 = 상대의 답변**

우리 제품의 정보 비대칭은 사주가 아니라 **상대방**에게서 온다. 실제로 현재 설계는 이미 그 방향이다 — 예측 맞추기, 상대 사용설명서, 로망·19금 블러. **문제는 설계가 아니라 포지셔닝이다.**

---

## 2. 포지셔닝 수정 — 가장 먼저 고쳐야 할 것

| | 현재 | 수정안 |
|---|---|---|
| 카피 | `너희 궁합 몇 점?` | `쟤가 진짜 원하는 게 뭔지 알려줄게` |
| 경쟁 상대 | 사주 궁합 (우리가 진다 — 더 번거로우니까) | **없음** (사주가 절대 못 하는 것) |
| 파는 것 | 우리 관계의 점수 | **상대방의 속마음** |
| 지불 명분 | 진단 결과 | **내가 절대 알 수 없는 정보** |

"궁합 진단"이라 부르는 순간 사주와 같은 링에 오르고, 우리는 입력 마찰이 더 크므로 반드시 진다.
**"상대 해독"으로 부르면 사주는 경쟁자가 아니라 못 하는 일을 하는 열등재가 된다.**

---

## 3. 핵심 권고 — 사주를 경쟁자가 아니라 **유입 깔때기**로 쓴다

형님 우려의 정답은 "사주를 피하자"도 "사주랑 싸우자"도 아니다. **사주 수요를 흡수해서 우리 제품으로 밀어 넣는 것**이다.

### 2단 구조

```
[1단 · 무료]  생년월일 2개 입력 → 사주 궁합 점수 + 짧은 해석
              ↑ 진입장벽 0. 청월당과 동일한 검증된 검색 수요를 그대로 흡수
              ↓
        "근데 사주는 타고난 거야.
         너희가 실제로 어떻게 행동하는지는 이걸로 안 나와.
         14문항만 답해봐. 진짜 너희를 보여줄게."
              ↓
[2단 · 유료]  설문 14문항 → 사주 + 설문 통합 리포트 (5,900원)
```

### 왜 이 구조가 강력한가

1. **검증된 수요를 그대로 먹는다.** "사주 궁합", "커플 궁합" 검색 유입은 이미 존재한다. 새 시장을 만들 필요가 없다.
2. **설문 마찰이 극적으로 줄어든다.** 사주 결과를 이미 본 상태 = 심리적 투자가 발생한 상태에서 설문을 요청하므로, 맨몸으로 설문을 들이대는 것과 완전히 다르다.
3. **차별점이 자동으로 생긴다.** 사주만 파는 곳은 "타고난 것"밖에 못 판다. 우리는 `타고난 것 + 실제 행동`을 판다. 이건 청월당도 못 하는 조합이다.
4. **"내가 말해준 걸 되판다"는 인식이 사라진다.** 리포트가 사주 해석과 섞이면 정보 비대칭이 복원된다.
5. **제작 부담이 작다.** 만세력 계산은 공개 라이브러리로 해결되고, 해석 텍스트는 LLM 생성 대상이다.

### 트레이드오프 (정직하게)
- "점술이 아닌 실용 관계 콘텐츠"라는 순수 포지셔닝은 희석된다.
- 사주 파트의 품질이 낮으면 오히려 신뢰를 깎는다. → **무료 구간은 짧고 정확하게**, 깊이는 유료 설문 파트에서 낸다.

## 4. 타깃을 좁힌다 — 수요가 불확실할수록 넓히면 안 된다

우리 제품은 **커플이 마주 앉아 함께 하는** 구조다. 그런 상황이 실제로 발생하는 순간을 정조준해야 한다.

| 후보 | 검색 수요 | 지불 의사 | 제품 구조 적합성 | 종합 |
|---|---|---|---|---|
| **기념일 (100일·1주년)** | 큼 (`기념일 데이트`, `100일 뭐하지`) | 이벤트성이라 높음 | **최적** — 마주 앉아 할 콘텐츠를 실제로 찾는 순간 | ⭐ |
| 권태기 | 큼 (`권태기 극복`) | 중간 | 좋음 — 대화 촉진이 정확히 니즈 | ○ |
| 결혼 전 | 중간 | **최고** | 좋음 — 다만 문항에 가치관 블록이 필요해짐 | ○ |
| 커플 일반 | — | — | 메시지가 흐려짐 | ✗ |

**권고: "기념일에 둘이 마주 앉아 하는 것"으로 좁힌다.** 제품 구조(1폰 릴레이)와 소비 맥락이 정확히 일치하는 유일한 타깃이다.

## 5. "만들고 볼까" 에 대한 답 — 둘 다 아니다

`일단 만들고 보자`는 **검증 비용이 높을 때** 쓰는 전략이다. 우리는 검증 비용이 극히 낮다.

- 청월당급 일러스트 자산 없이도 핵심 가치(문항 + 리포트)를 테스트할 수 있다
- 문항 후보는 이미 38개 확보돼 있다
- "커플이 실제로 이걸 하고 대화가 터지는가"는 구글폼 + 수동 리포트로 검증된다

**→ 제작 전 2주 검증이 가능하다. 만들고 볼 이유가 없다.**

### 2주 검증 설계

| 단계 | 기간 | 방법 | 판단 기준 |
|---|---|---|---|
| **1. 수요 신호** | 1주 | 랜딩페이지만 제작 + 소액 광고(20~30만원). `결제하기` 클릭 시 "곧 오픈, 알림받기" | **결제 버튼 클릭률**. 이게 진짜 지불 의사 신호다 |
| **2. 가치 검증** | 1주 | 지인 커플 10쌍에 구글폼 + 수동 리포트 전달 | 완주율 70%+ / "대화가 터졌다" 정성 반응 / **"얼마면 내겠나" 응답** |
| **3. 판정** | — | 두 신호가 모두 나오면 제작 착수 | — |

**광고 소재는 반드시 두 버전으로 나눠 테스트한다** — `궁합 진단형` vs `상대 해독형`. 2장의 포지셔닝 가설을 여기서 실측한다.

### 검증 실패 시
지금 기획은 **엔진**이다 — 설문 로직 + LLM 해석 파이프라인 + 캐릭터 자산 + 결제 퍼널 + 공유 카드. 소재만 갈아 끼우면 MBTI 궁합, 별자리 궁합으로 그대로 전환된다. **매몰비용이 작다.** 이것이 지금 기획을 버리지 말아야 할 이유다.

## 6. 보조 장치 — 무료 미끼 선반

청월당 홈에는 `이것도 공짜? 무료라고?` 라는 **무료 미끼 선반이 별도로 존재**한다. 무료 콘텐츠로 유입받아 유료로 전환시키는 구조다.

우리도 본 제품(5,900원) 앞에 **초경량 무료 테스트**를 둔다.
- 3문항짜리 `우리 연애 스타일 테스트` → 결과 공유 카드 → 본 제품 유도
- 사주 궁합 무료 파트도 이 선반의 일부가 된다
- SEO·바이럴 유입원 역할

## 7. 결론 — 권고안 요약

1. **기획을 버리지 않는다.** 설계는 좋다. 문제는 포지셔닝과 유입이다.
2. **포지셔닝을 "궁합 진단" → "상대 해독"으로 바꾼다.** 사주와 같은 링에 오르지 않는다.
3. **사주를 무료 유입 깔때기로 쓴다.** 검증된 수요를 흡수하고, 설문은 유료 전환 장치로 배치한다.
4. **타깃을 "기념일 커플"로 좁힌다.** 제품 구조와 소비 맥락이 일치한다.
5. **2주 검증 후 제작을 결정한다.** 랜딩 광고 + 지인 커플 10쌍.
6. 실패해도 엔진은 남는다. MBTI·별자리로 소재만 교체 가능하다.
