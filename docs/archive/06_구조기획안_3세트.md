# 설문·리포트 구조 기획안 3세트

> 개별 문항에 들어가기 전에 **장(章) 구성**부터 확정한다. 몇 장으로 나눌지, 각 장의 이름과 주제가 무엇인지, 왜 그 순서인지.

## 0. 세 세트에 공통으로 깔리는 것 — 애착 유형 엔진

### 왜 애착 유형인가
| | 효과 |
|---|---|
| 전문성 | 학술적으로 검증된 프레임 → "재미로 만든 테스트"에서 벗어남 |
| 콘텐츠 분량 | 4유형 × 4유형 = **16가지 조합**. 조합마다 다른 서사가 나와 리포트가 저절로 두꺼워짐 |
| 유입 | `애착유형 테스트`는 이미 검색량이 검증된 키워드 → 무료 미끼 콘텐츠로 분리 가능 |
| 재구매 | 관계 단계가 바뀌면 애착 표현도 바뀜 → 재진단 명분 |

### 어떻게 심는가 — 2차원 채점
애착은 유형 4개를 직접 묻는 게 아니라 **두 개의 연속 차원**으로 측정한다.

```
        회피 낮음        회피 높음
불안 낮음   안정형          회피형
불안 높음   불안형          혼란형
```

**모든 선택지에 `불안 점수`와 `회피 점수`를 부여한다.** 예:

| 문항 | 선택지 | 불안 | 회피 |
|---|---|---|---|
| 읽음만 뜨고 1시간 | 폰을 30분에 한 번씩 본다 | **+2** | 0 |
| 〃 | 나도 폰을 덮어두고 딴 일 | 0 | **+1** |
| 다투고 하루 뒤 | 못 참고 먼저 연락 | **+2** | −1 |
| 〃 | 나도 안 한다, 먼저 오길 기다림 | +1 | **+2** |

### 분산 원칙 (핵심)
> **애착 문항을 한 장에 모으지 않는다.**

한 곳에 몰면 유저가 의도를 알아채고 답을 꾸민다. 대신 **모든 장에 최소 2문항씩** 애착 근거를 섞는다. 유저는 끝까지 "연애 취향 테스트"를 한다고 믿지만, 결과에서 애착 유형이 나오는 순간 **"이걸 어떻게 알았지"** 라는 충격이 발생한다. 이게 이 제품 최대의 결제 트리거가 된다.

# 세트 A — 「진료 차트」 구조

**조직 원리: 진단 프로세스 순서** (문진 → 검사 → 소견 → 처방)
캐릭터가 연애 클리닉 원장이므로, 설문과 리포트 전체를 **의료 절차**로 통일한다.

### 설문 (6장)
| 장 | 이름 | 주제 | 애착 근거 |
|---|---|---|---|
| 접수 | **접수창구** | 이름·관계 단계·상대 이름 | — |
| 1 | **1차 문진 — 평소의 당신** | 애정 수신 채널 / 거리 조절 | 회피 ×2 |
| 2 | **2차 문진 — 흔들릴 때의 당신** | 불확실성 대응 / 갈등 타이밍 | **불안 ×2** |
| 3 | **정밀 검사 — 원하는 것** | 설렘 트리거 / 원하는 케어 / 표현 개방성 | 불안·회피 ×2 |
| 4 | **특수 검사 🔞** | 진도·신호·여운 | 회피 ×1 |
| 5 | **상호 문진** | 상대 예측 3문항 | — |
| 6 | **마지막 한마디** | 열린 질문 | — |

### 리포트 (9장)
`종합 소견서` → **`애착 유형 진단서`** → `두 사람 케미 차트` → `관계 운영 소견` → `로망 소견` → `🔞 소견` → `가장 큰 이상 소견 TOP3` → **`처방전`** → `원장의 편지`

### 장점
- 캐릭터·UI·리포트가 **하나의 메타포로 완전 통일**된다. 무료 결과는 `1차 소견서`, 유료는 `정밀 진단서`, 제7장은 `처방전`
- 애착 유형이 `진단서`라는 그릇에 담기면 전문성 인상이 최대치가 된다
- 19금이 `특수 검사`가 되어 "의사 앞이니까" 명분이 성립

### 단점
- 병원 프레임이 무겁게 느껴질 수 있다. 카피 톤으로 계속 눌러줘야 함
- `접수 → 문진 → 검사`가 길어 보이는 착시

# 세트 B — 「관계 온도 지도」 구조

**조직 원리: 심리 축 순서** (불안 차원 → 회피 차원 → 욕구 → 친밀)
애착 2차원 좌표를 **결과의 시각적 주인공**으로 세우고, 설문도 그 차원을 따라 배치한다.

### 설문 (5장)
| 장 | 이름 | 주제 | 애착 근거 |
|---|---|---|---|
| 1 | **가까워질 때** | 불확실성 대응 / 애정 수신 / 확인 욕구 | **불안 ×3** |
| 2 | **멀어질 때** | 거리 조절 / 갈등 타이밍 / 표현 개방성 | **회피 ×3** |
| 3 | **바라는 것** | 설렘 트리거 / 원하는 케어 | 불안·회피 ×2 |
| 4 | **더 가까이 🔞** | 진도·신호·여운 | 회피 ×1 |
| 5 | **너는 어떨까 + 한마디** | 예측 3 + 열린 질문 | — |

### 리포트 (8장)
`우리 좌표` (2D 그래프에 두 사람 점 + 거리) → **`너의 애착 유형`** → `나의 애착 유형` → `이 조합이 만드는 패턴` → `가장 크게 어긋난 곳` → `🔞 온도차` → `해법 카드` → `대화 카드 12`

### 장점
- **구조가 극도로 명료하다.** `가까워질 때 / 멀어질 때` 두 마디로 설문 전체가 설명된다
- 2D 좌표 위에 두 사람 점을 찍는 시각화는 **레이더차트보다 공유성이 훨씬 높다.** 점 사이 거리 하나로 모든 게 읽힘
- 애착이 구조 자체이므로 리포트 분량이 가장 안정적으로 확보됨

### 단점
- 축이 사실상 2개(불안·회피)라 **다른 영역의 콘텐츠가 상대적으로 얇아진다**
- 1장과 2장의 문항 성격이 비슷해 보여 지루할 수 있음
- 애착 의도가 중간에 들킬 위험이 세 세트 중 가장 높다

# 세트 C — 「관계 시간축」 구조

**조직 원리: 연애가 흘러가는 순서**
초기 커플이 실제로 겪는 순서대로 장을 배치한다. 설문이 곧 이야기가 된다.

### 설문 (5장)
| 장 | 이름 | 주제 | 애착 근거 |
|---|---|---|---|
| 1 | **설렘 — 처음 끌렸던 순간** | 설렘 트리거 / 표현 개방성 | 회피 ×1 |
| 2 | **가까워짐 — 둘의 거리** | 거리 조절 / 애정 수신 | **회피 ×2** |
| 3 | **흔들림 — 애매하고 부딪히는 날** | 불확실성 대응 / 갈등 타이밍 / 원하는 케어 | **불안 ×3** |
| 4 | **깊어짐 🔞** | 진도·신호·여운 | 불안·회피 ×1 |
| 5 | **그래서 우리는** | 예측 3 + 열린 질문 | — |

### 리포트 (9장)
`우리 요약` → `설렘의 지도` → `거리의 온도` → **`흔들릴 때 드러나는 것 = 애착 유형`** → `이 조합의 패턴` → `🔞 온도차` → `가장 어긋난 TOP3 + 해법` → `상대 사용설명서` → `언니의 편지`

### 장점
- **완주율이 가장 높다.** 이야기를 따라가는 느낌이라 설문이 설문처럼 안 느껴짐
- `설렘 → 가까워짐 → 흔들림 → 깊어짐`은 초기 커플의 실제 경험 순서와 정확히 일치
- 애착 유형이 `흔들림` 장에서 자연스럽게 나오는 것으로 보여, **의도를 끝까지 숨길 수 있다**
- 장 이름이 감성적이라 캐릭터 대사와 잘 붙는다

### 단점
- 애착 근거가 2·3장에 다소 몰린다 → 1·4장에 보조 문항을 의도적으로 심어 보완 필요
- 클리닉 메타포와 장 이름의 결이 살짝 다르다 (감성 vs 의료)

## 하이브리드 가능성

세 세트는 배타적이지 않다. 실제로 가장 강한 조합은:

> **C의 장 이름과 순서** + **A의 리포트 메타포(진단서·처방전)** + **B의 2D 좌표 시각화**

설문은 감성적 서사로 끌고 가서 완주율을 확보하고(C), 결제 후 리포트에서 갑자기 `진단서` 톤으로 전환해 전문성을 주며(A), 좌표 그래프로 공유 자산을 만든다(B). 다만 톤 전환 지점 설계가 필요하다.
