# 채점 엔진 명세 (규칙 기반 · LLM 불필요)

> 원천: `01_설문지_확정.md` + `archive/04_결제후_챕터구성.md` 2장
> **이 엔진은 LLM을 전혀 쓰지 않는다.** 점수·게이지·격차 지수·애착 좌표는 전부 결정론적으로 산출된다.
> LLM은 이 엔진의 출력을 **입력으로 받아 해설만 쓴다.**

---

## 0. 왜 규칙 기반인가

| | 규칙 기반 | LLM |
|---|---|---|
| 점수·라벨 | ✅ 전 장 게이지, 구간 라벨 | |
| 시각화 데이터 | ✅ 레이더 축값, 대조 매트릭스 | |
| 애착 좌표 | ✅ | |
| 격차 지수·TOP3 선정 | ✅ | |
| 대화 주제 슬롯 선택 | ✅ | |
| **해설 서술** | | ✅ 제2~7장 |
| **대화 주제 개인화 근거** | | ✅ 제8장 |
| **편지 변수 자연어화** | | ✅ 제9장 (경량) |

점수를 LLM에 맡기면 **같은 입력에 다른 점수가 나온다.** 재열람 시 숫자가 바뀌면 신뢰가 즉시 무너진다. 그래서 숫자는 전부 규칙 기반이다.

## 1. 입력 데이터 구조

```ts
type Choice = 1 | 2 | 3 | 4 | 5;

interface PersonAnswers {
  name: string;
  // 제1장
  q1: Choice;  // 애정 수신 채널   (1~4)
  q2: Choice;  // 갈등 처리 타이밍  (1~4)
  q3: Choice;  // 데이트 선호      (1~4)
  q4: Choice;  // 연락 페이스      (1~4)
  // 제2장
  q5: Choice;  // 설렘 트리거      (1~5)  ← 유일한 5택
  q6: Choice;  // 원하는 케어      (1~4)
  q7: Choice;  // 매력 우선순위    (1~4)
  // 제3장 (상대 예측)
  q8: Choice;   // 상대의 q1 예측
  q9: Choice;   // 상대의 q6 예측
  q10: Choice;  // 상대의 q3 예측
  // 제4장 🔞 (게이트 No면 전부 undefined)
  q11?: Choice; // 주도권 성향
  q12?: Choice; // 섹슈얼 매력 포인트
  q13?: Choice; // 여운·애프터
  q14?: string; // 민감 포인트 (자유서술, 원문 보존)
  // 제5장
  q15: string;  // 바라는 것 하나 (자유서술, 원문 보존)
}

interface SurveyInput {
  a: PersonAnswers;
  b: PersonAnswers;
  adultGateOpened: boolean;  // 두 사람 모두 Yes일 때만 true
  relationshipMonths: number; // 사귄 기간 (슬라이더)
}
```

> **🔞 게이트 규칙**: 한 명이라도 No면 ④는 미측정이다. 릴레이 모드에서 A만 Yes를 눌렀다면 B에게도 게이트를 띄우고, B가 No면 A의 Q11~Q14는 저장하되 점수 산출에서는 제외한다(재유도 시 재사용).

## 2. 애착 2차원 채점

### 2-1. 선택지별 점수표

애착에 기여하는 문항은 **7개**(Q1·Q2·Q4·Q5·Q6·Q11·Q13). 나머지는 0.

| 문항 | 선택지 | 불안 | 회피 |
|---|---|---|---|
| **Q1** 애정 수신 | ① 스킨십 | 0 | −1 |
| | ② 말 | +1 | −1 |
| | ③ 시간 | +1 | 0 |
| | ④ 정성 | 0 | +1 |
| **Q2** 갈등 타이밍 | ① 그 자리에서 바로 | **+2** | −1 |
| | ② 가라앉으면 말함 | 0 | 0 |
| | ③ 각자 시간 갖고 | −1 | +1 |
| | ④ 상대가 먼저 올 때까지 | +1 | **+2** |
| **Q4** 연락 페이스 | ① 하루 종일 | **+2** | −1 |
| | ② 아침·자기 전 | +1 | 0 |
| | ③ 며칠 텀도 OK | −1 | +1 |
| | ④ 용건 있을 때만 | −1 | **+2** |
| **Q5** 설렘 트리거 | ① 스킨십 | 0 | −1 |
| | ② 눈빛·표정 | 0 | 0 |
| | ③ 세심하게 챙김 | 0 | +1 |
| | ④ 내 편 들어줌 | +1 | −1 |
| | ⑤ 나를 위한 희생 | **+2** | −1 |
| **Q6** 원하는 케어 | ① 같이 열받아줌 | **+2** | −1 |
| | ② 말없이 안아줌 | +1 | −1 |
| | ③ 안 묻고 옆에만 | 0 | **+2** |
| | ④ 기분 전환 | 0 | +1 |
| **Q11** 주도권 | ① 내가 리드 | 0 | +1 |
| | ② 리드 받는 쪽 | +1 | −1 |
| | ③ 밀당 | 0 | 0 |
| | ④ 격정적으로 | 0 | −1 |
| **Q13** 애프터 | ① 껴안고 한참 | **+2** | −1 |
| | ② 도란도란 얘기 | +1 | 0 |
| | ③ 같이 씻고 늘어짐 | 0 | +1 |
| | ④ 맛있는 거 | 0 | +1 |

### 2-2. 정규화

🔞 응답 여부에 따라 이론적 범위가 달라지므로 **범위를 동적으로 계산한다.**

```
🔞 측정됨 (Q1·Q2·Q4·Q5·Q6·Q11·Q13):
  불안 raw ∈ [−2, +12]     회피 raw ∈ [−7, +10]

🔞 미측정 (Q1·Q2·Q4·Q5·Q6):
  불안 raw ∈ [−2, +10]     회피 raw ∈ [−5, +8]

정규화:  norm = (raw − min) / (max − min) × 100     // 0~100
```

### 2-3. 유형 판정

```
          회피 < 50      회피 ≥ 50
불안 < 50   안정형        회피형
불안 ≥ 50   불안형        혼란형
```

> ⚠️ **컷오프 50은 잠정값이다.** 실제 응답 분포를 모르는 상태의 기본값이며, 지인 커플 테스트 후 실측 분포의 중앙값으로 교체해야 한다. 한쪽으로 쏠리면 진단이 무의미해지므로 **첫 20쌍 데이터가 모이면 반드시 재조정한다.**

> ⚠️ **유형명을 리포트 전면에 노출하지 않는다.** MASTER 3장 파생 결정에 따라 애착은 해석의 숨은 근거로만 쓴다. LLM 프롬프트에는 좌표와 유형을 주되, 출력 문장에 `안정형/불안형/회피형/혼란형`이라는 라벨을 쓰지 말라고 명시한다.

## 3. 정합도 매트릭스 — 두 사람의 답이 얼마나 맞는가

각 문항마다 **선택지 쌍별 정합도(0~100)**를 정의한다. 같은 답은 대부분 100이지만, **Q11만 예외**(상보성 축)다.

### 3-1. Q1 애정 수신 채널 (유사성 · 명목형)

같은 채널을 원하면 서로 본능적으로 맞는 방식으로 준다.

| | ①스킨십 | ②말 | ③시간 | ④정성 |
|---|---|---|---|---|
| **①스킨십** | 100 | 70 | 45 | 40 |
| **②말** | 70 | 100 | 55 | 65 |
| **③시간** | 45 | 55 | 100 | 75 |
| **④정성** | 40 | 65 | 75 | 100 |

근거: ①② = 직접적·즉각적 표현 계열 / ③④ = 행동으로 증명하는 계열. 계열 내부는 높고 계열 간은 낮다.

### 3-2. Q2 갈등 처리 타이밍 (유사성 · 순서형)

즉시성 순서 ① > ② > ③ > ④. **거리 1당 22점 감점.**

| | ①즉시 | ②가라앉으면 | ③시간갖고 | ④상대먼저 |
|---|---|---|---|---|
| **①즉시** | 100 | 78 | 56 | **34** |
| **②가라앉으면** | 78 | 100 | 78 | 56 |
| **③시간갖고** | 56 | 78 | 100 | 78 |
| **④상대먼저** | **34** | 56 | 78 | 100 |

근거: `즉시형 × 시간필요형 = 싸움이 두 배로 길어진다`(03C). ①×④가 구조적 최악 조합.

### 3-3. Q3 데이트 선호 (유사성 · 명목형)

| | ①계획 | ②홈 | ③콘텐츠 | ④대화 |
|---|---|---|---|---|
| **①계획** | 100 | 40 | 75 | 55 |
| **②홈** | 40 | 100 | 45 | 70 |
| **③콘텐츠** | 75 | 45 | 100 | 65 |
| **④대화** | 55 | 70 | 65 | 100 |

근거: ①③ = 외출·활동형 / ②④ = 저강도·밀착형. ①×② (계획 외출 vs 집콕)가 가장 먼 조합.

### 3-4. Q4 연락 페이스 (유사성 · 순서형)

밀착도 순서 ① > ② > ③ > ④. **거리 1당 22점 감점.**

| | ①하루종일 | ②아침저녁 | ③며칠텀 | ④용건만 |
|---|---|---|---|---|
| **①하루종일** | 100 | 78 | 56 | **34** |
| **②아침저녁** | 78 | 100 | 78 | 56 |
| **③며칠텀** | 56 | 78 | 100 | 78 |
| **④용건만** | **34** | 56 | 78 | 100 |

근거: `집착 vs 무관심으로 서로를 오독`(03C). 초기 커플 최대 마찰 지점.

### 3-5. Q5 설렘 트리거 (유사성 · 5택)

| | ①스킨십 | ②비주얼 | ③다정함 | ④내편 | ⑤헌신 |
|---|---|---|---|---|---|
| **①스킨십** | 100 | 65 | 50 | 40 | 40 |
| **②비주얼** | 65 | 100 | 55 | 45 | 40 |
| **③다정함** | 50 | 55 | 100 | 70 | 70 |
| **④내편** | 40 | 45 | 70 | 100 | 80 |
| **⑤헌신** | 40 | 40 | 70 | 80 | 100 |

근거: ①② = 감각·즉각 계열 / ③④⑤ = 정서·헌신 계열. ④⑤는 거의 같은 축(내 편 ↔ 희생)이라 80.

### 3-6. Q6 원하는 케어 (유사성 · 명목형)

| | ①같이열받 | ②안아줌 | ③옆에만 | ④기분전환 |
|---|---|---|---|---|
| **①같이열받** | 100 | 60 | 40 | 55 |
| **②안아줌** | 60 | 100 | 70 | 50 |
| **③옆에만** | 40 | 70 | 100 | 45 |
| **④기분전환** | 55 | 50 | 45 | 100 |

근거: ②③ = 조용한 곁 지킴 계열. ①×③ (같이 흥분 vs 조용히 두기)이 가장 먼 조합 — `위로가 어긋나면 관계가 크게 흔들린다`(03C).

### 3-7. Q7 매력 우선순위 (유사성 · 가치관)

| | ①얼굴 | ②성격 | ③능력 | ④대화 |
|---|---|---|---|---|
| **①얼굴** | 100 | 45 | 65 | 50 |
| **②성격** | 45 | 100 | 45 | 75 |
| **③능력** | 65 | 45 | 100 | 50 |
| **④대화** | 50 | 75 | 50 | 100 |

근거: ①③ = 조건 지향 / ②④ = 관계 지향. 같으면 `가치관 싱크` 가산점(07).

### 3-8. Q11 주도권 (**상보성** · 유일한 예외)

**같은 답이 최고점이 아니다.** ①×②가 100, ①×①이 40이다.

| | ①내가리드 | ②받는쪽 | ③밀당 | ④격정 |
|---|---|---|---|---|
| **①내가리드** | **40** | **100** | 75 | 70 |
| **②받는쪽** | **100** | **45** | 75 | 65 |
| **③밀당** | 75 | 75 | 90 | 80 |
| **④격정** | 70 | 65 | 80 | **95** |

근거(07 명시): `둘 다 ①이면 조율 필요, ①×②면 찰떡, 둘 다 ④면 이건 그냥 잘 맞는 거야`. ②×②는 둘 다 리드받길 원해 아무도 시작하지 않는 교착이라 45.

### 3-9. Q12 × 상대 Q11 (**교차 매칭** · 비대칭)

Q12는 자기들끼리 비교하지 않는다. **내가 끌리는 상대의 모습 vs 상대가 실제로 하고 싶은 것**을 맞춘다.

행 = 내 Q12(내가 끌리는 모습), 열 = **상대의** Q11(상대가 하고 싶은 것)

| 내 Q12 ＼ 상대 Q11 | ①리드 | ②받는쪽 | ③밀당 | ④격정 |
|---|---|---|---|---|
| **①박력** | 95 | 40 | 70 | 90 |
| **②다정한 손길** | 60 | 65 | 80 | 45 |
| **③능숙한 리드** | 95 | 35 | 75 | 70 |
| **④수줍은 모습** | 45 | 85 | 70 | 40 |

**비대칭이므로 양방향을 각각 계산해 평균낸다.**
```
q12Score = ( M[a.q12][b.q11] + M[b.q12][a.q11] ) / 2
```

근거(07): `②를 원하는데 상대는 ①로 리드하고 싶어함 같은 어긋남이 바로 잡힌다`.

### 3-10. Q13 여운·애프터 (유사성 · 명목형)

| | ①껴안기 | ②얘기 | ③씻고늘어짐 | ④먹기 |
|---|---|---|---|---|
| **①껴안기** | 100 | 80 | 65 | 50 |
| **②얘기** | 80 | 100 | 70 | 65 |
| **③씻고늘어짐** | 65 | 70 | 100 | 75 |
| **④먹기** | 50 | 65 | 75 | 100 |

근거: ①② = 밀착·정서 계열 / ③④ = 실용·전환 계열.

## 4. 점수판 산출

### 4-1. ① 싱크로율 (예측 적중률)

```
예측 페어 6개 = 예측 3문항 × 2인

A→B:  a.q8 vs b.q1  |  a.q9 vs b.q6  |  a.q10 vs b.q3
B→A:  b.q8 vs a.q1  |  b.q9 vs a.q6  |  b.q10 vs a.q3

싱크로율 = (정답 수 / 6) × 100     // 0, 17, 33, 50, 67, 83, 100
```

**각 오답에 방향 태그를 붙인다** — 이 태그가 리포트 제2장 "오해의 구조" 서술의 핵심 재료다.

```
예측한 선택지의 애착 좌표 vs 실제 선택지의 애착 좌표를 비교:
  예측 불안점수 > 실제 불안점수  →  과대평가 (상대를 실제보다 더 매달리는 사람으로 봄)
  예측 불안점수 < 실제 불안점수  →  과소평가 (상대를 실제보다 더 쿨한 사람으로 봄)
  불안 동일 & 회피 차이 있음     →  거리감 오해 (방향은 회피 부호로)
  둘 다 동일 (Q3 같은 취향축)    →  취향 오해 (방향 없음)
```

### 4-2. ② 관계운영 궁합

```
② = mean( q1Score, q2Score, q3Score, q4Score )
```

### 4-3. ③ 로망 싱크

```
③ = mean( q5Score, q6Score, q7Score )
```

### 4-4. ④ 🔞 은밀한 궁합

```
④ = mean( q11Score, q12Score, q13Score )      // q12Score는 3-9의 양방향 평균
    (adultGateOpened === false 이면 null)
```

### 4-5. 총 궁합점수

```
🔞 측정됨:   총점 = ①×0.25 + ②×0.30 + ③×0.25 + ④×0.20
🔞 미측정:   총점 = ①×0.30 + ②×0.40 + ③×0.30
```

가중치 근거: **관계운영(②)이 일상 지속 빈도가 가장 높아 최대.** 🔞(④)는 게이트로 아예 없을 수 있는 데이터이므로 가장 낮게 잡아 미측정 시 재분배 폭을 최소화한다.

### 4-6. 구간 라벨

모든 게이지는 0~100, **높을수록 잘 맞는 방향**으로 통일한다. 방향을 섞으면 개발 실수와 사용자 오독이 동시에 발생한다.

| 구간 | 총 궁합점수 | 싱크로율 | 관계운영 | 로망 싱크 | 🔞 온도 |
|---|---|---|---|---|---|
| 0~30 | 지금은 다른 언어를 쓰는 중 | 서로를 오해 중 | 결이 많이 다름 | 로망이 서로 딴 곳을 봄 | 온도차 뚜렷 |
| 31~60 | 번역기가 필요한 사이 | 반은 알고 반은 모름 | 맞춰가는 중 | 일부만 통함 | 미지근하게 다름 |
| 61~85 | 합이 좋은 편 | 제법 잘 읽는 편 | 합이 좋은 편 | 취향이 잘 겹침 | 잘 맞는 편 |

## 5. 격차 지수 & TOP3

```
격차 지수(문항) = 100 − 정합도(문항)

후보 문항 10개: Q1 Q2 Q3 Q4 Q5 Q6 Q7 Q11 Q12 Q13
  ※ Q8~Q10(예측)은 제외 — 싱크로율이 담당
  ※ Q14·Q15(자유서술)는 제외 — 정량 대상 아님
  ※ 🔞 미측정 시 Q11~Q13 자동 제외 (후보 7개)

TOP3 = 격차 지수 내림차순 상위 3개

  (애착 주근거이면서 실제 마찰로 직결되는 순서)
```
