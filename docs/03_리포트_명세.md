## 0. 공통 골격

모든 장은 아래 순서를 기본으로 한다.

```
상단 업셀 배너 → 점수 게이지 → 시각화 → 해설 본문 → 언니 컷
```

> MVP에서는 **업셀 배너를 렌더링하지 않는다.** 결제·업셀이 없기 때문이다. 배너 슬롯과 문구는 코드에 남겨두고 `SHOW_UPSELL = false`로 끈다.

| 장 | 제목 | 게이지 | 시각화 | 언니 컷 | 생성 |
|---|---|---|---|---|---|
| 1 | 총평 — 우리 궁합, 진짜 점수 | 총점 | 대형 원형 게이지 + 4타일 | 1 | 규칙 |
| 2 | 싱크로율 — 서로를 얼마나 알고 있나 | ① | 예측 6칸 대조 | 1 | LLM |
| 3 | 관계운영 궁합 | ② | 레이더차트 2개 | 1 | LLM |
| 4 | 로망 싱크 — 서로가 원한 것 | ③ | 대조 매트릭스 | 1 | LLM |
| 5 | 🔞 은밀한 온도차 | ④ | 온도 게이지 2개 | **0** | LLM |
| 6 | 가장 어긋난 TOP3 + 해법 | — | 순위 카드 3장 | 1 | LLM |
| 7 | **상대 사용설명서** | — | 해답지 카드 인당 4장 | 1 | LLM |
| 8 | **오늘 나눠볼 대화 주제 3가지** | — | 주제 카드 3장 | 1 | LLM |
| 9 | 언니의 편지 | — | 편지 레이아웃 | 2 | 템플릿+LLM |

**언니 컷 합계 = 9컷.** 제5장이 0컷인 이유: *캐릭터가 선정성을 대변하지 않게 분리*(01 7장). 남는 1컷을 제9장에 몰아 정서적 마무리를 강화한다.

## 1. 제1장 — 총평

**부제**: "무료에서 궁금했던 그 숫자, 지금 연다"

- **게이지**: 총 궁합점수. 상태 3종 `locked`(회색 `?점`) → `unlocking` → `revealed`
- **점수판 4타일**: `{아이콘, 타일명, 점수 or "미측정", 미니 바, 탭 시 해당 장으로 스크롤}`

### 잠금 해제 연출 (MVP에서도 유지)

결제가 없어도 이 연출은 남긴다. **랜딩 티저에서 `?점`으로 돌던 게이지가 여기서 채워지는 것**이 이 제품의 감정적 클라이맥스이기 때문이다.

```
0.0s  회색 게이지 "?점" + 카피 "이제 진짜 점수를 볼 시간이야"
0.5s  잠금 아이콘 좌우 2회 흔들림 (150ms 간격)
1.0s  "철컥" 햅틱 + 잠금 아이콘 위로 튕겨나감 (ease-out-back 300ms)
1.3s  트랙 회색→그라디언트 크로스페이드(400ms)
      + 숫자 0→실점수 카운트업 (ease-out-cubic 1.6s), 게이지 바 동기화
2.9s  scale 1.0→1.06→1.0 (200ms) "팡" 강조
3.1s  언니 컷 pop-in(250ms) + 구간별 대사
3.6s  4타일 ①→②→③→④ 150ms 스태거 fade-up
4.5s  하단 스크롤 유도 화살표 bounce
      ※ 화면 아무 곳이나 탭하면 전체 스킵 → 최종 상태로 점프
```

### 결론 층위 원칙 (엄수)

> **1장은 숫자 공개와 이정표 역할만 한다.** "왜 이 점수인지"는 절대 여기서 말하지 않는다 — 2~5장의 몫을 미리 가로채면 뒤 장들이 맥빠진다.
> **총평은 집계이지 해석이 아니다.** 원인 분석 문장 0개.

## 2. 제2장 — 싱크로율

**부제**: "너가 나를 맞혔는지, 아니면 착각했는지"

- **시각화**: 3행(예측 문항) × 2열(A→B / B→A) = 6칸. 각 칸 `{문항 요약, 예측한 답, 실제 답, ✅/❌, 오답 시 방향 태그}`
- **주 데이터**: `predictions[]` 6개
- **교차 참조**: 빗나간 예측이 **어느 영역**인지
- **결론 층위**: "누가 상대를 더 정확히 읽는가", "오해가 생기는 패턴". **그 영역의 궁합이 좋은지 나쁜지는 여기서 판단하지 않는다**(3·4장 몫)

분량: 요약 100~150자 / 6칸 캡션 각 80~100자 / "가장 크게 어긋난 예측이 말해주는 것" 300~400자

## 3. 제3장 — 관계운영 궁합

**부제**: "데이트·연락·애정표현·갈등, 실제로 어떻게 굴러가고 있나"

- **레이더차트 2개 오버레이** (모바일은 반투명 겹침). **축 4개 = Q1 애정수신 / Q2 갈등 / Q3 데이트 / Q4 연락**
- 각 축 값은 "성향 강도"가 아니라 **A·B 각자의 응답 위치**를 양극 스케일에 표시. 겹치는 면적이 클수록 "합이 좋다"는 인상
- **교차 참조**: 로망 문항(원하는 방식 vs 현재 방식의 격차), 자유서술 어휘의 온도, 예측 정확도, **애착 좌표(숨은 근거)**
- **결론 층위**: **현재 실제로 하고 있는 방식**끼리의 궁합만. 로망 데이터를 인용해도 결론은 "지금 이렇게 하고 있다/이게 안 맞는다"는 **운영 습관** 층위

분량: 총점 요약 100~150자 / 4축 총평 300~400자 / 축별 각 150~200자 / 격차 원인 300~400자

---

## 4. 제4장 — 로망 싱크

**부제**: "이상형 답변, 나란히 놓고 보면"

- **대조 매트릭스**: 행 = Q5·Q6·Q7, 열 = `A답 / B답 / 매치 아이콘(◎△✕)`
- **교차 참조**: 갈등 대응 방식(로망이 무너지는 지점), 🔞 응답(미측정 시 생략), Q15 서술
- **결론 층위**: **이상적으로 원하는 것 자체**의 일치·불일치. 실행 방법은 7장 몫, 현재 습관 비교는 3장에서 이미 다룸

> ⚠️ **Q7 ③(능력·경제력) 가드레일** — 프롬프트에 명시: *"③을 고른 쪽을 속물적으로 묘사하지 말 것. `현실 감각도 사랑의 일부`라는 프레임으로 다룰 것."*

## 5. 제5장 — 🔞 은밀한 온도차

**부제**: "이건 좀 다르게, 조용히 보여줄게"

- **Yes**: 좌우 온도계 2개(세로 막대 0~100) + 중앙 일치도 원형 배지. 컬러는 **붉은 계열 채도를 낮춰** 자극적 인상 억제
- **Q14 원문 블록**: 두 사람의 자유서술을 **다듬지 않고 그대로** 인용 카드로 노출. 이 장의 핵심 가치
- **No**: 회색 잠금 + "미측정" + CTA `"4문항이면 채울 수 있어"` → 인라인 모달 → 완료 시 ④ 산출 + 총점 재계산 + 1장 애니메이션 재생
- **언니 컷 0개.** 대사도 말풍선 없는 캡션으로만 (예: `"이건 둘이 알아서 얘기해"`)
- **결론 층위**: **"온도가 같은지 다른지"까지만.** 실행 조언은 생략하거나 극히 절제된 한 문장. **이 장이 코칭 톤으로 흐르면 상품 성격이 바뀐다**

분량: Yes 기준 500~800자 (조언성 문장 최소화) / No 기준 150~250자

---

## 6. 제6장 — 가장 어긋난 TOP3

**부제**: "오늘 당장 확인해볼 세 가지"

- **순위 카드 3장**: `{순위, 카테고리 배지, A답 요약, B답 요약, 격차 바, 오늘 해볼 것 1문장}`
- **주 데이터**: `top3` (전 영역 스캔한 문항 단위 격차 상위 3)
- **교차 참조**: 해당 문항이 속한 카테고리의 세부 데이터, **애착 좌표(숨은 근거)**

### 6장 vs 7장 경계 (가장 중요한 구분)

| | 제6장 | 제7장 |
|---|---|---|
| 대상 | 가장 벌어진 **딱 3개 지점** | **로망 성향 전체** |
| 성격 | 응급처치 (reactive, 국소적) | 상시 루틴 (proactive, 포괄적) |
| 시제·범위 | **지금 당장 / 1회** | **평소 / 반복** |

같은 문항이 양쪽에 등장해도 된다. **결론의 시제와 범위가 다르면 중복이 아니다.**

분량: 인트로 100자 / 카드당 350자(무엇 100 + 왜 100 + 오늘 할 것 150)

---

## 7. 제7장 — 상대 사용설명서 (이 제품의 진짜 상품)

**부제**: "네가 좋아하는 거, 이제 어떻게 하면 되는지 알려줄게"

제2장 문항의 "해답지" 설계 원칙이 결과물로 회수되는 자리다. 이상형 응답을 **성향 설명에서 그치지 않고 실제 상황에서의 실행 방법으로 번역**하는 것이 이 장의 유일한 존재 이유다.

### 최상단 — Q15 원문 배치

카드보다 먼저, **상대가 직접 쓴 "제일 바라는 것 하나"를 원문 그대로** 인용 카드로 올린다. LLM이 다듬지 않는다. 상대 입장에서는 **가장 실행하기 쉬운 한 가지**다.

### 해답지 카드 포맷 (고정 3단)

```
┌────────────────────────────────────┐
│ 🏷 #데이트제안  #갈등직후  #스킨십타이밍 │
│                                      │
│ 이런 상황에서:                        │
│   {구체적 상황 서술 1문장}             │
│                                      │
│ 이렇게 하면:                          │
│   {실행 지침 1~2문장}                  │
│                                      │
│ 얘는 이렇게 반응한다:                  │
│   {예상 반응 + 왜 그런지 1~2문장}       │
└────────────────────────────────────┘

카드 수: 인당 4장 × 2인 = 총 8장
탭으로 "{A}를 위한 사용설명서" / "{B}를 위한 사용설명서" 전환
카드 소스: Q5·Q6·Q7(로망) × Q1~Q4(실행 맥락) 매핑
```

### 예시 카드

> 🏷 **#데이트제안**
> **이런 상황에서**: 다음 데이트 날짜를 정할 때
> **이렇게 하면**: 미리 코스를 다 짜서 "짜잔" 하고 통보하지 말고, 후보 두 개만 던지고 고르게 해줘.
> **얘는 이렇게 반응한다**: 자기가 고른 선택지라 준비 과정부터 신나서 챙긴다. 통제감을 뺏기면 오히려 흥이 식는 타입.

> 🏷 **#갈등직후**
> **이런 상황에서**: 다툰 직후, 마음은 안 풀렸는데 바로 대화하긴 싫을 때
> **이렇게 하면**: "지금 얘기하자"고 몰아붙이지 말고 "나 좀 이따 얘기하고 싶어, 언제 괜찮아?"라고 시간을 넘겨줘.
> **얘는 이렇게 반응한다**: 스스로 정리할 시간을 받으면 먼저 다가와서 대화를 연다. 몰리면 방어적으로 굳어버리는 타입.

분량: 인트로 150자 / 카드 8장 각 150~200자 / 마무리 150~200자

## 8. 제8장 — 오늘 나눠볼 대화 주제 3가지 ★ 교체된 장

**부제**: "이 세 가지만 얘기해봐. 오늘 확 가까워질걸"

> **교체 근거 (클라이언트 결정)**: 04 원본의 「질문 12개 카드 덱」을 **주제 3개**로 압축한다.
> 12개는 분량은 크지만 각 질문이 왜 이 커플에게 나왔는지 설명할 자리가 없다. 3개로 줄이면 **주제마다 "왜 너희에게 이 주제인가"라는 개인화 근거를 붙일 수 있어** 오히려 밀도가 올라간다.

### 주제 카드 포맷

```
┌────────────────────────────────────┐
│  주제 ①                              │
│  {주제 제목}                          │
│                                      │
│  왜 이 얘기냐면                       │
│   {이 커플 데이터에 근거한 이유 2~3문장} │
│                                      │
│  이런 걸 물어봐                       │
│   · {질문 1}                          │
│   · {질문 2}                          │
│   · {질문 3}                          │
│                                      │
│  이 얘기를 하면                       │
│   {기대 효과 1~2문장}                  │
└────────────────────────────────────┘
```

### 주제 선정 로직 (규칙 기반)

```
1. categoryGaps 를 내림차순 정렬
2. 상위 3개 카테고리를 주제 ①②③에 배정
3. 🔞 미측정이면 🔞 카테고리는 후보에서 자동 제외
4. 동점 시 우선순위: 갈등 > 거리·연락 > 위로·케어 > 애정표현 > 데이트 > 가치관 > 🔞
5. 카테고리별 주제 제목·기본 질문은 아래 뱅크에서 가져오고,
   "왜 이 얘기냐면" / "이 얘기를 하면" 두 블록만 LLM이 생성
```

### 카테고리별 주제 뱅크

| 카테고리 | 주제 제목 | 기본 질문 3개 |
|---|---|---|
| **갈등** | 부딪혔을 때 우리는 어떻게 할까 | · 우리가 다투면 너는 바로 풀고 싶어, 아니면 시간이 필요해?<br>· 내가 어떻게 다가오면 제일 마음이 풀려?<br>· "이건 하지 말아줘" 싶은 화해 방식 있어? |
| **거리·연락** | 우리한테 딱 좋은 거리 | · 연락 자주 오는 게 좋아, 아니면 가끔이 편해?<br>· 답장이 늦으면 어떤 생각이 들어?<br>· 혼자 있고 싶은 날엔 어떻게 말해주면 좋겠어? |
| **위로·케어** | 힘들 때 뭘 해주면 좋을까 | · 기분이 바닥일 때 내가 뭘 해주면 제일 좋아?<br>· 반대로 그때 절대 하지 말았으면 하는 건?<br>· 최근에 나한테 위로받고 싶었던 순간 있었어? |
| **애정표현** | 사랑받는다고 느끼는 순간 | · 내가 어떻게 할 때 제일 사랑받는다고 느껴?<br>· 요즘 제일 듣고 싶었던 말 있어?<br>· 내가 놓치고 있는 표현 방식이 있을까? |
| **데이트** | 우리한테 진짜 좋은 데이트 | · 다음 데이트는 네가 원하는 대로 짜본다면 어떤 그림이야?<br>· 지금까지 데이트 중에 제일 좋았던 날은?<br>· 사실 별로였는데 말 못 한 거 있어? |
| **가치관** | 서로한테 뭘 보고 끌렸을까 | · 나의 어떤 점에 처음 끌렸어?<br>· 지금은 그게 달라졌어?<br>· 앞으로 우리 사이에서 제일 중요한 게 뭐라고 생각해? |
| **🔞** | 말 안 했던 온도 이야기 | · 우리 둘 온도 차이, 솔직하게 하나만 맞춰볼까?<br>· 리드하는 쪽이 편해, 받는 쪽이 편해?<br>· 끝나고 나서 제일 좋은 마무리는 뭐야? |

### 마무리 카피 (고정)

> 이 세 가지만 오늘 얘기해봐. 어려운 얘기일수록 오늘처럼 가볍게 시작하는 게 제일 쉬워.
> 이 얘기 나누고 나면 서로를 훨씬 더 이해하게 되고, 지금 어긋나 있던 것들도 자연스럽게 풀릴 거야.

### 중복 회피

- 질문 3개는 **열린 질문 형식**이라 6·7장이 이미 말한 결론을 반복하지 않는다 — 질문은 결론이 아니라 대화의 문을 여는 장치다
- 단 "왜 이 얘기냐면" 블록은 6·7장이 인용한 **구체적 문장을 그대로 반복하지 않는다.** 카테고리 수준의 일반화로만 서술

분량: 카드당 250~350자 × 3 + 마무리 100자

## 9. 제9장 — 언니의 편지

**부제**: "여기까지 읽어준 두 사람에게"

- 손편지 레이아웃(종이 질감, 손글씨 폰트). 상단 컷 1 + 서명 옆 소형 컷 1 = **2컷**
- 스크롤 종료 시 `대화 주제 다시 보기` / `결과 공유하기` 버튼 2개 고정

### 데이터 바인딩

```
{A이름}, {B이름}      ← 입력 단계
{최다불일치영역}       ← top3[0]의 카테고리명
{의외발견}            ← predictions 중 가장 크게 빗나간 예측의 방향 태그를
                        자연어 한 문장으로 변환 (LLM 경량 호출)
{바라는것}            ← Q15 원문 인용

원칙: 이 장은 새로운 분석적 결론을 생성하지 않는다.
```

### 편지 초안

> {A이름}, {B이름}에게
>
> 여기까지 다 읽었네. 솔직히 좀 웃긴 것도 있고, 뜨끔한 것도 있었을 거야. 나도 옆에서 두 사람 답 읽으면서 몇 번 웃었어.
>
> 이 리포트에서 하나만 기억해줬으면 좋겠어. 점수는 숫자일 뿐이고, 진짜는 오늘 너희 둘이 이걸 같이 붙잡고 앉아서 서로 얘기했다는 거야. 몇 점이 나왔든, 어디가 어긋났든 — 그걸 궁금해했다는 것 자체가 이미 잘하고 있다는 증거야.
>
> {최다불일치영역} 부분, 오늘 나온 얘기 잊지 말고 한 번쯤 다시 꺼내봐. 어려운 얘기일수록 오늘처럼 가볍게 시작하는 게 제일 쉬워.
>
> 그리고 {의외발견}인 거, 오늘 처음 안 사람은 꼭 기억해두고. 그게 앞으로 제일 쓸모 있을 거야.
>
> 아까 그 세 가지 주제, 다음에 또 꺼내 봐. 오늘 다 못 나눈 얘기는 다음 데이트에 이어가면 되니까.
>
> 오늘 수고했어, 둘 다.
>
> — 언니가

분량: 500~700자
