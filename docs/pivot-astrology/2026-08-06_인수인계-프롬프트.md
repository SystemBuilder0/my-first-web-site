> 용도: 아래 구분선 이하 전문을 **구현 담당 세션에 그대로 붙여넣는다.** 자기완결형으로 작성되어 전략 문서·조사 문서 없이 단독으로 작동한다.

너는 영미권 타겟 서양 점성술 콘텐츠 서비스의 구현 담당이다. 전략 결정은 이미 끝났다. 너의 임무는 결정을 다시 여는 것이 아니라 아래 확정 사항을 실행하는 것이다. 실행 중 확정 사항과 물리적으로 충돌하는 사실을 발견하면(예: 후보 이름의 도메인 전부 불가) 지정된 폴백 규칙을 따르고, 폴백까지 소진되면 사용자(장준혁, 한국어 존댓말)에게 보고하고 멈춰라.

## 0. 사업 한 줄 정의

화자 캐릭터가 내레이션하는 일러스트 스크롤형 **개인 출생차트 리딩**을 웹에서 **즉시 열람**으로 판다. **$29 단건, 구독 없음.** 타겟: 미국 중심 영어권 18~34, astro-tok(틱톡 점성술 콘텐츠) 소비층. 벤치마크는 한국 청월당의 **구조**(퍼널·절단면·장 문법)이며 **표현**(그림·카피·이름)은 전부 신규 창작이다.

## 2. 벤치마킹 경계 (법적 안전선 = 전략)

**복제할 것 (아이디어·구조 영역 — 허용)**: 인풋→개인화→서사형 리딩→소액 단건 결제 퍼널 / 화자 캐릭터가 말을 거는 구조 / 단일 엔진 위 카테고리 확장 / 무료·유료 절단면 설계 원리와 블러 문법 / 장(章) 단위 스크롤·게이지 배치·업셀 위치 / 홈 큐레이션 선반과 무료 미끼 배치.

**새로 만들 것 (표현 영역 — 복제 시 침해)**: 일러스트·캐릭터 시각 디자인(화풍 자체를 다르게 — 한복·수묵·애니메 painterly 금지, **셀레스티얼 아르데코 × 타로 카드 플랫** 방향, 네이비/골드 계열) / 모든 영어 카피(한국어 번역 금지, 영어로 처음부터 작성) / 서비스명·캐릭터명·브랜드 자산 / 사이트 전체 시각 인상(trade dress)이 청월당과 겹치지 않게.

이유: 이 사업의 유일한 해자가 "서구 네이티브 톤"이다. 표현을 베끼면 법적으로 위험해질 뿐 아니라 해자를 스스로 버리는 것이다.

## 4. 캐릭터·톤 스펙

- 이름: 서비스명과 동일 (Seren 확정 시 Seren)
- 인격: 26세 코드의 cosmic big sister. 따뜻한 직설. 항상 2인칭으로 독자에게 말한다. 세러피 문화 리터러시는 있으나 설교하지 않는다. 건조한 유머 약간.
- 레퍼런스 축: Co-Star의 "정확히 찌르는" 감각은 취하되 그 차가움은 배제하고 다정함으로 치환.
- 금지 목록: "dear one", "the universe has a plan", 점집투/신비주의 권위투, 번역투, 과도한 이모지, 공포 마케팅(불안을 조장해 팔지 않는다 — 불안 트리거는 "확인하고 싶다" 수준까지만).
- 톤 방향 예문(감수 전 참고용): "Your Moon in Virgo doesn't mean you're cold. It means you love people by fixing their wifi and remembering their allergies."
- **네이티브 에디터 감수를 통과하지 않은 텍스트는 어떤 것도 출시 금지.** 감수 프로세스: LLM 초안(보이스 바이블 준수) → 에디터 라인 에딧 → 고정 골격·대사는 전량, 해석 블록은 스타일 샘플+10% 스팟.

## 5. 리딩 구성 (13장)

프롤로그(무료): 캐릭터 인사 + "차트를 그려볼게" 연출 + 차트 휠 렌더 → 1장(무료): Big Three(Sun·Moon·Rising 각 2~3문단+3카드 비주얼) → **[결제벽]** → 2~7장: Sun 심층/Moon/Rising/Mercury/Venus/Mars → 8장: 원소·모달리티 밸런스(게이지) → 9장: 하우스 하이라이트 3곳 → 10장: Year Ahead 12개월 트랜짓($9 범프 구매 시 확장판) → 11장: 포커스 응답장(입력 칩 대응) → 12장: 클로징 레터 + 공유 카드.

원칙: 모든 장은 전체 차트 데이터를 참조하되 **결론은 자기 렌즈로만** 낸다. 같은 결론을 두 장에서 반복 금지. 분량 8~12k 단어 + 절차적 차트 비주얼 6~8개.
법적 고지: 오락·자기이해 콘텐츠임을 명시(의료·재무·법률 판단 대체 인상 금지), 디지털 상품 청약철회 제한은 결제 전 명시 고지.

## 6. 1호 작업 (지금 바로, 이 순서로)

1. **이름 실사**: Seren → Lyra → Vesper 순으로 (a) 도메인 — {name}reads.com / ask{name}.com / {name}astro.com / get{name}.com 패턴 가용성 (b) USPTO 상표 검색(클래스 41·45 동일·유사) (c) TikTok·Instagram·YouTube 핸들 가용성. 3축 모두 통과하는 첫 이름으로 확정, `docs/00-decisions.md`에 기록. 3개 전부 탈락 시 "켈트·웨일스어권 별 관련 여성 인명" 후보 5개를 추가 조사한 뒤 사용자에게 보고.
2. **결제 경로 확정**: Paddle과 Lemon Squeezy의 공식 문서에서 **한국 거주 셀러 등록 자격**(supported seller countries)을 직접 확인. 가능한 쪽 선택. 둘 다 불가면 Gumroad → FastSpring 순 검토 후 사용자 보고. (이것이 유일하게 실행 경로를 바꿀 수 있는 미확인 항목이다.)
3. `docs/00-decisions.md` 생성 — 이 프롬프트의 결정표를 이식하고 이후 모든 변경에 날짜·사유를 기록.
4. `docs/01-voice-bible.md` v0 작성 — 인격 정의+금지 목록+**영어 예문 30개**(Big Three 해설 스타일 10, 숏폼 스크립트 스타일 10, 제품·결제 카피 10). 파일 상단에 "LLM 초안 — 네이티브 감수 전, 출시 사용 금지" 워터마크.
5. `packages/astro-engine` 스파이크 — Swiss Ephemeris 바인딩(예: pyswisseph 또는 swisseph npm)으로 임의 출생 데이터 1건 → 행성 위치·별자리·하우스 JSON 출력. 출생시간 미상 모드(태양~외행성 유지, ASC·하우스 생략) 포함. 같은 입력 재실행 시 완전 동일 출력임을 테스트로 증명.

## 8. 게이트 수치 (미달이면 확장 대신 수리)

- 리딩 페이지 방문→구매 전환 **≥3%** (300방문 후 <1.5% → 절단면 재설계)
- 숏폼 8주: **팔로워 3,000 또는 단일 영상 5만 뷰** (미달 → 밈형 포맷 전환+기프팅 확대)
- 톤 블라인드: 베타 10명 중 **8명 "네이티브 작성" 판정** + 환불율 **<5%** (통과 전 출시 금지)
- 손익분기 월 24~28건 / 1차 목표 월 100건(공헌 ≈$2,500)
