## 4단계. 신한 외화(USD) 알림 파싱 — 확정 (2026-11-13, 장준혁 확정)

### 4-1. 수집
- Gmail 검색: `subject:[신한알림] from:topjang3@gmail.com` (기간은 직전 실행 이후, 첫 실행은 `newer_than:3d` 권장)
- 같은 제목이라 한 스레드로 묶인다. **스레드가 아니라 메시지 단위로** 모든 메시지를 읽는다(get_thread로 전체 메시지 확보 — 검색 결과 미리보기는 일부 메시지만 보여 줌).
- 본문은 `<br/>` 등 태그를 공백으로 바꾸고 연속 공백을 한 칸으로 정리한 뒤 파싱한다.

### 4-2. 건너뛰기 (적재·보고 안 함, 건수만 집계)
- 본문이 비어 있는 메일
- 본문에 `[USD]`가 없는 메일
→ 테스트 메일로 간주.

### 4-3. 형식 (정규식)
예: `[Web발신] 신한11/13-13:08 180*425426[USD] 입금 0.01 잔액 3,357.71 장준혁`

```
신한\s*(MM)/(DD)-(HH):(MI)\s+\S*\[USD\]\s+(입금|출금)\s+([\d,]+(\.\d+)?)\s+잔액\s+(-?[\d,]+(\.\d+)?)
```

| 문자 부분 | 거래 DB 칸 | 규칙 |
|---|---|---|
| 신한MM/DD-HH:MM | 날짜 (datetime) | 한국 시간(+09:00). 연도 = 메일 수신일(KST 환산) 연도, 단 거래월 > 수신월이면 전년도(12월 거래·1월 수신 경계) |
| 마스킹 계좌[USD] | 계좌 = `신한 외화(USD)`, 통화 = `USD` | 계좌번호(마스킹 포함)는 어디에도 저장하지 않는다 |
| 입금/출금 | 방향 | 그대로 |
| 금액 | 금액 | 쉼표 제거, **출금은 음수** (이 출처 한정 규칙) |
| 잔액 숫자 | 잔액 | 쉼표 제거 |
| — | 출처 = `알림`, 분류 = `미분류`, 수집일 = 실행일 | 거래 제목 = `외화 {방향} {금액} USD` |
| — | 비고 | Gmail 메시지 ID |

### 4-4. 중복 판정
- 키: 거래 일시(분) + 입출금 + 금액 + 잔액
- 원본ID 형식: `shinhan-usd|YYYY-MM-DDTHH:MM|{입금|출금}|{금액 절댓값 소수 2자리}|{잔액 소수 2자리}`
- 적재 전 거래 DB에서 같은 원본ID를 조회해 있으면 건너뛴다. 같은 분·같은 금액이 두 번 와도 잔액이 달라 구분된다.

### 4-5. 형식 불일치 (보류)
- `[USD]`는 있으나 위 정규식에 맞지 않는 메일(예: 아직 예시가 없는 출금 문자 변형, 해외송금 등)은 **적재하지 않는다.**
- 실행 보고서에 "형식 불일치 보류" 섹션을 따로 두고 메시지 ID·수신 시각·본문 앞 80자(계좌번호는 `***`로 가림)를 적는다.
